# VIVE Focus Visionの境界警告

確認日：2026-11-03。対象はFocus VisionのAndroid単体実行。公式の公開資料を確認したもので、実機で警告を解除した記録ではない。

## 分かっていること

利用者からは「開始地点から離れると、トラッキングを失わないよう初期位置へ戻る旨の警告が出る」と報告されている。正確な文言、HMDのソフトウェアバージョン、プレイエリア設定は未確認。本アプリの表示文言には該当する警告が見当たらないため、VIVE側の境界・追跡に関する通知を第一候補とする。これは状況からの推測である。

| 公式資料で確認できた事項 | 本研究での扱い |
|---|---|
| デフォルトモードはルームスケール・固定プレイエリアとMRに対応 | 走行ではデフォルト＋ルームスケールを第一候補とする |
| インスタントモードは装着ごとに半径1 mの固定エリアを作り、MRには非対応 | 今回の走行には採用しない |
| プレイエリアの端に近づくと境界が表示される | 実際の走路と停止場所を含めて設定する |
| 通常の公称プレイエリアは最大10×10 m | 会場全体を登録できるとは扱わない。10 m直進でも開始・停止区間を含む配置を確かめる |

根拠はHTCの[トラッキングモード](https://www.vive.com/jp/support/focusvision/category_howto/choosing-a-tracking-mode.html)、[プレイエリア設定](https://www.vive.com/jp/support/focusvision/category_howto/setting-up-play-area.html)、[製品仕様のTracked area specs](https://shop-us.vive.com/pages/vive-focus-vision)。公称範囲は現地での追跡率や本研究の測定精度を保証するものではない。

## 無効化について確認できた範囲

VIVE Business+のPro／Ultimate向け設定には、境界と追跡喪失時の扱いを管理する項目がある。ただし、公開資料は今回の日本語警告との対応や、この機器で選べる設定値まで示していない。契約・機器の登録状態と、実際の管理画面を確認する必要がある。[HTCの管理機能一覧](https://business.vive.com/nz/support/business-plus/category_howto/batch-configuration-features.html)

VIVE Custom APIもBusiness+ライセンスを必要とし、Pro／Ultimateの機能一覧には境界サイズや表示状態の取得などがある。現在のSDKを入れただけで、任意のOS警告を消せるとは確認できない。[HTC Custom API](https://developer.vive.com/resources/custom_api/)

一般設定で今回の警告を完全に消す方法は、確認した公開資料では未確認。別機種の古いFocus向け設定、Meta Quest用の境界API、出典のないADB設定をFocus Visionの対処として流用しない。追加契約や管理SDKの導入は今回の実装に含めない。

## 実機での切り分け

1. HMDのソフトウェアバージョン、現在のトラッキングモード、固定／ルームスケールの別を控える。
2. デフォルト＋ルームスケールで、走路と停止場所を含む境界を設定する。設定変更後はアプリの割当・校正と表示位置を確認し直す。
3. 自由走行で開始地点から少しずつ離れ、警告が出る位置と正確な文言を控える。同時にPCでHMDの準備状態と走行用3台の追跡状態を確認する。自由走行データは保存しないため、確認結果は実施者が別に記録する。
4. 境界を広げて警告が出なくなれば、その走路を再確認する。追跡欠測も起きる場合は、照明・周囲の特徴・遮蔽を含めて別に確認する。
5. 警告が残る場合は、Business+の利用資格と対象設定を確認する。表示だけを抑えられても、位置姿勢が取得できる範囲まで広がったとは扱わない。

アプリはOSの警告を検出・解除できると表示せず、実際の欠測・HMD中断・原点変更への停止処理を維持する。現地で警告が出ないことと、[測定性能の検証](../../docs/specifications/validation.md)を分けて確認する。実施者向けの操作は[導入・装着・準備](../../docs/operations/setup.md)を参照する。
