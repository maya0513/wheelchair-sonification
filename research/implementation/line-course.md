# 線課題のコース・位置合わせ・ズレ解析

確認日：2026-11-18。課題の決定と設計判断を記録する。当日の進行は[実験手順](../../docs/2_experiment-protocol.md)、集計と群比較は[分析計画](../../docs/3_analysis-plan.md)で管理する。

## なぜ線課題か

実験室の使える範囲では、従来の10 m直進と開けた場所の8の字が置けない。あわせて、指導教員から現行の時間指標では群差が見えにくいとの指摘があった。床に引いた線の中心を維持する課題を追加し、走行軌跡から連続量のズレを測る。

ズレは左右車輪速度の不均衡から生まれるため、FBが提示する変数（左右車輪速度）の制御を直接反映する。誤差の減少で技能を測るのは運動学習の追跡課題の標準的な方法であり、本研究が聴覚FBの根拠とするFujii et al. 2016も成果指標にRMSEを用いている。主張できる範囲は直進・経路維持という要素技能までで、車いす操作全般の学習とは区別する。

## 課題セット

- 課題は2本：8の字（2周を1試行）と線課題（コース1周を1試行）
- 順番は8の字→線課題。練習は評価と同じ課題を割付FBありで実施する
- 直進の独立課題は廃止する（直進運動は線課題と8の字に含まれる）
- 教示の骨子：「線の中心に車いすの中心を合わせ続けて走ってください」

## コース構成

スタート／ゴールは通路右側の線の上、縦方向の真ん中。線は床にテープで引く。コースは分岐のない1本の閉じた経路とする。

| 区間 | 内容 | 備考 |
|---|---|---|
| A：上り直線 | スタートから右側の線を上端へ | ズレの主要な計測区間の候補 |
| B：頂部ヘアピン | 上端で半円状に折り返す | 半径は通路幅の半分（約0.75 m、仮） |
| C：下り直線 | 左側の線を下る | 上りと別の線を使う |
| D：カーブ周回 | 下り直線から左へ入り、広い部分を大きく回る | 一方向旋回 |
| E：帰りの直線 | 下辺を右へ進み、右側の線を上ってゴールへ | ゴール手前の停止も見られる |

寸法はすべて仮の値。通路幅は最大で約1.5 m、車椅子幅は約0.9 m（どちらも未実測）。通路の長さと広い部分の寸法は初回設営で測る。

## フィールド座標と基準線

追跡座標はセッションごとに原点が変わるため、コースの定義は部屋に固定したフィールド座標で持つ。

- 原点はスタート位置。xはスタート方向を向いたときの右、zはスタート方向
- 部屋のカーペットは1辺0.5 mで、目地を基準に開始位置とマーカーを毎回同じ物理位置へ置ける
- 基準線は点列ファイル（CSV）で持ち、アプリには入れない。列は`x_m,z_m,segment`、進行順に並べ、閉ループでは終端に始点を繰り返す。点の間隔は直線で約1 m、カーブでは25–50 cm（粗いと折れ線がカーブを内側に切り、ズレに偏りが出る）
- マーカーも点ファイル（CSV）で持つ。列は`name,x_m,z_m`

## マーカーと位置合わせ

基準線そのものは初回に確定し、来訪ごとに必要なのは追跡座標からフィールド座標への変換（回転＋平行移動）だけとする。起動のたびに基準線の全点を記録し直す方法は、準備の繁雑さから採らない。開始位置の向きだけから変換を推定する方法も、角度の誤差が距離に比例して横ずれになる（1度で7 m先に約12 cm）ため採らない。

固定マーカーは3点（仮決定。問題があれば直す）：

| 名前 | 場所 |
|---|---|
| M1 | スタート地点 |
| M2 | 通路の上端（ヘアピン付近） |
| M3 | 広い部分の1点 |

来訪ごとの手順は、機器チェックの記録に相乗りする。任意のトラッカーをM1→M2→M3の順に各数秒置き、チェックのposes.csvへ静止位置を残す。追加作業は実質1分程度。HMDを再起動したら、その来訪の変換は取り直す。

変換は、実測3点とフィールド座標3点の組から2次元剛体変換を最小二乗（Kabsch法）で求める。点ごとの残差とRMS残差を品質指標として試行ごとに記録し、残差が大きい場合はマーカーの置き直しや点数の追加を検討する。任意の補助として、回転はマーカーで固定したまま、平行移動だけを試行ごとの開始位置で補正する方法も用意する（ドリフト対策。使うかどうかはパイロットで判断する）。

## ズレの定義と集計

- 測る点は車体トラッカー（Chassis）の位置。車いすの中心はトラッカーの取り付け位置で定義されるため、取り付けは中心に寄せて固定する
- 各時刻のズレは、フィールド座標へ変換した車体位置から、基準線の最も近い区間までの符号付き距離（進行方向の左が正）。航法のクロストラックエラーと同じ考え方で、参加者の速度によらず定義できる
- 追跡が無効なサンプルは計算から除く。計算はすべてオフラインで、アプリの改修は不要
- 集計は試行ごと・区間ごと。主要指標はRMSとし、平均絶対偏差を副次指標として併記する。最大ズレ、所要時間、平均速度も併記し、ズレと速度の引き換えを切り分ける
- 8の字については、所要時間に加え、speeds.csvから「ほぼ停止」（左右の平滑速度が両方とも0.03 rps未満の状態が0.5秒以上）を数える。0.03 rpsはアプリの提示停止しきい値に合わせた仮の値
- 主要指標の最終確定は、パイロットのばらつきを見て本計測前に行い、日付入りで[分析計画](../../docs/3_analysis-plan.md)へ反映する

解析は`scripts/line-deviation.mts`で行う。

```sh
mise exec --locked -- node scripts/line-deviation.mts \
  --reference <基準線.csv> --markers <マーカー.csv> \
  --check-poses <機器チェックのposes.csv> --marker-key <トラッカーのkeyの一部> \
  --trial-poses <試行のposes.csv> [--trial-speeds <試行のspeeds.csv>] \
  [--trial-offset] [--out-prefix <出力先>]
```

静止点が想定数と異なる場合はエラーを出し、`--marker-select`で使う静止点を番号で選べる。変換・ズレ・ほぼ停止の各処理には合成データによるテスト（`scripts/line-deviation.test.mts`）がある。

## パイロットで確認すること

- 変換の残差の大きさと、静止記録によるトラッカーのドリフト
- 区間Bのヘアピン（半径約0.75 m）が実際に回れるか、切り返しが何回入るか
- ズレ指標のばらつきと天井・床（主要指標の確定材料）
- 8の字で「ほぼ停止」する回数と時間
- 基準線の記録点の間隔が十分か（カーブ区間のズレの偏り）
