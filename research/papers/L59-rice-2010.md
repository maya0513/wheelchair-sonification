**Hand rim wheelchair propulsion training using biomechanical real-time visual feedback based on motor learning theory principles**

## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 運動学習理論に基づく視覚FBソフトと訓練方法の開発・1例の予備報告。 |
| 対象・人数 | 長期の手動車いす利用者1名。 |
| 課題 | 固定ダイナモメータで3回訓練、実走50 mの評価。 |
| 装置・計測 | SmartWheel240 Hz、ダイナモメータ、正面モニター。 |
| フィードバック | 角度・頻度・速度の実測値／目標。多変数連続提示案から、変数を減らし不連続・ランダム提示へ改訂。 |
| 評価時点・指標 | 開始と3か月後の実走行。 |

## 結果と限界

1例で角度増大・頻度等の低下を報告。

1例・複数回訓練・専用計測輪。固定台での画面提示を、HMDの実空間走行へそのまま移せない。「知覚できる遅れなし」は実測遅延の数値ではない。

## 本研究への示唆

画面の情報を増やしすぎない設計、速度と角度の区別、専用力計測の必要性を参考にする。1変数3状態・300 ms・純音の最適性を証明するものではない。
