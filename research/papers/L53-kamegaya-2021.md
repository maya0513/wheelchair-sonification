# L53｜車椅子8の字駆動テストの開発へ向けた予備的検討

ヘルスプロモーション理学療法研究 10(4), 189–193。調査・照合日：2026-10-14。

- 出典：[10.9759/hppt.10.189](https://www.jstage.jst.go.jp/article/hppt/10/4/10_189/_pdf/-char/ja)
- 閲覧範囲：**本文重点確認**。
- 本文：[保存PDF](../pdfs/L53.pdf)。版・条件は[PDF一覧](../pdfs/INDEX.md)。

## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 方向転換・加減速を含む駆動時間の検者間信頼性を検討。介入試験ではない。 |
| 対象・人数 | 健常成人36名（男性15、女性21）、21.3±0.6歳。車いす経験の詳細記載なし。 |
| 課題 | 屋内平地、コーン2本を5 m間隔、中点を開始終了線にし、8の字を1周。上肢駆動、できる限り速く、背部をバックサポートから離さない指示。 |
| 装置・計測 | AR-101自走型車いす、5TC-045クッション。作業療法士2名が同じ走行をストップウォッチで0.1秒単位に計時。 |
| フィードバック | 追加の音・画面による訓練なし。 |
| 評価時点・指標 | 同じ走行の計時一致、ICC(2,1)、Bland–Altman。日を変えた再テストなし。 |

## 結果と限界

計時値は約16.8秒、ICC 0.999（95%CI 0.999–1.000）。加算誤差は認めず、比例誤差あり。

一致したのは2検者の計時。被験者の再テスト信頼性、学習への反応性、臨床的妥当性、日常利用者での性能は未検証。高いICCは介入効果の大きさではない。

## 本研究への示唆

5 m・1周とキャスターでの開始終了を参考にする。2反復・動画・安全教示・訓練への使用は本研究の変更。元資料の5周を原著の手順として扱わない。
