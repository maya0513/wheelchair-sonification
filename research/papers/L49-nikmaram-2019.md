# L49｜Musical Sonification of Arm Movements in Stroke Rehabilitation Yields Limited Benefits.

## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 上肢ソニフィケーションの再現・低価格装置への展開を2施設で検討。 |
| 対象 | 42名登録、Site1 12名・Site2 30名、Site2で2名除外。EEG/EMG記録4名、結果図の例は3名。 |
| 課題 | 音あり／同運動の音なし、1回約30分の反復訓練。 |
| 計測・装置 | Site1：Xsens上腕・手首、Site2：Leap Motion。探索EEGは日本光電20ch、EMG、200 Hz。 |
| FB・情報提示 | 手の上下位置を音階、他軸を音色・音量へ。 |
| 評価時点・指標 | 前後の臨床検査・滑らかさ。小部分でβ帯EEG–EMG位相結合。 |

## 結果と限界

臨床検査に音の追加効果を支持する証拠なし。滑らかさの小効果や電気生理の探索所見を報告。

Site1は交互割付、Site2は擬似無作為。装置・施設差が滑らかさを変える。EEG小標本から機序を確定できない。

## 本研究への示唆

肯定的な先行L11だけで背景を構成しない。脳波は探索として別扱いにする好例だが、20ch＋EMGの解析を簡易1chへ移さない。
