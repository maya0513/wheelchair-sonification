## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 9課題のWheelchair Circuitの信頼性を検討。 |
| 対象・人数 | 入院リハビリテーション最終期のSCI27名。 |
| 課題 | 8の字、段差、台、スプリント、歩行、3%・6%傾斜、車いす駆動、移乗。 |
| 装置・計測 | 課題時間・可否・ピーク心拍。機器の詳細は抄録で未確認。 |
| フィードバック | 訓練介入なし。 |
| 評価時点・指標 | 3回の試行と2評価者による評価者内・間信頼性。 |

## 結果と限界

時間ICCは評価者内.70–.99、間.76–.98。実施可能課題数は3–9。

抄録確認。対象はSCI、複合サーキットであり、5 m・1周8の字だけの測定特性ではない。

## 本研究への示唆

可否だけでなく時間を評価する背景。必要な設備・課題・負担から全サーキットは採らない。
