## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 脳卒中上肢に対するリズム刺激とリアルタイム聴覚FBの系統的レビュー・メタ解析。 |
| 対象 | 23研究、患者585名。 |
| 課題 | 上肢機能回復の訓練。 |
| 計測・装置 | 研究ごとに異なる。 |
| FB・情報提示 | リズムによるcueingと動作依存のsonificationを扱う。 |
| 評価時点・指標 | FMA、SIS、可動域、Wolf Motor Function Test等。 |

## 結果と限界

FMA等に統合した有益な効果。FMAのHedges gは全体0.79、リアルタイム群の集計は1.3、リズム群0.6と報告。

抄録中心。介入・期間・対象の異質性があり、群別の統合値は直接ランダム化したモダリティ比較ではない。

## 本研究への示唆

背景の可能性を支える資料。卒研の効果量・必要人数の直接の根拠に転用しない。
