# L60｜日本語版NASA-TLXによるメンタルワークロード測定：各種室内実験課題の困難度に対するワークロード得点の感度

## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 日本語版TLXの課題難度への感度と、一対比較を省く簡便法を検討。 |
| 対象・人数 | 22–31歳の男女12名。 |
| 課題 | 視覚探索・暗算・トラッキングを別日実施。各課題3難度。 |
| 装置・計測 | PC課題、6尺度の評定、一対比較。 |
| フィードバック | 車いすFBではない。各課題の通常の反応表示・音等。 |
| 評価時点・指標 | 各難度の課題後にTLXと全体負荷を評定。 |

## 結果と限界

難度に対する感度を確認し、重み付きWWLと簡便法の関係を検討。

室内認知課題。運動を伴う車いす課題や、独自の短い説明文の妥当性を直接保証しない。

## 本研究への示唆

日本語の尺度名・意味と採点の方向を照合する。今回は6下位尺度を個別報告し、重み付け得点や勝手な総合得点を標準TLXと呼ばない。
