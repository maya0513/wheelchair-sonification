## 方法と結果

| 項目 | 原著の報告 |
|---|---|
| 目的 | 車輪IMUで推定する推進の時空間指標を、光学式モーションキャプチャと比較する。FBによる学習の研究ではない |
| 対象 | 車いす利用者27名、女性2名・男性25名。各人の車いすを使用 |
| 課題 | 車いすを固定台へ固定。普通・速い・遅いの自己選択3速度で各10周期。実空間を移動する走行ではない |
| 比較基準 | VICON 10カメラ、200 Hz。車輪軸とスポークへマーカーを取り付け、車輪角度・角加速度を計算 |
| 比較対象 | 車輪スポークのCometa IMU、142 Hz。**手首IMUは使用していない** |
| 推進区間 | 光学系は車輪角加速度のゼロ交差、IMUは車輪角速度の極小・極大から開始・終了を推定。力・接触圧の直接検出ではない |
| 処理 | 6 Hzの2次Butterworthフィルタ、Pythonによる処理。オンライン提示の遅延・動作は検証していない |
| 推進角 | Table 3で光学系66.25±24.91°、IMU64.50±22.74°。光学系−IMUのBias±SDは1.75±4.14°、相関ρ=.992 |
| 接触・離手時刻 | 両者のBias±SDはそれぞれ−0.02±0.02秒、−0.02±0.01秒 |
| 学習・FB | 介入、保持、転移の評価なし |

## 読み取りの注意

1. 比較した2系統はともに車輪の回転変化から推進区間を推定している。光学系との一致を、力による推進相や皮膚とリムの接触を直接測った正解との一致とみなさない。
2. 1.75±4.14°は**差の平均と標準偏差**。角度MAE、全プッシュの最大誤差、±5°以内に収まる保証ではない。Figure 3の横軸は10周期にわたる平均を示し、単一プッシュを即時分類する性能へ読み替えない。
3. 固定台では実走行に伴う車体・体幹運動の影響が異なる。Discussionでは、実走行での車輪IMUとSMARTWheelの比較で推進時間に差が出た先行研究にも触れている。今回の屋外・キャンバー車・VIVEへの精度の転用はできない。
4. 車輪センサーだけでの推定には先例があるが、削除した旧接触角案の「手首の位置・車輪との相対運動」方式を検証した研究ではない。

## 本研究への示唆

車輪回転から推進区間と角度を推定する代替案の具体例として有用。今回は接触角を評価に採用せず、車輪速度を返す。先行研究の誤差を手元の装置の性能へ転用せず、角度案を将来再検討する場合も実測精度・比較基準・オンライン処理を確認する。[計測可能性の整理](../topics/propulsion-angle-measurement-feasibility.md)
