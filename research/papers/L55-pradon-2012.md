# L55｜Could mobilty performance measures be used to evaluate wheelchair skills?

Journal of Rehabilitation Medicine 44, 276–279。調査・照合日：2026-10-14。

- 出典：[10.2340/16501977-0919](https://www.medicaljournals.se/jrm/content/html/10.2340/16501977-0919)
- 閲覧範囲：**本文重点確認**。
- 本文：[保存PDF](../pdfs/L55.pdf)。版・条件は[PDF一覧](../pdfs/INDEX.md)。

## 研究の要約

| 項目 | 内容 |
|---|---|
| 目的・デザイン | 速度・スラローム時間とWSTの関係、測定信頼性を調べる。 |
| 対象・人数 | 脊髄損傷者40名。再テスト18名、評価者間8名。 |
| 課題 | 20 m直進（最初の12 mを計時）、10 m往復スラローム（ブロック間1 m）。スラロームは接触・通過失敗1件につき10秒加点。 |
| 装置・計測 | 普段の車いす、計時。 |
| フィードバック | 訓練介入なし。 |
| 評価時点・指標 | WST3.2との相関、1週間後再テスト、同日の評価者間。 |

## 結果と限界

最大速度・スラローム時間はWSTと関連。スラロームの再テストICC .88、評価者間 .95。WST高得点層では関係が弱い。

SCI集団での結果。高能力者での識別・部分標本の小ささ。初心者の一回訓練の反応性を証明していない。

## 本研究への示唆

時間・誤りを含む操作評価の先例。独自加点は導入しない。本研究は8の字時間を主要評価とし、接触等は把握した場合の備考に残す。10 mスラロームは比較候補で、今回追加しない。
