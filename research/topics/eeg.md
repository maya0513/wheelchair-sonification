# 簡易EEGの品質と解釈

本研究の測定には組み込まない、将来検討用の文献レビュー。機器確認と分析の案は[補助EEGの検討案](../../docs/archive/exploratory-eeg.md)を参照する。

## 型番でできることが変わる

[L46](../papers/L46-lee-2026.md)の比較では1ch前額機、2ch前額機、Muse2の4ch等を扱う。[L34](../papers/L34-krigolson-2017.md)の初期Museは研究用500 Hz設定で、現在のMuse2の256 Hzとは異なる。[D07](../papers/D07-brainflow-boards.md)。小型・装着可能という情報だけでは、取得品質・生波形・参照電極・時刻・解析の範囲が決まらない。

| 欲しい評価 | 必要条件・制約 |
|---|---|
| 安静のαと開閉眼 | 生波形、電極位置、参照、単位。前額のみでは見えにくい人もいる |
| 訓練区間のPSD | 動作中の有効データと時刻合わせ。除外率も結果 |
| 前頭正中θ | Fz/FCz等の位置に関する根拠が必要。Fp1の単一電極と同じとはしない [L43](../papers/L43-cavanagh-2014.md) |
| 運動野μ/β ERD | 運動野の電極、時刻精度、反復試行等が必要 |
| ERP | 刺激・取得の時刻精度と十分な有効試行。将来の最小追加案にも含めない |
| 脳・筋の結合 | EEGに加えEMG、多電極等。[L49](../papers/L49-nikmaram-2019.md)の20ch＋EMG解析を小型機へ移さない |

## 肯定的研究と制約を併読する

[L34](../papers/L34-krigolson-2017.md) [L35](../papers/L35-badcock-2013.md)は簡易機器でERPを得る可能性を示すが、主に座位・特定の電極・特定の取得経路での検証。[L41](../papers/L41-ratti-2017.md)には機器間の差、[L42](../papers/L42-kam-2019.md)には良好な一致があり、乾式／消費者向けという名称だけでは品質を決められない。

[L46](../papers/L46-lee-2026.md)の動作頑健性は主に動作前後の安静PSDの比較であり、推進中の有効性を直接保証しない。[L37](../papers/L37-kline-2015.md)は動作ノイズが脳活動らしい周期変化を作り、頭部加速度だけでは説明しきれないことを示す。[L40](../papers/L40-yang-2023.md)では3chのASRにも制約がある。フィルタを増やして「きれいにした」ことを妥当性の証明にしない。

## 認知負荷の解釈

[L39](../papers/L39-bilalpur-2018.md)は音の対応付けの負荷をEEGと主観で探索しているが、運動中の車いす研究ではない。αやθは視覚入力、運動、瞬目、筋活動、疲労等でも変わる。[L38](../papers/L38-muthukumaraswamy-2013.md) [L43](../papers/L43-cavanagh-2014.md)。聴覚群と視覚群でEEGが違っても、そのまま認知負荷の差とは言えない。

将来分析に用いる場合も、主観負荷、速度、動作量を合わせて解釈する。
