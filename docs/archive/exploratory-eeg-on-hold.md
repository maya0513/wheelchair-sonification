# 脳波を補助評価として追加する最小案

## 研究上の役割

主目的は車いす推進のFB比較。EEGは「簡易機器をこの課題で記録できるか」と「訓練区間に伴うスペクトルの探索的変化」を補足する。EEGが取れなくても運動データの研究は成立させる。脳波を使った車いす制御・新しいBCI・神経フィードバックは今回の研究目的に追加しない。

音FBとEEGを直接結ぶ[L39](../../research/papers/L39-bilalpur-2018.md)、上肢音化＋探索EEG/EMGの[L49](../../research/papers/L49-nikmaram-2019.md)を参考にする。ただし後者は20ch＋EMG・ごく少数の探索例。単純な1chの記録で同じ結合解析を再現する案にはしない。

## 実物で確認する最少項目

| 項目 | 必要な情報 |
|---|---|
| 製品 | 正式型番、ファームウェア、重量、電池、装着方法 |
| 電極 | 位置・ch数、基準・接地、dry/wet、接触品質の出力 |
| データ | 生波形、単位・ADC換算、実効標本化、内部フィルタ、飽和値 |
| 接続 | SDK、OS、保存形式、ライセンス・生データの取得条件 |
| 時刻 | 機器時刻、連番、受信時刻、遅延、再接続・パケット欠落 |
| 併用 | ゴーグルや髪との干渉、頭・顎の動きによる接触変化 |

[L34](../../research/papers/L34-krigolson-2017.md) [L41](../../research/papers/L41-ratti-2017.md) [L46](../../research/papers/L46-lee-2026.md) [D07](../../research/papers/D07-brainflow-boards.md)。研究で報告された旧機種の周波数・単位換算を、実物にそのまま適用しない。

## 取得できるデータによる分岐

| 条件 | 採用する範囲 |
|---|---|
| 生波形＋時刻＋単位が取得可能 | 品質評価、区間PSD。電極の範囲に合う帯域を探索 |
| 生波形はあるが詳細な同期が難しい | 数十秒以上の区間のPSDと品質。ERPやストローク位相解析を行わない |
| メーカーの集中度等だけ | 製品独自指標として探索的に保存。EEG帯域・認知負荷の測定値と呼ばない |
| 動作中品質が不足 | 開閉眼・安静と取得失敗率を報告。運動中の帯域差を解釈しない |

前額1–2chでは前頭正中や運動野を測ったとみなさず、全脳マップ・μ ERD・脳間／脳筋結合を主張しない。少数chのICA/ASRを必須の解決法にしない。[L37](../../research/papers/L37-kline-2015.md) [L38](../../research/papers/L38-muthukumaraswamy-2013.md) [L40](../../research/papers/L40-yang-2023.md) [L43](../../research/papers/L43-cavanagh-2014.md)

## 本計測前の約5分の機器検証

座位開眼60秒、閉眼60秒、瞬目15秒、軽い顎の動き15秒、ゆっくり頭を動かす15秒、短い推進60秒、座位回復30秒を記録し、状態をイベントとして残す。説明を含め約5分。痛みを誘発する動作や強い顎収縮は課さない。

開閉眼は信号の生理的反応を見る検証、瞬目・顎・頭の動きは**ノイズの見本**。動作前後に安静PSDが似ていても、動作中の品質の証明にはならない。[L46](../../research/papers/L46-lee-2026.md)。前額で明瞭なαが見えないだけで装置故障・参加者異常とは決めない。

この長めの検証は予備実験で行い、本参加者の装着枠では開閉眼各60秒と品質確認を中心に短縮する。装着・確認が10分枠を超えそうならEEGを中止し、主課題を優先する。

## 記録と同期

可能ならUnityのphase/trial/FBイベントとEEGをLSLへ送りLabRecorderでXDF保存。対応しない機器では、機器の生ファイルとPC受信時刻を保存し、区間マーカーを共通PCで記録する。[L45](../../research/papers/L45-kothe-2025.md) [D05](../../research/papers/D05-lsl-time.md)

開始・終了の共通イベントでずれとドリフトを確認する。LSLの時計補正後も、取得装置内部・Bluetooth・音出力の遅れは別。身体に接続するEEG電極へ自作信号を注入する方式は採用しない。同期不十分なら区間レベルの比較へ限定する。

## 最小オフライン解析

1. 生波形・スペクトル・連番・接触品質を確認し、元データを保存する。VとµV、PSDのV²/HzとµV²/Hzを混同しない。
2. 状態と不良区間を注釈として残す。接続断・飽和・flatline・大きな動作ノイズを対象とし、除外理由を保存。可能な範囲で群名を隠して判定する。[D06](../../research/papers/D06-mne-psd.md)
3. 128 Hz以上が取得でき、内部フィルタと単位が分かる場合の初期案は1–30 Hzの解析帯域。50/60 Hzのnotchは必要性と取得条件を確認して使用し、低域化すれば筋ノイズが消えたとはしない。[L38](../../research/papers/L38-muthukumaraswamy-2013.md)
4. 2秒窓、50%重複、Hamming窓のWelch PSD。θ4–7 Hz、α8–13 Hzを事前定義した探索帯域とし、β13–30 Hzは筋混入の注意を添えた追加項目。[D06](../../research/papers/D06-mne-psd.md)
5. 連続データを非重複2秒epochに分けて品質判定し、有効な連続部分でPSDを計算。確認した単位がµVなら、初期候補はpeak-to-peak150 µV超・flatline・機器の不良フラグを除外対象とする。ただし150 µVは装置未確認の仮閾値で、予備実験で飽和値・波形を見て固定する。
6. 各phaseで有効データ60秒以上・取得区間の50%以上を探索PSDの条件とする。足りなければPSD比較は欠測。良い窓だけを多く取れた群が有利になる偏りも確認する。
7. 参加者ごと・区間ごとに帯域パワーを集約する。対数パワーと同一人の開眼安静との差を主に示す。短時間の前額信号で相対帯域比やθ/αを「認知負荷スコア」と断定しない。

これらは運用上の初期解析案であり、機器固有の妥当性を確認する前に固定値を押し付けない。標本化が低い・内部処理しか出ない・単位不明なら適用範囲を縮める。ソフト・閾値・参照・フィルタを報告する。[L47](../../research/papers/L47-pernet-2019.md) [D06](../../research/papers/D06-mne-psd.md)

## 結果に最低限入れるもの

- 製品・電極・参照・標本化・内部フィルタ、取得経路。
- 参加者・群・phase別の取得時間、有効時間、有効率、除外理由。
- 開閉眼・瞬目・顎・頭部動作・推進の代表波形とPSD。都合のよい波形だけを選ばない。
- 参加者ごとの帯域パワー、主観負荷の下位尺度、速度・プッシュ頻度・動作量。

統計の単位は参加者で、2秒窓を独立した人数として検定しない。15人から負荷分類AIを学習させることを必須項目にしない。探索する帯域・区間を先に決め、EEGの全ての組合せから有意差だけを拾わない。

視覚刺激自体のα変化、音刺激の誘発反応、疲労や運動量も群差になりうる。群差が出ても「聴覚で認知負荷が低下した」と単独で結論せず、条件と複数指標を併記する。品質不足でも「小型EEGを推進中に取得する際の実現性と制約」という補足結果を残す。
