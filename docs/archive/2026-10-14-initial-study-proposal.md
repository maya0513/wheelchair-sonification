# 研究計画のブラッシュアップ案

## 推奨する問いと位置づけ

仮題：**車いす推進動作の獲得と同日内保持に対する即時聴覚フィードバックの効果：初心者を対象とした小規模3群探索研究**。

「追加FBによって目標への再現精度が変わり、FBを外した同日内の評価にも残るか」を問う。主眼は15人で比較条件と計測を成立させ、効果の方向と不確実性を示すこと。十分な検出力を持つ確証RCT、長期定着、傷害予防、神経機序の証明とは位置づけない。[L03](../../research/papers/L03-kantak-2012.md) [L48](../../research/papers/L48-lakens-2022.md)

最小案は[装置案](2026-10-14-initial-system-proposal.md)の**区間完了後の即時要約FB**。原案の並行・連続FBから提示時点を変更する理由は、接触角が終了後に確定すること、視覚条件と情報を揃えられること、古いHMDの視界やEEGとの干渉を必須にしないこと。走行中提示へ変更する場合は、本計測前に方式・表題・仮説を固定し直す。

## 対象・割付・共通条件

- 車いす未経験の学生等15名を、聴覚・視覚・追加FBなしの並行3群へ各5名。参加経験、利き手、体格、運動習慣、上肢の状態を記録する。
- 3名単位の置換ブロックで群数を均等にし、乱数種・割付順序を保存。事前計測終了後に条件を開示する。事前成績を見て都合よく入れ替えない。
- いずれも同じ基本教示、同じ目標、同じ椅子設定・課題・練習時間・待ち時間。無FB群にも教示と練習を与える。[L19](../../research/papers/L19-rice-2013.md)
- 音・表示の理解確認は動作を伴わない模擬データで行う。指導者の声かけを定型化する。
- 施設の研究倫理手続きと同意を本計測前に確認。無理な可動範囲や速度を要求せず、痛み・強い疲労があれば中止とする。

主要側は利き手側に統一。4点が取得できれば反対側も副次として保存する。全員で同じ機材構成にする。データの動画採点では可能な範囲で群名を隠す。

## 課題と主要評価

**直進課題を訓練と主要評価に使う。**実測した安定追跡範囲内の平坦な直線を共通距離に固定する。仮コースは4–6 mから検討し、20 mを必須にしない。停止・折返し・制動は主要角度から分離し、複数の直進を1区間として主要側の有効ストロークを最低3回確保する。各評価は同じ本数・同じ領域で2反復を行い、必要数は予備実験で確定・固定する。

同一人の快適な事前速度を基準とし、全群同じ速度指示を使う。各区間の速度、時間、回数も記録。短い距離では加減速の影響を受けるため、定常長距離の臨床推奨値を無条件に適用しない。[L17](../../research/papers/L17-symonds-sensewheel-2016.md) [L30](../../research/papers/L30-gorce-2012.md)

| 区分 | 指標・時点 |
|---|---|
| 主要指標 | 休憩後・無FBの推定接触角の目標からの平均絶対誤差[deg]。参加者ごとに2反復を同じ重みで集約 |
| 主要比較 | 事前接触角を考慮した3群差。音−無FB、音−視覚の方向と区間を示す |
| 副次 | 無FB直後の誤差、実際の角度、頻度、速度、区間時間、訓練中の推移、データ有効率 |
| 補助 | NASA-TLX下位尺度、快適性・理解、EEGの探索値と有効率 |
| 転移 | 最後に未練習の簡単なジグザグを少数回。完了時間と接触・コース誤りを別評価 |

目標・音・視覚の対応は[装置案](2026-10-14-initial-system-proposal.md)に明記。主要側で各反復の有効ストロークが3回に満たないときは、事前規定した追加反復を1回だけ許す。それでも不足した評価は欠測とし、除外理由を記録する。

元の「ジグザグ・8の字・ボール8の字」を全部訓練する案から、主課題と転移を分ける。ボール保持は手の使い方まで変えるので最小案から外す。転移課題中の左右対称性を成功指標にしない。[L31](../../research/papers/L31-soltau-2015.md)

## 1回来訪90分の暫定プロトコル

| 経過 | 内容 |
|---|---|
| 0–8分 | 説明・同意・状態確認・車いす設定 |
| 8–18分 | センサー装着・校正、EEGの短い開閉眼／品質確認 |
| 18–23分 | 共通の習熟、追加FBなし |
| 23–28分 | 無FB事前、2反復 |
| 28–33分 | 目標の説明、割付開示、音／表示の模擬理解確認 |
| 33–49分 | 訓練4分×3ブロック、間に2分休憩×2 |
| 49–54分 | 無FB直後、2反復・短い主観評価 |
| 54–74分 | 座位休憩20分。追加の車いす練習・動作FBを与えない |
| 74–79分 | 無FB短時間保持、2反復 |
| 79–84分 | 未練習課題への小規模な転移評価 |
| 84–90分 | 取り外し・体調確認・説明 |

訓練終了から短時間保持開始までは、この案で約25分。**20分は休憩時間であり、訓練からの遅延ではない。**実測の時刻を報告する。休憩中の質問紙は冒頭の短時間に揃え、EEG解析の安静区間と分ける。装着が長引く場合はEEG追加を短縮・中止して90分を守る。

予備参加者2–3名で90分の通し実行を確認し、本標本には含めない。主課題の計測時間・反復数・コースを変更した場合は、本計測開始前に凍結する。

## 分析と解釈

参加者が独立した単位。多数のストロークやEEG窓をNに数えない。反復ごとに誤差を算出し、参加者内で集約する。事前、直後、休憩後の個人値を線で結び、群平均・散らばりを併記する。

主要モデルは `休憩後の目標絶対誤差 ~ 群 + 事前接触角` の小さいANCOVA。個人目標を事前角度から作るため、事前の目標誤差はほぼ一定になり得る。そこで共変量は目標算定に使った事前接触角の原値とする。共変量が完全に一定なら群のみのモデルへ落とす。推定した調整群差と95%モデル区間を示す。完全な15名データが得られる場合、主たる群効果のF統計量を3名ブロック内の全6^5=7,776通りの割付で評価する探索的ランダム化検定を併記できる。検定結果に合わせてモデルや主要指標を選び直さない。

5名ずつではモデル区間も分布仮定に敏感で、効果推定は不安定。非有意を「効果なし」「同等」と解釈せず、個人差と区間幅を中心に記述する。[L48](../../research/papers/L48-lakens-2022.md)。事後速度の調整は介入効果の一部を除く可能性があるため主モデルへ自動投入せず、速度差を示し、行うなら別の感度分析と明記する。

主要評価の欠測は理由と群別人数を示す。穴埋め・都合のよい反復選択をせず、欠測が出た場合の主報告は記述的な群差と個人データに留める。完全データの割付検定をそのまま流用しない。EEG欠測だけでは運動の主解析から除かない。

## 卒論で言えることの書き方

「本装置・本課題・初心者の小標本で、追加FBの形式に伴う目標再現精度と同日内の変化を探索した」と記す。長期保持が未測定であること、位置由来の接触推定であること、力・代謝・傷害を測っていないこと、日常利用者への一般化が未確認であることを具体的に残す。[L03](../../research/papers/L03-kantak-2012.md) [L14](../../research/papers/L14-yan-2021.md) [L17](../../research/papers/L17-symonds-sensewheel-2016.md)
