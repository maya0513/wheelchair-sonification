# 実験手順

本実験中の被験者はメニュー・コントローラー・保存操作を行わない。実施者の事前準備にはゴーグルの案内付きチェックを使える。実施者がPCで時点・課題・反復を選び、ゴーグルが計測・FB・保存を行う。実施者は基本1名を想定し、実際に監視とPC操作を両立できるかを現地で確認する。[運営と開始条件](operations/study-operations.md)

## 実施前

同一のスポーツ用車いす、クッション、タイヤ条件を使い、フットサポートを体格へ合わせて記録する。平坦・乾燥した走路と停止余裕を確保する。会場はフットサルコート程度を想定するが、実寸・照度・床・追跡・通信は現地確認。直射日光を避け、屋外で成立しなければ会場を見直す。

実施者がPCホットスポットとゴーグルを接続し、装着前に承認する。5台の役割、左右車輪軸、保存容量、音量、実空間視認を確認する。手首は記録だけで、リムへ手を添える校正は行わない。参加者ごとにHMD標準の眼球校正を行い、実施者がPCへ確認を記録する。静止・正面の座位で車体に対する表示位置を合わせる。[操作](operations/console.md)・[機器](operations/setup.md)

同意・適格性確認後、共通習熟と無FB事前評価を行う。左右と速さの[短い理解確認](operations/participant-materials.md)を全員に行い、割付表から群を登録する。プログラムは合否や進行を強制しない。

## 評価共通の開始姿勢

最初のキャスターを開始線に合わせて静止し、両手はハンドリム最上部へ軽く添え、開始音前に押さない。無理なく添えられない場合は位置を個人ごとに記録し、事前・直後の全評価で揃える。これは反応時間を含む本研究の計時のための標準化で、引用原著の開始姿勢を再現したという意味ではない。

## 8の字1周

コーン2本を5 m間隔に置き、中点を通り両コーンを結ぶ線に直交する開始終了線を引く。周囲と通過後の停止方向に最低2 mの障害物のない余裕を置く。PCは走路外の、開始終了線と両コーンを見渡せる位置に設置する。

```text
      左コーン C1 ──2.5 m── S ──2.5 m── C2 右コーン
                           │
                        開始終了線
```

1. 上記の共通姿勢で、左コーンへ向かう同じ向きに静止する。
2. PCの記録開始後、3秒の準備音と開始音を待つ。実施者は開始前に安全を確認する。
3. 左コーンを反時計回り、右コーンを時計回りに回り、8の字を1周する。途中の中点通過はゴールにしない。
4. 両方を回った後、最初のキャスターが線を通過した時点で実施者が計時終了を押す。通過後に減速・停止し、記録を終了する。
5. 位置戻し・原則30秒の休憩を挟み2反復。2周連続の合計時間にはしない。

読み上げる文は[8の字の共通教示](operations/participant-materials.md#8の字評価)を使う。

[亀ヶ谷2021](../research/papers/L53-kamegaya-2021.md)を基にするが、開始音基準・車体・反復等を変更している。[時間の意味](specifications/measurement.md)

## 10 m直進

10 mの開始終了線、幅1.5 mの走路、前後最低2 mの準備・停止域を設ける。上記の共通姿勢から開始音で出発し、最初のキャスターの終了線通過でPC計時を終了する。その先で安全停止する。同じ方向で2反復し、位置戻し・原則30秒休憩を挟む。

読み上げる文は[直進の共通教示](operations/participant-materials.md#直進評価)を使う。

[WPT](../research/papers/L54-askari-2013.md)を参考にした研究用課題で、開始音基準や装着条件は異なる。全10 mを記録する。

## 30分の配分

会場設営、接続、トラッカー登録・車輪軸の校正、自由走行による機能確認は実施者が参加者の来訪前に済ませる。以下の30分には説明・同意、参加者固有の装着・眼球校正、終了操作を含む。保持評価と、そのための20分休憩・再装着は設けない。

| 経過 | 内容 |
|---|---|
| 0–3分 | 説明・同意・適格性・体調 |
| 3–6分 | 椅子適合、手首2台とHMDの装着、視界・音量・眼球校正・表示位置確認 |
| 6–8分 | 共通習熟：直進1回・8の字1回、停止・方向転換。追加FBなし |
| 8–12分 | 事前評価：8の字2回→直進2回、追加FBなし |
| 12–14分 | 音と表示の理解確認、割付開示 |
| 14–21分 | 訓練2セット。実動4分、切替・休憩3分。訓練中だけ割付FB |
| 21–25分 | 無FB直後評価：8の字2回→直進2回 |
| 25–28分 | 質問紙、取り外し、体調確認 |
| 28–30分 | 保存・回収確認と予備時間 |

訓練1セットは直進1分→切替30秒→8の字1分→終了・移動30秒の3分。これを2セット行い、間に1分の座位休憩を挟む。直進は往復、8の字は快適な安全速度で繰り返し、両課題でFBを出す。休憩中は記録を終了し、FB・視線保存を止める。HMDは着けたままを基本とし、不快があれば外す。

1分はPCの目安表示。実施者が新しい走行を始めないよう指示し「訓練終了」でFBを止め、安全停止後「記録終了」。実動時間・はみ出し・実施本数を残す。時計による自動進行・強制終了は行わない。直後評価までの実際の間隔も残す。

保持や持続的な学習は測定しない。訓練の実動4分は時間制約に合わせた設定で、効果が得られると先行研究が保証した量ではない。予備実験で装着と全反復を含む30分の成立性を確認する。

## 中止・再試行

痛み・めまい・強い疲労・参加者の希望・実空間を確認できない状況では中止する。実施者の停止指示を共通習熟で練習する。接触や経路の問題は把握した場合に備考へ残す。動画は要求しない。

技術的不成立の再試行は各評価時点で追加1試行までを基本とし、元試行・置換先・理由を記録する。遅い成績、接触、目標未達を理由にやり直さない。アプリは再試行上限や次の課題を強制せず、実施者が手順表で判断する。

全群・全時点の記録中に探索用の視線を保存し、欠測だけで試行を中断しない。[記録形式](specifications/recording.md)

未完了や計時失敗へ0秒・60秒・平均値を入れない。トラッカー欠測と手動時間の成立は分ける。説明・同意、安全確認、本人に必要な休憩を時間のために省かない。30分に収まらない場合は安全に終了して未完了と理由を記録し、反復や訓練量を参加者ごとに黙って変えない。予備実験で収まらなければ、本計測前に計画を再検討する。
