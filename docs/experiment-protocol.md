# 実験手順書

当日の設営、教示、進行、再試行と中止の手順をまとめる。参加条件と割付は[実施運営](operations/study-operations.md)、計時と採点は[計測・採点の定義](specifications/measurement.md)、提示の動作は[フィードバック仕様](specifications/feedback.md)で確認する。

## 実施前の確認

[開始条件](operations/study-operations.md#本計測開始条件)と当日の担当を確認する。同意・適格性の確認後に習熟と事前評価を行い、個人目標と模擬提示の理解を確認してから割付を開示する。

事前直進のデータが[基準角の必要量](specifications/feedback.md#個人目標と3状態)を満たさなければ、割付へ進まない。正常計測で本数が少ない場合は追加走行せず、基準量不足として記録する。理解確認の進め方は[参加者用資料](operations/participant-materials.md#説明と理解確認)に従う。

## 操作の担当

被験者に課題選択、群設定、校正ボタン、数値入力、開始・終了・保存を行わせない。実施者がPCのブラウザーで進行し、プログラムが順序・反復・計時・算定・保存を管理する[操作設計](specifications/operation-flow.md)へ変更する。被験者は口頭の説明に従って走行し、理解確認・体調・質問紙に回答する。

[PCコンソール](development/experiment-console.md)で進める。研究用の実測性能と現地での成立性は[開始条件](operations/study-operations.md#本計測開始条件)に従って別途確認する。

## 会場・機器・共通設定

- 平坦・乾燥・非滑走の同一床面を使う。屋外を第一候補とし、直射日光・低照度での制限、床材、傾き、実空間視認性を現地で確認して記録する。成立しなければ屋外で本計測を進めない。[現地条件](operations/study-operations.md#会場・機器・安全)
- 同じ車いす・クッション・タイヤ条件を使う。フットサポートを体格へ合わせ、設定を記録して来訪中は維持する。足で床を蹴らず、上肢で駆動する。
- 主要側は利き手側。両利きは本人が普段よく使う側を事前に申告する。実験後に成績のよい側へ変えない。左右の手首・車輪と車体の5台を使い、両側の元データを保存する。評価・FBの主要側の定義は変えない。
- 同じ提示機器・トラッカーを全群・全時点で装着する。視覚条件だけ特別な機器を付ける構成は採用しない。
- 実験者1名、安全補助者1名の2名体制を準備する。動画の計時・エラー採点では群情報を伏せる。2名を確保できない場合は開始条件を満たす体制を再検討する。
- コース全体を映す固定動画を使う。開始終了線・コーン・キャスターが見える位置を選び、原則60 fps。側方の角度検証動画が別途必要な場合も、撮影範囲・音声の同意を得る。

## 主要課題：8の字1周

[亀ヶ谷ら2021の方法・図1（原著pp.190–191）](../research/papers/L53-kamegaya-2021.md)を基本にする。5 m間隔のコーン2本、その中点を通る開始終了線を設置する。

```text
                       上から見た模式図
                  左側の輪          右側の輪
                 ／      ＼        ／      ＼
               （   C1     ＼  S  ／    C2   ）
                 ＼      ／  │  ＼      ／
                    ────     │     ────
                     2.5 m ← S → 2.5 m
                            開始終了線
               C1中心とC2中心の距離：5.0 m
```

曲線は進路の説明であり、指定半径や固定された最適軌道ではない。線幅は約20 mm、コーンは同一の柔らかい製品とし、高さ・底面寸法を実測記録する（原著にはこの仕様の詳細記載なし）。周囲とゴール通過後の停止方向に少なくとも2 mの障害物のない余裕を設ける。

1. キャスターを開始線上に置いて静止する。毎回、左側コーンへ向かう同じ向きに合わせ、キャスターを進行方向へ整える。具体的な開始向きを設営写真へ残す。
2. 殿部を座面奥へ置き、足をフットサポートへ載せる。測定中は背部をバックサポートから大きく離さない。強制固定や可動域の限界を要求しない。
3. 左側コーンを反時計回り、続いて右側コーンを時計回りに回る同じ順序で、8の字を1周する。途中の中点通過（片側の輪のみ終了）はゴールにしない。
4. キャスターが開始線を離れた時点から、両コーンを回り終えて最初のキャスターが終了線を通過する時点まで計時する。反応時間は含めない。
5. 終了線直前で止まらず通過し、その先の指定した安全な余裕で減速して停止する。接触・経路誤り等を記録する。
6. 2反復を行い、間に原則30秒の座位休憩・位置戻しを入れる。各反復は1周で、2周連続の合計時間にはしない。

共通教示：

> 合図の後、左、右の順にコーンを回って8の字を1周してください。安全な範囲でできるだけ速く、コーンにぶつからないように走ってください。途中で真ん中を通っても、両方を回るまでは終わりではありません。最後の線は通過してから、その先でゆっくり止まってください。

全評価で同じ文を読み、音や表示のこと、接触角を長くすることを追加で促さない。最大努力を無条件に要求する原著から、安全を優先する表現へ変更している。

## 副次課題：10 m直進

[WPT原著2013、Appendix 1（pp.1696–1697／保存PDF pp.7–8）](../research/papers/L54-askari-2013.md)の静止開始・普段の速度・10 mを参考にする。前進・両上肢駆動に限定した研究用構成であり、WPTの全採点を実施するものではない。

```text
2 mの準備域 | 開始線 ─ 2 m ─ [ 中央6 m：角度評価・訓練FB ] ─ 2 m ─ 終了線 | 2 mの停止域
                         ←──────── 計時距離10 m ────────→
                   走路幅1.5 m（WPT原著は最低1.2 m）
```

開始線直前で静止し、前輪を進行方向へ揃える。本人の準備ができたら出発する。先頭の車輪が開始線を通過してから、同じ車輪が終了線を通過するまで計時する。終点の先へ進んでから減速・停止する。2反復を同じ方向で行い、位置戻しと座位休憩を原則30秒取る。戻りの走行は評価値に含めない。

共通教示：

> 普段の無理のないこぎ方と、快適な速度で、まっすぐ終点の先まで進んでください。急いだり、線の手前で止まったりする必要はありません。

角度・プッシュ周期の解析は中央2–8 mで開始終了した有効プッシュに限定する。開始・制動の影響を減らすための本研究独自の区切りで、長距離の定常推進と同じとは仮定しない。全10 mでは時間、主要側の回数、速度を別に記録する。訓練中も同じ中央区間だけFBを出す。

原著から加えた条件と、その解釈上の注意は[設計上の判断](decisions.md#先行課題から取り入れる部分)にまとめる。

## 90分の進行

| 経過 | 実施内容 | 固定する事項 |
|---|---|---|
| 0–8分 | 説明・同意・状態確認・適格性 | 中止自由、動画、個人情報の説明 |
| 8–18分 | 椅子適合、装着、校正、快適音量、視界確認 | EEGなし。安全な実空間視認 |
| 18–23分 | 共通習熟 | 直進1回・8の字1回＋安全な停止・方向転換。追加FBなし |
| 23–28分 | 無FB事前評価 | 8の字2反復→直進2反復 |
| 28–33分 | 個人目標・模擬理解確認・割付開示 | 全員が両モダリティを非運動で理解確認 |
| 33–52分 | 訓練3セット | 実動12分、切替3分、セット間休憩4分 |
| 52–57分 | 無FB直後評価・短い質問紙 | 同じ課題順。訓練を振り返る補助評価 |
| 57–77分 | 座位休憩20分 | 追加練習・FB・動作教示なし |
| 77–82分 | 無FB短時間保持評価 | 同じ課題順・2反復 |
| 82–90分 | 取り外し、体調確認、説明 | 完遂時間・有害事象・逸脱を記録 |

全評価は8の字を先に測る。主要評価を先に置き、直進テストの追加練習が主要評価へ直前に影響することを抑える。事前角度の算定は直進から行うが、主要評価時点は8の字で統一する。

訓練1セットは「直進2分→切替30秒→8の字2分→終了・移動30秒」。セット間の2分休憩を2回挟む。直進は同じコースを往復するが、折返し・整列中はFBを出さない。8の字は快適な安全速度で繰返し、各周回で止まることは求めない。評価時だけ1周ごとの時間を測る。

2分終了時には次の走行・周回を開始せず、その場で急制動せず安全に終了する。FBは2分の窓で終了し、安全停止まで元データを記録する。はみ出し時間、実動時間、完了本数を記録し、切替30秒内で処理する。10秒準備・位置戻し・安全停止を含む実時間が予定枠へ収まるかも予備実験で確認し、収まらないなら本計測前に構成を再評価する。速い参加者は回数が増えるので、同じ時間でも回数が等しいとは報告しない。

休憩は静かな座位で、通常の姿勢変更・水分補給を認める。車いす技能の動画・説明・イメージ練習の指示を与えない。眠気・居眠り、会話、休憩中断を記録する。20分は訓練からの遅延ではなく休憩の長さである。

休憩後成績には、訓練後に行った無FBの8の字2回・直進2回という課題経験も含まれる。19分訓練のみの保持・記憶固定化を分離する設計ではない。全群の予定評価量を共通にし、技術的再試行による追加量と時間は別記録する。

## 試行成立と再試行の規則

| 状況 | 扱い |
|---|---|
| 正しい経路を完了、コーンに軽く接触 | 時間を残し、接触回数を併記。接触を理由に速い・遅い試行を選別しない |
| コーンを回らない、左右順を誤る、途中で経路を失う | 経路誤りとして終了。未完了を記録し、都合のよい時間へ置換しない |
| 8の字60秒以内に未完了 | 安全に停止し時間切れ。60秒を完了時間とは記録しない |
| カメラ不動、誤った設営、校正・追跡の技術的不成立 | 各評価時点で追加1試行まで。どの反復を置換するかと理由を事前記録し、最初の成立した再試行を使用 |
| 正常計測だが直進中央区間のプッシュが少ない、または区間内に完結するプッシュがない | 本数だけを理由に再試行しない。角度・開始間隔の取得量を残し、指標ごとの集約条件に従う |
| コース接触・経路誤り・遅い成績 | 成績改善のための再試行は行わない |
| 痛み、めまい、強い疲労、機器不快、安全補助者の介入、参加者の中止希望 | 即時に安全停止。続行を求めず、中止理由と取得済みデータの使用意向を確認 |

全10 mの時間が成立していても中央区間の角度だけ欠測になりうる。8の字の動画が成立していれば、推進データ欠測だけで8の字時間を消さない。ただし訓練FBが成立しなかった区間は介入逸脱として記録する。

角度や開始間隔の有効数を[試行表](operations/record-forms.md#評価試行表)へ残す。評価指標の必要量、集約、片方の反復だけが成立した場合の扱いは[分析計画](analysis-plan.md#副次指標の計算と比較方針)に従う。基準角を決めるための必要量を、割付後の評価へ流用しない。

90分を超えそうな場合も20分休憩や無FB条件を縮めない。初期予定の取り外し8分の余裕を使い、最終90分に安全な取り外し・説明ができる時刻で残りを中止する。主要評価を優先し、保持時点の直進だけ省略した場合は理由を残す。追加の来訪を参加条件にしない。反復不足の集約規則は[分析計画](analysis-plan.md)に従う。

動画の計時・接触・完了の判定は[計測・採点の定義](specifications/measurement.md)、記録する項目は[記録様式](operations/record-forms.md)を使う。
