# 実験手順

被験者はメニュー・コントローラー・保存操作を行わない。実施者がPCで時点・課題・反復を選び、ゴーグルが計測・FB・保存を行う。実施者は基本1名を想定し、実際に監視とPC操作を両立できるかを現地で確認する。[運営と開始条件](operations/study-operations.md)

## 実施前

同一のスポーツ用車いす、クッション、タイヤ条件を使い、フットサポートを体格へ合わせて記録する。平坦・乾燥した走路と停止余裕を確保する。会場はフットサルコート程度を想定するが、実寸・照度・床・追跡・通信は現地確認。直射日光を避け、屋外で成立しなければ会場を見直す。

実施者がPCホットスポットとゴーグルを接続し、装着前に承認する。5台の役割、左右車輪軸、保存容量、音量、実空間視認を確認する。手首は記録だけで、リムへ手を添える校正は行わない。[操作](development/experiment-console.md)・[機器](development/tracker-measurement.md)

同意・適格性確認後、共通習熟と無FB事前評価を行う。左右と速さの[短い理解確認](operations/participant-materials.md)を全員に行い、割付表から群を登録する。プログラムは合否や進行を強制しない。目標角の算定は行わない。

## 評価共通の開始姿勢

最初のキャスターを開始線に合わせて静止し、両手はハンドリム最上部へ軽く添え、開始音前に押さない。無理なく添えられない場合は位置を個人ごとに記録し、事前・直後・保持の全評価で揃える。これは反応時間を含む本研究の計時のための標準化で、引用原著の開始姿勢を再現したという意味ではない。

## 8の字1周

コーン2本を5 m間隔に置き、中点を通り両コーンを結ぶ線に直交する開始終了線を引く。周囲と通過後の停止方向に最低2 mの障害物のない余裕を置く。PCは走路外の、開始終了線と両コーンを見渡せる位置に設置する。

```text
      左コーン C1 ──2.5 m── S ──2.5 m── C2 右コーン
                           │
                        開始終了線
```

1. 上記の共通姿勢で、左コーンへ向かう同じ向きに静止する。
2. PCの記録開始後、3秒の準備音と開始音を待つ。実施者は開始前に安全を確認する。
3. 左コーンを反時計回り、右コーンを時計回りに回り、8の字を1周する。途中の中点通過はゴールにしない。
4. 両方を回った後、最初のキャスターが線を通過した時点で実施者が計時終了を押す。通過後に減速・停止し、記録を終了する。
5. 位置戻し・原則30秒の休憩を挟み2反復。2周連続の合計時間にはしない。

> 開始音が鳴ったら、左、右の順にコーンを回って8の字を1周してください。安全な範囲でできるだけ速く走ってください。最後の線は通過してから、その先でゆっくり止まってください。

[亀ヶ谷2021](../research/papers/L53-kamegaya-2021.md)を基にするが、開始音基準・車体・反復等を変更している。[時間の意味](specifications/measurement.md)

## 10 m直進

10 mの開始終了線、幅1.5 mの走路、前後最低2 mの準備・停止域を設ける。上記の共通姿勢から開始音で出発し、最初のキャスターの終了線通過でPC計時を終了する。その先で安全停止する。同じ方向で2反復し、位置戻し・原則30秒休憩を挟む。

> 開始音が鳴ったら、普段の無理のないこぎ方と、快適な速度で、終点の先までまっすぐ進んでください。急いだり、線の手前で止まったりする必要はありません。

[WPT](../research/papers/L54-askari-2013.md)を参考にした研究用課題で、開始音基準や装着条件は異なる。中央2–8 mだけに限定する規則は廃止する。

## 90分の目安

| 経過 | 内容 |
|---|---|
| 0–8分 | 説明・同意・適格性・体調 |
| 8–18分 | 椅子適合、5台とHMDの装着、機器・視界・音量確認 |
| 18–23分 | 共通習熟：直進1回・8の字1回、停止・方向転換。追加FBなし |
| 23–28分 | 事前評価：8の字2回→直進2回、追加FBなし |
| 28–31分 | 音と表示の理解確認、割付開示 |
| 31–50分 | 訓練3セット、訓練中だけ割付FB |
| 50–57分 | 無FB直後評価、短い質問紙、HMD取り外し |
| 57–77分 | HMDを外した座位休憩20分 |
| 77–81分 | HMD再装着、追跡・視界・固定の確認 |
| 81–86分 | 無FB保持評価：8の字2回→直進2回 |
| 86–90分 | 取り外し、体調、保存・回収確認 |

訓練1セットは直進2分→切替30秒→8の字2分→終了・移動30秒。セット間は2分休憩を2回挟む。直進は往復、8の字は快適な安全速度で繰り返す。訓練の両課題でFBを出す。短い休憩はHMDを着けたまま。

2分はPCの目安表示。実施者が新しい走行を始めないよう指示し「訓練終了」でFBを止め、安全停止後「記録終了」。実動時間・はみ出し・実施本数を残す。時計による自動進行・強制終了は行わない。

20分休憩は取り外し後から再装着前まで。水分補給・通常の姿勢変更を認め、追加練習・技能の説明を行わない。再装着確認を休憩に含めない。訓練終了から保持評価までの実際の時間も保存する。

## 中止・再試行

痛み・めまい・強い疲労・参加者の希望・実空間を確認できない状況では中止する。実施者の停止指示を共通習熟で練習する。接触や経路の問題は把握した場合に備考へ残す。動画は要求しない。

技術的不成立の再試行は各評価時点で追加1試行までを基本とし、元試行・置換先・理由を記録する。遅い成績、接触、目標未達を理由にやり直さない。アプリは再試行上限や次の課題を強制せず、実施者が手順表で判断する。

未完了や計時失敗へ0秒・60秒・平均値を入れない。トラッカー欠測と手動時間の成立は分ける。90分内に必要な手順が収まらなければ、省いた項目と理由を残し、休憩・評価を黙って短縮しない。予備実験で時間配分を確認する。
