# 研究資料の入口

聴覚・視覚・追加FBなしの3群で、左右車輪速度を返す練習の効果を調べる。[研究計画](study-plan.md)が目的とデザインの入口で、[アプリの概要](app-overview.md)は画像で使い方を説明する。

## 研究を理解・説明する

| 内容 | 文書 |
|---|---|
| 背景、目的、デザイン、結論の範囲 | [研究計画](study-plan.md) |
| 課題、教示、30分の配分、中止・再試行 | [実験手順](experiment-protocol.md) |
| 評価指標、集約、群比較、欠測 | [分析計画](analysis-plan.md) |
| 12枚相当の発表本文とメモ | [発表資料](presentation.md) |

## 実験を準備・実施する

[導入・装着・準備](operations/setup.md) → [PC操作](operations/console.md) → [保存先と回収](operations/records.md)の順に読む。機器の準備を終えた後は[実験手順](experiment-protocol.md)で進行を管理する。

募集・安全・正式保管先・日程とG1–G6は[実施運営](operations/study-operations.md)、読み上げる教示と質問項目は[参加者への説明](operations/participant-materials.md)にまとめる。[確認状況](status.md)ではPC上の検証と実機・責任者の確認を区別する。

## 定義・数値を確認する

| 定義の正本 | 管理する内容 |
|---|---|
| [FB仕様](specifications/feedback.md) | 返す情報、速度処理、音、縦バー、提示条件 |
| [計測仕様](specifications/measurement.md) | 計時、回転速度、機器識別・校正の条件 |
| [記録形式](specifications/recording.md) | ファイル、列の意味、座標系、時計、有効性 |
| [検証計画](specifications/validation.md) | 試験方法、実機の受入れ目標、予備実験 |

操作手順や発表資料には必要な要約を置き、設定を変えるときは上の正本から更新する。実装・ビルド・画像確認は[開発資料](development/README.md)、先行研究の結果と出典は[research/](../research/README.md)、原発表の復元は[保存資料](archive/README.md)を参照する。
