# 研究資料の入口

この研究は、左右車輪の回転速度を音や表示で返し、車いす初心者の練習を支援するものです。聴覚フィードバック群、視覚フィードバック群、追加フィードバックなし群の3群（各5名、計15名）で、練習直後の成績を比べます。来訪は1回30分で、事前と直後の評価は全群ともフィードバックなしで行います。課題はコーン間の8の字走行と10 m直進で、主要な評価は直後の8の字1周時間の2反復平均です。

装置は、VIVE Focus VisionとUltimate Tracker 5台（左右車輪、車体、両手首）で車輪の回転を測り、Unity製のアプリが提示と保存を行います。実施者はノートPCのブラウザーで記録と正式な計時を操作し、参加者は本実験中にメニューやコントローラーを操作しません。

このページは研究資料全体の入口です。目的とデザインは[研究計画](1_study-plan.md)、装置と画面は[アプリの概要](app-overview.md)で説明します。定義と数値はこのページでは決めず、[仕様と定義](specifications/README.md)にある正本で管理します。
