## 現行の研究

走行中の推進動作FBが、初心者の平地での走行・旋回技能の獲得と同日内保持に及ぼす影響を調べる。15名規模を聴覚・視覚・追加FBなしの3群へ割り付け、直進と8の字を練習する。主要評価は、20分休憩後・無FBでの8の字1周の所要時間。接触・経路誤り・未完了も必ず報告する。

FBは直進中、主要側の直前のプッシュの推定接触角を「短い／目標範囲／長い」で返す。3領域ゲージと440／660／880 Hzの純音を対応させ、回復期に開始して原則300 ms提示する。個人目標は最大＋10°とし、95°へ近づくほど増分を減らし、基準95°以上では維持する。8の字中と全評価時には追加FBを出さない。独立した転移テスト・ボール課題・48時間後の再来訪・脳波測定は実施しない。

正常計測でプッシュが少ない場合の再試行を廃止し、基準角算定と副次集約の必要量を分けた。状態別の判定精度・検証量、連続した目標算定、回復期の提示開始・取消、副次指標の式と記述方針を定義した。保持前の直後評価も課題経験に含むと明記した。採用理由と変更前後は[決定台帳](decisions.md#変更管理)で確認できる。

## 確認が済むまで本計測を始めない事項

- 教員・学内の倫理手続き、責任者、同意書、募集条件、データ保管・撤回の規則。
- 会場の床面と実寸、椅子の適合、安全補助者、コース全域の安全な視認。
- 実物の機器型番・追跡範囲、推定接触角、提示時点、300 msの知覚、記録の成立性。
- 2–3名の通し予備実験、90分以内の完遂、採用仕様の凍結記録。

会場は「フットサルコート1面ほどの広さ」との申告であり、床材・屋内外・実測寸法・追跡可能範囲は未確認。元の機器名を実物の確定仕様として扱わない。脳波計は未到着であり、届いた場合も今回の計画へ自動的に追加しない。

仕様の変更は[変更記録](decisions.md#変更管理)へ記入し、影響する詳細文書と発表版を同時更新する。コード、SDK選定、センサー検出アルゴリズムの詳細は今回の確定範囲に含めない。
