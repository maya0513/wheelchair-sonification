# 実験手順

本実験中の被験者はメニュー・コントローラー・保存操作を行わない。実施者の事前準備にはゴーグルの案内付きチェックを使える。実施者がPCで時点・課題・反復を選び、ゴーグルが計測・FB・保存を行う。実施者は基本1名を想定し、実際に監視とPC操作を両立できるかを現地で確認する。[運営と開始条件](operations/study-operations.md)

この文書は、当日の進行、課題、30分の配分、中止と再試行を定める。機器の準備は[導入・装着・準備](operations/1_setup.md)、PCの操作は[実験中のPC操作](operations/3_console.md)が担い、手順全体の並びは[実験当日の手順](operations/README.md)で示す。

## 実施前

同一のスポーツ用車いす、クッション、タイヤ条件を使い、フットサポートを体格へ合わせて記録する。平坦・乾燥した走路と停止余裕を確保する。会場は実験室とし、使える範囲に合わせて課題を設定する。実寸・照度・床・追跡・通信は現地確認する。線課題の基準線とマーカーは[線課題の設計](../research/implementation/line-course.md)に従い、来訪前に機器チェックでマーカー位置を記録する。

実施者がPCホットスポットとゴーグルを接続し、装着前に承認する。5台の役割、左右車輪軸、保存容量、音量、実空間視認を確認する。手首は記録だけで、リムへ手を添える校正は行わない。参加者ごとにHMD標準の眼球校正を行い、実施者がPCへ確認を記録する。静止・正面の座位で車体に対する表示位置を合わせる。[操作](operations/3_console.md)・[機器](operations/1_setup.md)

同意・適格性確認後、共通習熟と無FB事前評価を行う。左右と速さの[短い理解確認](operations/2_participant-materials.md)を全員に行い、割付表から群を登録する。プログラムは合否や進行を強制しない。

## 評価共通の開始姿勢

最初のキャスターを開始線に合わせて静止し、両手はハンドリム最上部へ軽く添え、開始音前に押さない。無理なく添えられない場合は位置を個人ごとに記録し、事前・直後の全評価で揃える。これは反応時間を含む本研究の計時のための標準化で、引用原著の開始姿勢を再現したという意味ではない。

## 8の字2周

実験室の通路内に8の字を設定する。寸法と目印は初回設営で確定し、[線課題の設計](../research/implementation/line-course.md)に記録する。開始終了線と、通過後の停止方向に障害物のない余裕を置く。PCは走路外の、開始終了線とコース全体を見渡せる位置に設置する。

1. 共通姿勢で、同じ向きに静止する。
2. PCの記録開始後、3秒の準備音と開始音を待つ。実施者は開始前に安全を確認する。
3. 一方の周回を反時計回り、もう一方を時計回りに回り、8の字を2周する。2周を1試行とする。途中の中点通過はゴールにしない。
4. 2周した後、最初のキャスターが線を通過した時点で実施者が計時終了を押す。通過後に減速・停止し、記録を終了する。
5. 位置戻し・原則30秒の休憩を挟み2反復。

読み上げる文は[8の字の共通教示](operations/2_participant-materials.md#8の字評価)を使う。

開始音基準・車体・反復等は本研究の設定である。[時間の意味](specifications/measurement.md)

## 線課題

床にテープで引いた線の中心を維持して、コースを1周する。コース構成・基準線・位置合わせ・ズレの計算は[線課題の設計](../research/implementation/line-course.md)が定める。

1. スタート位置で共通姿勢を取る。
2. PCの記録開始後、3秒の準備音と開始音を待つ。実施者は開始前に安全を確認する。
3. 線の中心に車いすの中心を合わせ続けてコースを1周する。
4. スタート／ゴール位置に戻り、最初のキャスターが開始線を通過した時点で実施者が計時終了を押す。通過後に減速・停止し、記録を終了する。
5. 位置戻し・原則30秒の休憩を挟み2反復。

読み上げる文は[線課題の共通教示](operations/2_participant-materials.md#線課題評価)を使う。

ズレは記録した車体軌跡からオフラインで計算し、その場の計時とは分けて扱う。全周を記録する。

## 30分の配分

会場設営、接続、トラッカー登録・車輪軸の校正、自由走行による機能確認は実施者が参加者の来訪前に済ませる。以下の30分には説明・同意、参加者固有の装着・眼球校正、終了操作を含む。保持評価と、そのための20分休憩・再装着は設けない。

| 経過 | 内容 |
|---|---|
| 0–3分 | 説明・同意・適格性・体調 |
| 3–6分 | 椅子適合、手首2台とHMDの装着、視界・音量・眼球校正・表示位置確認 |
| 6–8分 | 共通習熟：8の字1回・線課題1回、停止・方向転換。追加FBなし |
| 8–12分 | 事前評価：8の字2回→線課題2回、追加FBなし |
| 12–14分 | 音と表示の理解確認、割付開示 |
| 14–21分 | 練習：評価と同じ2課題を割付FBで実施。配分は予備実験で確定する |
| 21–25分 | 無FB直後評価：8の字2回→線課題2回 |
| 25–28分 | 質問紙、取り外し、体調確認 |
| 28–30分 | 保存・回収確認と予備時間 |

練習は評価と同じ2課題（8の字・線課題）を割付FBで実施し、快適な安全速度で繰り返す。1課題あたりの時間・反復数と休憩の配分は予備実験で確定し、本計測前に固定する。休憩中は記録を終了し、FB・視線保存を止める。HMDは着けたままを基本とし、不快があれば外す。

練習の時間管理はPCの目安表示を使う。実施者が新しい走行を始めないよう指示し、練習終了でFBを止め、安全停止後に記録を終了する。実動時間・はみ出し・実施本数を残す。時計による自動進行・強制終了は行わない。直後評価までの実際の間隔も残す。

保持や持続的な学習は測定しない。練習量は時間制約に合わせた設定で、効果が得られると先行研究が保証した量ではない。予備実験で装着と全反復を含む30分の成立性を確認する。

## 中止・再試行

痛み・めまい・強い疲労・参加者の希望・実空間を確認できない状況では中止する。実施者の停止指示を共通習熟で練習する。接触や経路の問題は把握した場合に備考へ残す。動画は要求しない。

技術的不成立の再試行は各評価時点で追加1試行までを基本とし、元試行・置換先・理由を記録する。遅い成績、接触、目標未達を理由にやり直さない。アプリは再試行上限や次の課題を強制せず、実施者が手順表で判断する。

全群・全時点の記録中に探索用の視線を保存し、欠測だけで試行を中断しない。[記録形式](specifications/recording.md)

未完了や計時失敗へ0秒・60秒・平均値を入れない。トラッカー欠測と手動時間の成立は分ける。説明・同意、安全確認、本人に必要な休憩を時間のために省かない。30分に収まらない場合は安全に終了して未完了と理由を記録し、反復や訓練量を参加者ごとに黙って変えない。予備実験で収まらなければ、本計測前に計画を再検討する。
