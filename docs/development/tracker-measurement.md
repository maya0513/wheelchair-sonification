# 5台の装着と校正

[計測仕様](../specifications/measurement.md)を実現する準備手順。実機5台同時取得と研究用性能は未検証。

1. 左手首・右手首・左車輪・右車輪・車体へ固定する。スポーツ車いすのキャンバーを想定し、車輪の軸は左右別々に求める。回転・手・衣服・床との干渉と脱落を確認する。
2. PCの設定画面で、1台ずつ動かして機器識別と役割を対応付ける。接続順で決めず、同じ機器の重複割当を拒否する。
3. 静止して車体基準を取得する。次に左右の車輪を安全にゆっくり前進方向へ回し、車体に対する相対姿勢の変化から各回転軸と正方向を求める。固定具が動かないことを確認する。
4. 左右の既知角・前後回転、停止時の揺れ、車体旋回の影響を確認する。校正の結果と機器IDを保存する。

手首は元データ記録用で、リムとの位置合わせ、接触区間、手首別の校正、コース座標の校正を行わない。角速度なので車輪径も計算に不要。手首だけの欠測はFB停止条件ではない。

車輪・車体の再装着、再接続、追跡原点の変更、固定の変更では対応する校正を無効にする。単なる一時的な追跡欠測では、欠測をまたぐ速度を計算せず、復帰後に新しい差分から再開する。アプリ再起動後に保存済み校正を無条件に有効にしない。

同じ装着・座標を維持できる来訪間でも実施者が有効性を再確認する。HMDを20分休憩で外した後は、再装着・追跡座標・機器識別・出力を確認する。装着による車体特性の変化、5台の有効率、固定具・電池・全走路の追跡を[検証計画](../specifications/validation.md)へ記録する。
