# 装着・割当・案内付きチェック

実施者が事前に行う機器準備。ゴーグル単体で進められ、PC接続後は「準備・チェック」に同じ状態を表示する。参加者の装着後は見え方・聞こえ方の短い確認を行い、本実験中の操作は求めない。

## 装着と開始

先にHMDへVIVE Wireless Dongleを取り付け、ゴーグルの「設定 → 入力 → モーショントラッカー」でペアリングと環境スキャンを済ませる。アプリはHMDが取得した位置姿勢を使い、ペアリング自体は行わない。[HTCの設定手順](https://www.vive.com/jp/support/ultimate-tracker/category_howto/setting-up-vive-ultimate-tracker.html)

左右車輪・車体の3台を走行用、左右手首の2台を元データの追加記録用とする。3台でも機能チェックできる。研究計画の5台構成や本計測の受入れ条件を変更するものではない。

車輪は回転する部分、車体は剛性のあるフレームへ固定する。カメラを覆わず、手・衣服・車体・床との干渉や脱落、固定部のずれを確認する。背もたれの布だけを車体基準にしない。装着の強度・全走路の追跡は実機確認が必要。

停止・着座して「チェックを始める」を選ぶ。標準コントローラーのポインターとトリガーで選択する。A／Xでメニュー、B／Yで操作パネルを正面へ再配置する。再配置は表示だけの変更で、計測原点は変更しない。動作前には5秒の準備時間があり、コントローラーを置いてから動ける。

## 案内に沿って確認する

1. 車いすを止める。静止が続くと次の説明へ進む。
2. 周囲を確認し、前へ約1 mゆっくり進んで止まる。
3. 後方を確認し、後ろへ戻って止まる。
4. 車体・左右車輪の候補を、実物の位置に重なる目印と照合して確定する。動きだけで勝手に確定しない。
5. 必要なら左右の手首を順番に上げ下げして識別する。手首を装着していない機能確認では省略する。
6. 停止、前後進、左右への旋回を案内どおりに行う。方向・左右差が取得できるか確認する。
7. 停止したまま視覚、聴覚の見本を順番に確認し、見え方・聞こえ方を回答する。
8. 結果を確認して実験待機へ移る。PCでは項目ごとの結果と保存・回収状態を確認できる。

前進データから左右の軸を独立に求め、後退データで軸と方向の整合性を確認する。キャンバーと任意の取付姿勢を扱う。車輪径は角速度の計算に不要。手首から接触や推進角は求めない。

候補が複数、動作不足、追跡不良の場合は理由を表示する。「実物を選ぶ」では左車輪、右車輪、車体の順に目印を指して選び、前後進で校正する。PCの同じ画面からも選べる。実物が見づらい場所ではPCで調整する。HMDの機器番号1〜5とSDKの0〜4の対応を仮定せず、接続順でも役割を決めない。

PCの結果欄から音・表示・特定の動作だけを再確認できる。参加者の装着後は「装着後の短い確認」で表示と音の見本だけを確認し、車輪の識別動作を繰り返さない。再確認は別IDで保存し、対象外の項目を合格扱いにしない。機器A〜Eはこのアプリ内の目印で、HMDの番号との対応を示すものではない。

## 自動候補の条件

設定の正本は実装の `PreparationSettings`。PCの詳細設定から変更でき、変更後は校正を取り直す。以下は試作用の初期条件であり、メーカー性能や研究用精度を保証する数値ではない。

| 条件 | 初期値 |
|---|---|
| 静止 | 2秒。並進0.04 m/s、回転8°/s以下を判定に使用 |
| 前後の移動 | 各0.5 m以上、互いに反対方向 |
| 車輪の回転 | 各45°以上、定軸性0.8以上 |
| 有効サンプル | 95%以上。欠測をまたぐ角度差を使わない |
| 車体候補の姿勢変化 | 各区間12°以内 |
| 左右の間隔 | 前進方向に対する左右成分0.2 m以上 |
| 回転軸 | 前進方向との内積絶対値0.4以下、前後の軸の差20°以内 |
| 動作の待機上限 | 各40秒。失敗時は安全停止を案内し、再開は手動 |

条件を満たす組合せが一つのときだけ候補を出す。手首などが紛らわしい場合は実物選択へ移る。前後進だけで常に識別できるとは扱わない。

## 有効性と再確認

再装着、再接続、追跡原点や固定の変更では校正を取り直す。一時的な追跡欠測をまたいだ速度は無効とする。アプリ再起動後に古い校正を自動復元しない。20分休憩後は再装着・座標・機器識別・出力を実施者が確認する。

チェックの「確認済み」は機能についての結果。既知角、別の時計と回転数、全走路の追跡、実出力遅延による[測定検証](../specifications/validation.md)は別に行う。見本の値を実測速度として記録しない。[保存形式](research-records.md)・[PC操作](experiment-console.md)
