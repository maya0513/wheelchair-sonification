# 記録形式と回収

位置姿勢・速度はHMD、正式な課題時間と回答はPCへ保存する。研究ID・来訪ID・試行IDで対応付ける。実名は入力しない。通信形式は3、研究試行の保存形式は2で、旧接触角形式を速度として読み込まない。

## HMDの一試行

`Application.persistentDataPath/ResearchSessions/<trial-id>/`。Androidでは通常`Android/data/io.github.maya0513.wheelchairsonification/files/`配下だが、実機上の実際の場所を確認する。

| ファイル | 内容 |
|---|---|
| session.json | 形式、研究ID・来訪・試行、群・時点・課題・反復、入力方式、FB設定、ビルド |
| calibration.json | 役割・機器ID、左右の回転軸、校正条件・有効性 |
| poses.csv | 取得時刻、取得できた入力時刻、機器、位置・姿勢、追跡・無効理由。手首も記録 |
| speeds.csv | 時刻、左右の符号付き生速度・平滑速度・提示値、有効性 |
| events.csv | 記録・FBの開始終了、取消、中断、欠測・校正無効化 |
| diagnostics.csv | 処理間隔、保存異常、取得できた機器状態 |
| completed.json | ファイルを正常に閉じた印。正しい課題完了・正式採点の印ではない |

取得できないセンサー時刻・実提示時刻・電池等を推測で埋めない。定期書出しと終了時の書出しを行い、書込み失敗では提示・試行を停止する。元データを書き換えない。

## 単体チェック

`Application.persistentDataPath/DeviceChecks/<check-id>/`。参加者IDや来訪を作らずに保存できる。研究試行とは混ぜない。

| ファイル | 内容 |
|---|---|
| report.json | 段階、割当候補、項目別の確認済み・要確認・未実施、理由 |
| poses.csv | 未割当も含む全機器の元の位置姿勢・入力時刻・有効性。研究試行と同じ列 |
| speeds.csv | 動作確認中の符号付き左右速度、有効性、段階。見本の値を実測として記録しない |
| settings.json | 自動候補・静止・校正の設定 |
| calibration.json | 役割と回転軸、有効性 |
| operations.csv | 操作と段階の遷移。HMDとPCの操作を共通処理で記録 |
| build.json | 入力方式、アプリ・Unity・ソース識別、開始UTC |
| closed.json | ファイルを閉じた印。チェック完了か中断かを区別 |

保存失敗や強制終了では最後まで揃わないことがある。`closed.json`のない記録を正常完了と扱わない。機能チェックの結果は測定精度・実出力遅延の検証結果ではない。元データは記録再生の入力として読めるが、研究試行用の速度再解析とは区別する。

## PC

初期保存先は`~/WheelchairSonificationData/`。画面に実際の絶対パスを表示する。回収ZIPとSHA-256、`archives.json`の対応表、来訪IDごとの`operator.json`（PC計時・理解確認・質問紙・手動操作記録）を置く。計時には試行ID、単調時計での開始・終了、経過秒、合図のWeb Audio予定時刻とソフトウェア通知時刻、取消・未完了理由を残す。ブラウザー再起動をまたぐ単調時計を結合しない。開始予約があり終了がない記録は未完了として確認する。PC保存失敗の記録はブラウザー内にも一時保持し、次の起動で再保存を試みる。HMD再起動後は過去の来訪を自動再開せず、同じ研究IDの新しい来訪として、前後の来訪IDを実施者の備考で対応付ける。

HMDが試行またはチェックを閉じると、その一件をZIP化してPCへ転送する。単体チェックはPC未接続でも保持し、接続後に回収する。ZIP内部のSHA-256一覧と外側のSHA-256を作り、PCの一致確認後に回収済みとする。失敗時は元記録と未回収の試行一覧を保持し、記録ページの再回収で古い試行から順に転送する。別試行のZIPへ上書きしない。HMD再起動後の手動再回収では保存済み試行を再探索するため、既存ZIPと重複しうる。試行IDで照合し、別の試行として数えない。

USB用には終了・中断済み記録をMediaStore経由で`Download/WheelchairSonificationExports/`へ出せる。Windowsで「内部共有ストレージ → Download → WheelchairSonificationExports」を開きPCへコピーする。元アプリデータは触らない。

このPCは回収先。正式保管先、アクセス権、保存期間、バックアップ・撤回期限は[責任者確認](../operations/study-operations.md)が必要。リポジトリ・配布物に参加者データを入れない。
