# 画面・音を実機なしで確認する

```sh
just dev preview             # ゴーグル・PCの画像と音見本をまとめて生成
just dev unity-preview       # ゴーグル側だけ生成
just dev console-preview     # PC側だけ生成
just dev unity-preview-open  # Editorで頭部・コントローラーを模擬操作
```

`.local/ui-preview/index.html`で画像・切り出し・撮影条件・音見本を確認する。Unityを入れていないPCへもフォルダー／ZIPを渡せる。2分の音はオフラインで生成するため2分待機しない。

UIはAPKと共通のWorld Space Canvas・TextMeshPro・Prefab。左右速度、左右差、無提示、停止、明暗、FOV70°／90°、車体の移動・旋回、頭部回転後、表示位置合わせ後を確認する。仮の背景・視野角は実機のパススルー映像やレンズ画質の再現ではない。PC画面は`.local/console-preview/`。

音見本は片側・両側・速度差・加減速・停止・欠測・静止ノイズと2分例。左右チャンネルを確認できる環境で小音量から試聴する。波形のクリップや不連続の検査と、快適性・疲労の主観評価は別である。

固定見本は[FB仕様](../specifications/feedback.md#初期設定)の提示上限から生成する。`audio-manifest.json`には使用したFB設定も残す。`60-range-light`・`61-range-dark`の画像は同じ速度処理を通した0.5／0.25 rpsを明暗の背景で示す。

| 確認方法 | 分かること | 実機で残ること |
|---|---|---|
| 自動テスト | 計算、取消、時計、保存 | 実測の誤差 |
| Unity PNG | 配置、文字、左右ゲージ、見切れ | レンズ越しの可読性 |
| Editor操作 | 状態遷移、視点と表示 | 実操作感・追跡 |
| WAV | 波形、左右割当、再生例 | HMDの左右分離・聴取疲労 |
| APK | 実行環境での成立 | 現地・走行中の性能 |

差を一律の割合では示さない。文字欠け・重なり・見切れは画像を実際に開いて確認し、画質・追跡・実出力遅延・単独見守りは現地で測る。本実験中の参加者画面は操作パネルを持たず、EditorのシミュレーターをAndroidへ有効化しない。

準備パネル、動作案内、割当確認、実物選択、見え方・聞こえ方の回答、失敗、結果も共通の準備処理から撮影する。PCの画像検証用の状態はUnityの同じ処理から生成する。画像検証専用の模擬機器は配布コンソールへ含めない。

PC画像では詳細欄を開かずに使う位置合わせ、欠測時の停止確認、自由走行の終了後も確認する。理解確認の見本はHMDが送る提示上限から計算し、旧APKで上限が取得できない場合は更新の案内を出す。1分タイマーと案内文の一致も実ブラウザーで検査する。

EditorではHで頭部、[／]で左右コントローラー、WASD・Q／Eで移動、マウスで向き、左クリックで選択する。Spaceはマウス操作の切替、Mはメニュー、Rは再配置。トラッカーの実運動を再現する機能ではなく、識別の計算は別の合成データ試験で確認する。

縦バーは車体固定なので、頭を横に向けた画像で視野外へ出ることは正常。明暗背景で輪郭、左右ラベル、半透明のバーを確認する。視線の実測はEditorでは取得不可と表示され、画像を眼球計測の検証としない。
