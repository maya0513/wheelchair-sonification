# 確認証拠と残作業

ソフトウェアの確認と、実機での研究用性能を分けて管理する。[本計測開始条件G1–G6](../operations/study-operations.md#本計測開始条件)は、実際の証拠が揃うまで未完了。

| 対象 | 証拠と確認範囲 |

| 実通信・保存 | Linux Unityの合成入力で18試行を記録・回収。約76.1秒、20分待機なし。`.local/console-integration-2026-11-01T18-34-15-438Z/result.json` |

リファクタリングでは視線取得、表示の車体固定、CSV整形、記録再生、Android接続先取得を分離した。重複・未使用処理を整理し、C#・補助スクリプトの書式を統一した。`just check`には文書・文献・PDFの整合検査を追加した。

画像・WAV一覧は`.local/ui-preview/index.html`、実施者画面は`.local/console-preview/index.html`。読み方と確認の限界は[プレビュー手順](xr-preview.md)を参照する。90分継続試験は任意で、このソースでの成功証拠はない。20分休憩を実際に待つ自動試験は行わない。

## ビルドと配布

生成対象は署名付きv0.6.0／versionCode 6。`.local/builds/android-release/`へAPK、対応コンソール、概要・画像・音見本、ビルド情報、チェックサムをまとめる。APKのARM64・IL2CPP・非デバッグ・XR・通信形式3・ライセンス・署名・既存鍵との一致はビルド時に検査する。対象ソースと各検査結果は、その一式の`build-info.json`で確認する。

コンソールは配布ZIPをリポジトリ外へ展開し、NodeだけでHTML・JS・CSS・時計モジュールを起動できることを確認する。梱包結果は`.local/logs/distribution-verification.json`。実際に公開されたバージョンと添付物は[Releases](https://github.com/maya0513/wheelchair-sonification/releases)を参照する。APKを生成しただけで公開済みとは扱わない。[ビルド・公開手順](android-build.md)
