# PC操作とオフライン接続

実験の進行判断は実施者が[手順表](../experiment-protocol.md)に沿って行う。課題を自動で進めるアプリではない。

## 起動

```sh
just experiment-console-demo  # 実機なし、常に模擬と表示
just experiment-console       # 実機用
```

配布ZIPではNode.jsを用意して`node scripts/experiment-console.mts`を実行する。ブラウザーは`http://127.0.0.1:8765/`。外部回線、Unity、VIVE Hubの常時実行は不要。

会場にWi-Fiがなければ、このPCのWi-Fi設定で事前にホットスポットを作り、Focus Visionを接続する。コマンドはネットワークを勝手に切り替えない。PCのAPインターフェースだけへ機器用通信を公開し、ゴーグルはWi-Fiのゲートウェイを検出する。アドレスの固定入力は不要。起動時にAP未接続なら有効化後にサーバーを起動し直す。

装着前に、HMDに出る6桁の確認番号を実施者がPCへ入力する。PCページはローカル専用、機器通信はペアトークン、ブラウザー操作はCookie・CSRFで認証する。通信形式2の同じ配布物を組み合わせ、旧APK/コンソールを混ぜない。

HMDアプリを完全に再起動した場合は、PCコンソールもCtrl+Cで停止して起動し直し、ブラウザーを再読み込みして新しい6桁番号で承認する。以前の機器承認は自動で置き換えない。保存済みデータは消えず、過去の来訪を自動再開しない。

## 通常の操作

1. 参加者ID・群、実測／合成入力を明示して選ぶ。役割・校正・音量は設定ページで確認する。
2. 時点・課題・反復を選ぶ。記録中に変更しない。
3. **記録開始**。HMDの開始応答後、評価では**開始合図**を押す。3秒の準備音、開始音と同時にPCの時計を開始する。
4. ゴールを見て**計時終了**またはSpace。入力欄・選択欄の編集中はSpaceを計時へ使わない。
5. 安全停止後に**記録終了**。訓練では2分の目安で**訓練終了**を先に押してFBを止め、元データを安全停止まで残す。
6. 試行別ZIPの自動回収結果を確認する。失敗は記録ページから再回収する。理解確認・質問紙もPCへ入力する。

2分・20分タイマーは通知のみ。休憩時計はHMDを外しても動き、操作を禁止しない。ブラウザーを閉じる／PCが停止すると、HMDは通信監視で試行を未完了終了する。復帰だけで再開しない。再起動前の未完了記録とPCの計時記録を照合し、次に行う課題は実施者が選ぶ。

## 表示と保存

通常画面は参加者・課題、記録と計時、機器状態。設定、理解確認・質問紙、記録は別ページ。参加者には設定を見せず、走行中は割付と時点に合うFBだけを提示する。

PC保存先の初期値は`~/WheelchairSonificationData/`。実際の絶対パスを画面に表示する。詳しくは[記録形式](research-records.md)。保存失敗の表示を無視して次の試行へ進めない。通信断時も身体の安全停止は実施者が判断する。
