# 判定・提示・保存のテストケース

以下は開発時に確認する入力と期待結果の例。実行結果は、使用したGitコミット、入力データ、設定とともに記録する。判定・提示の期待値は[フィードバック仕様](../specifications/feedback.md)に基づく。欠測後の再開、保存失敗、再起動は、提示規則を守って運用するための実装上の確認例である。作り方は[開発ガイド](guide.md)、技術性能の受入れ基準は[検証計画](../specifications/validation.md)を参照する。

| ID | 入力・操作 | 期待する結果／確認点 |
|---|---|---|
| T01 | 目標70°、64.9／65／70／75／75.1° | 順にSHORT／TARGET／TARGET／TARGET／LONG。両境界を含める |
| T02 | 事前中央値60／84.9／85／90／94.9／95／97° | 目標70／94.9／95／95／95／95／97°。85°・95°の前後で連続すること、目標算定と個々のプッシュ判定を分けて確認 |
| T03 | 既知の正方向の車輪角359→1° | 増分＋2°として扱う。−358°にしない。逆方向・累積回転も別に確認 |
| T04 | 校正後、角度が分かる位置へ動かす | 既知角度との誤差を記録。車いす全体の向きを変えても輪の相対回転を混同しない |
| T05 | プッシュ途中に追跡無効、NaN等の不正値 | 有効な接触角を作らず無提示。最後の正常値で補完しない。復帰時に途中のプッシュをつなげない |
| T06 | 訓練直進、中央2–8 m内で開始・終了し、提示開始まで回復期 | 群に対応したFBを1回。Aは音のみ、Vはゲージのみ、Nは追加FBなし |
| T07 | 8の字、評価、停止・制動・旋回、範囲外 | 動作FBなし。中央区間の外で始まった／終わったプッシュも提示しない |
| T08 | SHORT／TARGET／LONGの提示 | 音は440／660／880 Hz、表示は左／中央／右。状態に応じた数値・履歴等を追加しない |
| T09 | 回復期に開始済みの提示中、次の接触開始を入力 | 次接触だけでは切らず原則300 ms後に消去。音は各10 msのフェードを含む。実提示開始が回復期か、次プッシュへ継続したかは外部測定も行う |
| T10 | 提示中に別の有効プッシュ終了イベント | 先行提示を打ち切り最新状態を300 ms提示。遅れたイベントをキューに貯めない。打切りを記録 |
| T11 | 提示開始待ち中に次接触、または範囲外・停止・旋回・追跡不良・課題切替 | 次接触後の前プッシュの新規提示を取消。領域外等では待機取消と実行中の終了を行い、理由を記録 |
| T12 | 同じ入力・時刻列・校正・設定で再生 | 計算結果と提示依頼が再現する。再生速度や描画フレーム数だけで判定が変わらない設計を目指す |
| T13 | 接続断、機器の順序入替、追跡復帰 | 無効を検出し、古い値・別機器を採用しない。復帰条件と校正確認を記録 |
| T14 | 保存先なし・書込拒否等を模擬 | 実施者へ保存異常を通知。記録できないまま試行を続けない。研究データを壊して試さない |
| T15 | 終了・異常終了後に再起動 | 保存済み分を確認できる。未完了試行を完了扱いにせず、同じファイルを上書きしない |
| T16 | 90分以上稼働、複数セッションを開始・終了 | メモリ・ファイル・電池・追跡状態を点検し、前回の目標や提示が残らない |

期待値は仕様・手計算・独立した参照データから用意する。**テスト対象と同じ式をコピーして期待値を作るだけでは、同じ間違いを見逃す。** ランダムな合成データを使う場合も乱数の種とデータを固定する。検出法を調整したデータと、最後の性能確認に使うデータを分け、再装着・別の動作で確認する。

集約の確認では、目標70°・角度60°と80°なら平均絶対誤差10°、開始間隔1秒と2秒なら頻度約0.667 push/sを期待値にする。基準角算定の2反復合計4本・各反復1本以上と、評価の角度各1本・頻度各1間隔以上を混同しない。正常な少数プッシュを入力したときに、取得済み値を消したり追加試行を要求したりしないことも確認する。[集約の定義](../analysis-plan.md#副次指標の計算と比較方針)

## Ultimate Tracker計測・XR画像の追加確認

| 対象 | 確認すること | 自動確認と実機の境界 |
|---|---|---|
| 3次元の車輪軸 | 左右に傾いた軸、任意の車体トラッカー取付姿勢、360°収録、359°→1° | 合成入力の既知値と比較。実車の動画参照は未実測 |
| 車体と車輪 | 車体の並進・旋回だけで接触角が変わらない | 座標変換のテスト。振動・ずれは実機で確認 |
| 5役割 | 重複、切断、実行中device IDの変更、原点変更時に開始・校正を無効にする | 論理検査と実際の再接続を分ける |
| 接触候補 | 近接・速度条件、離脱、時刻間隔・欠測をまたぐ候補の無効化 | 既知の合成軌跡と、別途動画採点を使う |
| 元データ | 生の位置姿勢・時刻・校正から同じ推定角・状態・理由を再現 | 入力再現性を確認。実測精度とは別 |
| 保存・取り出し | 正常／未完了、書出し失敗、元記録保持、ZIP内SHA-256 | ファイル検査は自動、MediaStoreとWindowsコピーは実機 |
| 1枚の操作画面 | 大きなSDF文字、ページ・数値パッド、無提示とゲージ、頭部回転・再配置 | 実描画PNGと目視。レンズ越しの可読性は実機 |
| 提示と中断 | 提示中は操作画面なし、A/Nはゲージなし、300 ms、停止後に操作画面へ | Play Modeと実出力測定を分ける |

画像生成のコマンドと対象は[画面確認](xr-preview.md)、校正条件は[実測手順](tracker-measurement.md)、記録の列と取り出し先は[実測記録](research-records.md)で管理する。
