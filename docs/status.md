# 確認状況と次に行うこと

実装、PC上の確認、実機での測定性能、研究の実施許可を区別する。本計測の判断と担当は[開始条件G1–G6](operations/study-operations.md#本計測開始条件)に集約する。

来訪は合計30分、事前・直後の2時点に変更した。保持評価は設けない。訓練量と配分は[実験手順](experiment-protocol.md)、主要評価は[分析計画](analysis-plan.md)を参照する。

## 使える機能と確認範囲

| 対象 | 実装・PC上の確認 | 次に行うこと |
|---|---|---|
| 準備・チェック | 登録・動作確認・FB検査を独立化。実物選択、HMD単体操作を合成入力で確認 | 実物との対応、目印の位置、装着・キャンバー、全走路を確認 |
| 自由走行 | 実際の左右速度によるFB、手動終了、欠測・中断、保存なしを合成入力で確認 | HMDで開始・終了、実走行とOS警告の発生位置を確認 |
| 速度FB | 左右共通の提示範囲を調整。計算・固定見本・無提示条件・画像・波形を確認 | 独立参照で速度・追跡・実出力を測り、尺度・左右音・可読性を確認 |
| 視線 | 全群の試行記録に左右眼球・頭部・表示配置を保存。合成入力で欠測・例外・座標変換・保存を確認 | HMD標準の眼球校正、取得率・取得間隔、再装着、処理負荷を実機で確認 |
| PC操作・回収 | 手動課題選択・正式計時・回答・試行別ZIP回収を確認 | 実際の合図音、手動停止、無線、WindowsへのUSBコピー、単独見守りを確認 |
| 実験運営 | 手順・教示・分析・開始条件を文書化 | 倫理・同意、会場、正式保管先・期間、2–3名の通し予備実験、条件固定 |

機能チェックの「確認済み」は測定精度の合格ではない。手順と受入れ目標は[検証計画](specifications/validation.md)を参照する。実機や責任者の確認を、APKの生成・画像確認で代替しない。

## 確認証拠を探す

以下はアプリv0.7.1のPC上の確認。検証の記録と対象ファイルのハッシュは`.local/verification/v071/`に保存する。コミット前のAPK検査は`build-info-worktree.json`、配布するAPKのソースはビルド情報で区別する。実機での確認は含まない。

| 確認 | 結果・記録 |
|---|---|
| 自動試験 | Unity Edit Mode 71件、Play Mode 20件、Node 69件成功。XML・TAPは上の確認フォルダーへ保存 |
| 準備・位置合わせ | 登録・軸校正を保った位置の再設定、見本・動作・記録中の操作拒否、手首を除いた静止判定を確認 |
| 自由走行 | A／X・PCでの終了、欠測時の停止確認、復帰後に自動再開しないことを確認。既存ファイルが変わらず、新しい研究試行を作らないことも照合 |
| 時計・尺度 | 記録開始で古い時計表示を解除。二重計時の禁止は保持。固定見本・新旧尺度の記録再生・符号付き元データの保持を確認 |
| 画面・音 | Unity 61画像、Chrome 39画像。新しい位置合わせ、停止確認、1分案内を目視。WAV 9例で左右の音高、無音、クリップ・不連続を検査 |
| APK | 署名付きv0.7.1／versionCode 8。ARM64・IL2CPP・非デバッグ・XR・通信・ライセンスと、既存APKとの署名一致を検査 |

従来の準備機能・配布の確認は`.local/verification/v070/`、Linux UnityとPCを接続した18試行はソース`ae2055d4e06ba484374637fb4feeaf7171b7a780`での記録。今回再実行した証拠とは区別する。

現在の文書リンク・文献一覧・BibTeX・PDFの対応は`just dev docs-check`で検査する。今回更新した文書の推敲・照合記録は`.local/verification/v071/yomiyasu/`に保存する。文献の閲覧範囲は[文献一覧](../research/catalog.md)、原著と提案の区別は各ノートで確認する。

画像とWAVは`.local/ui-preview/index.html`、PC画面は`.local/console-preview/index.html`で開く。[画像付き概要](app-overview.md)は要点だけを掲載する。波形検査は実際のHMDでの聴取・疲労の確認を代替しない。来訪30分の通し予備実験は未実施。90分耐久試験は任意確認で、今回の成功証拠はない。準備の3秒・目安の1分は時計を進めて検証し、実時間の待機は行わない。

## 配布物

Releaseの添付物は署名付きAPK一件。PCは同じ版のリポジトリから起動する。ローカル出力は`.local/builds/android-release/`で、APK・`build-info.json`・`SHA256SUMS.txt`を保持する。ARM64・IL2CPP・非デバッグ・XR・通信形式3・ライセンス・署名・既存鍵との一致を検査する。対象ソースと検査結果は`build-info.json`、使い方は[画像付き説明](app-overview.md)で確認する。

実際に公開されたバージョンと添付物は[Releases](https://github.com/maya0513/wheelchair-sonification/releases)を参照する。導入は[実施者の準備手順](operations/setup.md)、再生成・公開は[開発者のビルド手順](development/android-build.md)に従う。
