# 原発表の復元と、現在の研究条件

更新日：2026-10-15。現行仕様v1.1との対応を追記。復元元は[2025-08-08のPDF](2025-08-08_中間発表準備_上山颯太.pdf)（9ページ）と[2025-09-08というファイル名のPPTX](2025-09-08_中間発表スライド.pptx)（11枚・発表者ノート）。ファイル名の月と研究予定の月を同一視しない。原資料そのものは改変していない。

## 2025年の原案

目的は、リアルタイム音響FBを用いた手動車いす推進技能学習支援システムの開発と効果検証。聴覚・視覚・無FBの3群で、各群10名以上・目標15名。両手首・両輪のトラッカー、Unity、HMDで処理・提示する構成だった。資料にVIVE Tracker、Focus Visionとあるが、現在の実物の型番を保証しない。

課題はジグザグ往復、5 m間隔のコーンを8の字5周、ボールを持つ8の字。習熟、事前、訓練、無FB事後、48時間以降の無FB保持という流れ。PPTXのノートではボール課題を二重課題・認知的効率性の評価と説明していた。

PDFではシステム作成8月・計測9月以降、PPTXでは作成9月・計測10月以降。現在の日程はこの予定を根拠にしない。PPTXにはFujiiら2016の引用があり、ほかの背景主張の根拠は十分明示されていなかった。

## 今回のユーザー確認と採用方針

| 項目 | 現在の条件 |
|---|---|
| 関心 | 車いす技能全体への関心を、実施可能な平地の走行・旋回・加減速へ具体化 |
| 対象・人数 | 車いす未経験の成人学生等、15名規模。30名は難しい |
| 比較 | 聴覚・視覚・追加FBなしの3群 |
| 来訪 | 1回90分以内。48時間後の再来訪なし |
| 期限 | 2026-12-20頃までにデータ収集終了 |
| 会場 | フットサルコート1面程度の広さの平地。床材・屋内外・実寸は未確認 |
| 機材 | 数世代前のVRゴーグルとトラッカー。型番・台数・性能は実物確認待ち |
| EEG | 未到着。今回の装着・取得・同期・分析を計画から外す。調査・保留案は保存 |
| FB | 走行中を維持。進路誤差案と比較して、直前プッシュの接触角を返す案を採用 |
| 訓練 | 直進と8の字の両方。接触角FBは直進に限定 |
| 主要評価 | 休憩後・無FBの8の字所要時間。正確さと未完了も必須報告 |
| 追加課題 | ボール、独立した転移は実施しない |

詳細な設計値・確認待ち事項は[決定台帳](decisions.md)。会場の広さと追跡範囲、ユーザーとの計画合意と倫理承認を区別する。

## 元の主張をどう直すか

| 元の主張・設計 | 判定 | 根拠・修正 |
|---|---|---|
| 長い接触角・低頻度が重要 | 条件付き | 単一指標の極端な変更は力を増やしうる。角度・頻度・速度を併記し、力・傷害は結論にしない。[L15](../research/papers/L15-richter-2011.md) [L17](../research/papers/L17-symonds-sensewheel-2016.md) |
| 左右推進力の対称性が鍵 | 過大 | 位置から力は測れず、旋回には左右差が必要。[L31](../research/papers/L31-soltau-2015.md) |
| 視覚FBは除去後に元へ戻る | 一般化を修正 | 視覚の終了後要約FBにも保持・転移がある。[L14](../research/papers/L14-yan-2021.md) |
| 聴覚にはガイダンス仮説が当てはまらない | 未確立 | [Fujii](../research/papers/L05-fujii-2016.md)は聴覚100%対50%で、視覚との直接比較ではない |
| 聴覚なら認知負荷が低い | 検証する期待 | 課題・音の対応で変わる。主観負荷は補助評価。[L13](../research/papers/L13-gref-2016.md) |
| トラッカーで角度・頻度・力を評価 | 分離 | 角度は検証が必要。力は別計測。[L25](../research/papers/L25-ojeda-2014.md) |
| ジグザグ・8の字5周を独自設定 | 課題を再選定 | 5 m・1周8の字と10 m直進の先例を調査し、変更部分を明示。[L53](../research/papers/L53-kamegaya-2021.md) [L54](../research/papers/L54-askari-2013.md) |
| ボールで負荷を増やせば差が明瞭になる | 根拠不足 | 手の使用法も変わり、負荷追加が初心者で明確な差を生む保証はない。[L58](../research/papers/L58-salm-2025.md) |
| 全課題を練習し転移も評価 | 用語・設計修正 | 現行は両課題を練習するので独立した転移評価とはしない |
| 20分休憩で48時間保持を代替 | 同等とはしない | 同日内の短時間保持という別の評価へ変更。[L03](../research/papers/L03-kantak-2012.md) |

## 初期調査案からの変更

初期案では実行可能性を重視して停止後の要約FB・接触角主要・小規模転移・探索EEGを提案した。その後、ユーザーは走行中FBを維持し、平地技能を主要評価し、直進と8の字を両方訓練する構成を選択した。[旧案](archive/README.md)へ保存し、現行計画と区別した。

2026-10-15のv1.1では、正常な少数プッシュを理由とする再試行を廃止し、目標算定の基準量と評価の集約条件を分けた。個人目標は95°へ向けて増分を連続的に減らし、提示は回復期に開始する原則300 msとして次プッシュへの継続を許容する。状態別検証・副次計算式・直後評価も経験した後の同日内成績という解釈を詳細資料と発表版へ反映した。変更前後と採用理由は[決定台帳](decisions.md#変更管理)を参照する。
