# 分析計画

独立した単位は参加者。反復・姿勢サンプル・ログ行を人数に加えない。15名・各群5名の探索研究として、効果の大きさと不確実性を示す。[研究計画](study-plan.md)

## 主要評価

主要アウトカムは、20分休憩後・無FBの8の字1周時間の2反復平均[s]。開始音から目視による計時終了までで、反応時間を含む。[計測仕様](specifications/measurement.md)

`T(i,phase)=(t(i,phase,1)+t(i,phase,2))/2`

保持の平均時間を目的変数、群と事前の同じ平均時間を説明変数とするANCOVAで、A対V、A対Nの調整差と95%区間を示す。差はA−比較群とし、負ならAの時間が短い。両側の探索的p値2つはHolm法で調整し、有意水準0.05。95%区間は個々の比較の区間で、同時区間とは呼ばない。

小標本でモデル前提を保証できないため、個人データ・群別記述値・残差を併記する。事後に多数の共変量、交互作用、外れ値除外を加えない。非有意を同等性の証明としない。

## 副次・補助

| 項目 | 報告 |
|---|---|
| 直後8の字 | 2反復平均、事前・保持と合わせた個人の推移 |
| 快適速度の10 m直進 | 時間の2反復平均。短縮だけを技能向上としない |
| 左右車輪速度 | 元データからの探索的記述。解析区間・時計・欠測・平滑化を明記 |
| 主観評価 | NASA-TLXの6下位尺度、不快・疲労、理解・自由記述。独自総合点を作らない |
| 成立性 | 追跡・FBの有効率、中止、未完了、計時失敗、訓練量・休憩・再装着時間 |

接触角、接触回数、目標誤差、推進頻度、力、効率は今回の定量的な評価指標に含めない。手首は元データとして保存するが、事後のパターン分類を主分析へ追加しない。

## 欠測と逸脱

- 主要モデルは事前・保持の2反復が揃う参加者で行う。1反復だけの値は図に残し、1反復を認める記述は感度分析として別に示す。
- 未完了・計時失敗は理由を付けた欠測。規定の技術的再試行があれば、最初の成立した置換試行を使う。
- 追跡欠測だけで成立した手動時間を消さない。訓練FBが欠けた場合は介入逸脱として報告する。
- 割付群のまま報告し、成績に応じた除外や群の入替えをしない。同意撤回は同意・施設規則に従う。
- 完全例解析には選択の偏りが残る。割付人数、解析人数、欠測・中止理由を必ず群別に示す。

## 結果に残すもの

参加者フロー、群別の事前特性、各時点の平均・SD・中央値・範囲・n、個人の時間推移、主要2比較の調整差と区間、欠測・逸脱、機器・提示の検証結果を示す。

反応成分、手動操作、同日内の再テスト、非盲検、小標本という限界を記載する。車輪速度の変化だけから上肢負担低減や効率改善を主張しない。データ固定日、Gitコミット、設定、解析コード、全除外理由を保管する。
