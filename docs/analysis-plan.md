# 分析・結果報告の事前計画

研究仕様 v1.0／2026-10-14。データ取得前の分析方針。[研究計画](study-plan.md)・[実験手順](experiment-protocol.md)。実測データ・解析コードはまだない。本計測前に凍結し、変更は理由を残す。

## 単位・時点・主要アウトカム

独立した単位は**参加者**。同じ人の反復、プッシュ、動画フレームを独立した被験者として数えない。Nは割付人数と解析人数を別に示す。N=15、各群5名を計画し、予備参加者は混ぜない。

主要アウトカムは、**20分休憩後・無FBの8の字1周時間の2反復平均[s]**。事前の同じ2反復平均を共変量とする。

```text
T_i,phase = (t_i,phase,1 + t_i,phase,2) / 2
改善量（図示用） = T_i,pre − T_i,phase   # 正なら時間短縮
主要モデルのアウトカム = T_i,retention
```

2反復に同じ重みを与える。主要時点を直後へ変更しない。基準角度から作る目標誤差を、時間モデルの事前値として使わない。訓練から保持までの実際の遅延も併記する。

## 副次・補助アウトカム

| 分類 | 指標 | 集約 |
|---|---|---|
| 操作成績 | 直後8の字時間、各反復の接触・経路誤り・未完了・介入 | 時間は反復平均。エラーは人数・試行数・個人件数も併記 |
| 推進動作 | 中央直進区間の主要側推定接触角、目標絶対誤差 | 反復内で有効プッシュ平均→2反復を同じ重みで平均 |
| 周期 | 主要側の開始間隔の逆数[push/s] | 中央区間の連続する有効プッシュ対だけ。欠損をまたがない |
| 直進の走行 | 全10 m時間、10/T [m/s]、主要側の回数、10/N [m/push] | 反復ごとに計算→参加者内の反復平均 |
| 獲得過程 | 訓練セットごとの角度・状態の割合、有効FB数、走行本数 | 直進と8の字を分け、参加者ごとのセット値に集約 |
| 補助 | TLXの6下位尺度、理解正答率、快適性、疲労、機器・データ有効率 | 参加者単位で記述。主観負荷は精神と身体を分ける |

全10 mの回数／時間と、中央区間の開始間隔から求める頻度は区間・定義が異なるため、同じ列に混在させない。m/pushは距離当たりの回数に対応する指標で、代謝効率や推進力ではない。[L54](../research/papers/L54-askari-2013.md)

## 主要比較・推定・検定

```text
T_retention = β0 + βA × I(A群) + βV × I(V群) + βpre × T_pre + 誤差
N群を基準とする。
主要な2比較：A−N = βA、A−V = βA−βV。
```

通常の最小二乗ANCOVAを採用し、調整群差[s]と95%モデル区間を示す。負ならA群の時間が短い。共通の事前平均における調整平均も示す。主アウトカムを割合変化や最速反復へ取り替えない。事前値が完全に一定なら群のみのモデルにする。3群を含む設計行列が成立しない場合はモデル比較を行わず、個人データと記述値を示す。

主要2比較は両側とする。p値を示す場合はこの2比較を1つの族としてHolm補正し、未補正pと補正pを区別する。各95%区間は**個別のモデル区間**であり、同時95%区間ではない。p値を主たる結論の基準にせず、推定差と幅を中心に記述する。

全15名の事前・保持の完全データがある場合のみ、3名ブロック内の全6^5=7,776通りの割付を用いた探索的ランダム化検定を併記できる。統計量は、事前値のみのモデルに群を追加する2自由度のF統計量。各割付でモデルを再計算する。これは群全体の検定であり、2つの個別比較の検定や区間へ読み替えない。欠測後の参加者を勝手に詰め直して同じ検定を使わない。

分布・残差を図で点検するが、正規性検定の結果で主モデルを選び直さない。感度分析として `log(T_retention) ~ 群 + log(T_pre)` を同じ対象者で併記し、指数変換した比を示す。主結果と向きが異なる場合は両方を報告する。外れ値を見た後に除外・Winsor化・都合のよい変換をしない。

## 少人数での解釈

15名は募集可能性からの設定で、事前の検出力計算で十分と証明した人数ではない。大量のプッシュを記録しても、群比較の参加者数は各5名のまま。反復は各人の測定誤差を減らせるが、参加者の個人差を無限に埋めるものではない。[L48](../research/papers/L48-lakens-2022.md)

効果の実用的な大きさを判定する確立した閾値は、この研究用の課題・初心者には確認できていない。原著の検者間ICCから、最小重要差や学習効果の検出力を算出しない。[L53](../research/papers/L53-kamegaya-2021.md)

## 欠測・未完了・除外

| ケース | 主要時間の扱い | 報告 |
|---|---|---|
| 正しい経路で完了、接触あり | 時間を使う | 接触数とともに解釈 |
| 経路誤り、時間切れ、補助介入、痛み等で中止 | 完了時間は欠測 | 未完了と理由。60秒・0秒・平均値に置換しない |
| 技術的に動画が失敗 | 規定の再試行が成立すればその値を使用 | 元試行・再試行・遅延を保存 |
| 2反復のうち1回しか有効でない | 主要な2反復平均は欠測 | 1回の値は図・参考記述に残す。1反復も認める感度分析は別記 |
| トラッカー欠測、動画の8の字は成立 | 時間は使う | 推進データだけ欠測。FBの不成立は別の介入逸脱 |
| 同意撤回 | 同意・施設規則に従う | 撤回人数と対応可能な範囲を報告 |

基本は割付された群のまま報告する。未完了・技術欠測を理由に群を入れ替えたり、再募集を有意差に合わせて延長したりしない。主要モデルは事前・保持の2反復平均が揃う参加者で行い、割付人数・完全例人数・欠測理由を群別に示す。**欠測があれば完全例解析の選択の偏りが残る**ため、無条件のITT効果や全員での因果効果とは呼ばない。主要評価が欠けた場合の中心的報告は、個人データ・群の記述差・完了率とする。

角度の有効率不足による除外は推進指標にのみ適用する。目標へ近づかなかった参加者、高い基準角度、音が気に入らなかった参加者を事後除外しない。推進角度・頻度などへの変更で主アウトカムを救済しない。

副次指標は利用可能なデータを参加者単位で集約し、そのnを毎回付ける。欠測の多い群で「残った人は改善した」と一般化しない。プロトコル逸脱を除いた記述は感度分析として併記できるが、主報告の割付別結果を置換しない。

## 速度・正確さ・推進動作の関係

- 8の字時間と接触・経路誤り・未完了を同じ表・図で示す。速度改善にエラー増加が伴えば、その交換関係として記述する。
- 角度が大きくなっても時間が改善しない、時間だけ改善する、といった結果も残す。両方が同じ向きに変わることを前提にしない。
- 訓練後の速度・角度・練習回数は介入の影響を受けうるため、主要モデルへ自動的に共変量投入しない。
- 年齢・性別・体格・経験は記述に用い、15名で多数の交互作用や機械学習分類を探索しない。群の初期偏りを隠さない。
- 非有意を「同等」「効果なし」、群内だけの有意差を「群間差」と書かない。

## 必須の結果表・図

1. 参加者フロー：募集、同意、適格、割付、各評価の完了、解析人数と理由。
2. 群別の事前特性と、事前・直後・保持の平均・SD・中央値・範囲・n。
3. 全員の時間の折れ線図。群平均を重ね、未完了・欠測を記号と理由で表示。
4. 主要2比較の調整差と95%区間。尺度・方向・モデル・解析nを明記。
5. 接触・経路誤り・未完了・中止と、推進角度・頻度・速度の併記。
6. 提示有効率、実動・遅延、知覚の問題、仕様逸脱と機器性能の検証結果。

分析ログには文書版、設定版、採点版、データ固定日、使用ソフト版、全除外・欠測理由を残す。検定結果を見て主要時点・反復・仮説を変更した場合は、変更後の結果を事後探索と明記する。
