# 参加者への説明・理解確認・主観評価

実施者が読み上げる説明と、理解確認・訓練後の質問紙をまとめる。参加条件や同意書の準備は[実施運営](study-operations.md#募集・説明・同意)、当日の順序と時間枠は[実験手順](../experiment-protocol.md#90分の進行)に従う。

## 説明と理解確認

全員へ次の共通説明を行う。

> 直進では、無理のない範囲で、教わった長さを目安に滑らかにこいでください。低い音または左の印は、次を少し長めにする目安です。真ん中の高さの音または中央の印は今くらい、高い音または右の印は次を少し短めにする目安です。速く音を出すことや、左右に曲がることを求めているのではありません。痛みや不快感があればすぐに知らせてください。

個人目標を説明した後、割付開示前に全員が音と表示の模擬提示を受ける。座位で行い、車いすは動かさない。各10問（SHORT 3、TARGET 4、LONG 3）で状態と次にどうこぐかを答える。各9/10以上、3状態すべてに正答があることを目安とする。未達なら説明を1回繰り返し、同じ状態構成の別順序で再確認する。

模擬入力は目標との差 `e = θ − θ*` で作る。次の表は実施者だけが使う。参加者には角度数値や正答を同時に見せず、音またはマーカーを提示する。各300 msの提示後に回答を待ち、回答または5秒経過後に1秒空けて次問へ進む。状態と修正方向の両方が合って1問正答とする。

| 問 | 聴覚用e[°] | 聴覚の正答 | 視覚用e[°] | 視覚の正答 |
|---|---:|---|---:|---|
| 1 | −12 | SHORT・長めに | 0 | TARGET・維持 |
| 2 | 0 | TARGET・維持 | ＋8 | LONG・短めに |
| 3 | ＋12 | LONG・短めに | −8 | SHORT・長めに |
| 4 | −3 | TARGET・維持 | ＋3 | TARGET・維持 |
| 5 | ＋8 | LONG・短めに | −10 | SHORT・長めに |
| 6 | −8 | SHORT・長めに | ＋10 | LONG・短めに |
| 7 | ＋3 | TARGET・維持 | −3 | TARGET・維持 |
| 8 | −10 | SHORT・長めに | ＋12 | LONG・短めに |
| 9 | 0 | TARGET・維持 | 0 | TARGET・維持 |
| 10 | ＋10 | LONG・短めに | −12 | SHORT・長めに |

登録順が奇数なら聴覚→視覚、偶数なら視覚→聴覚とする。再確認は該当列を10問目から逆順で提示する。初回・再確認の正答数と所要時間を残す。枠を超えた場合は実施手順の90分上限に従い、休憩や主要評価を削らない。

再確認でも未達なら安全・理解の成立性を確認できないため割付へ進めず、その理由を記録する。模擬提示では車いすを動かさず、条件別の運動練習量を作らない。全員に両方を示すことでN群も音の意味を知るが、訓練中の動作依存FBは受けない。

## 主観評価用紙

参加者には「最後のセットだけでなく、3セットの練習全体を振り返って答えてください」と伝える。

補助評価は、最後の訓練セットを含む**訓練3セット全体**を対象に1回行う。直後課題を終えた後、52–57分の枠内で記入する。枠内に収まらなければ質問紙を欠測とし、20分休憩や主要評価を削らない。実施の有無・時点と省略理由を記録する。予備実験で1分程度に収まる用紙と説明を確認する。

NASA-TLXは[公式資料D08](../../research/papers/D08-nasa-tlx.md)と[日本語版原著L60](../../research/papers/L60-haga-1996.md)を参照する。今回は**6下位尺度を個別に記述**し、一対比較の重み付けを行わず、WWLや独自の総合得点を作らない。身体的負荷を認知負荷と混同しない。

| 下位尺度 | この研究での短い説明 | 回答（0–100、5点刻み） |
|---|---|---|
| 知的・知覚的要求 | 考える、見分ける、注意する負担 | 小さい 0 ─ 大きい 100 |
| 身体的要求 | 体を動かす負担 | 小さい 0 ─ 大きい 100 |
| タイムプレッシャー（時間的要求） | 急かされる感じ、時間の圧迫 | 弱い 0 ─ 強い 100 |
| 作業成績 | 自分で感じる課題の達成度 | よくできた 0 ─ できなかった 100 |
| 努力 | うまく行うために必要だった努力 | 小さい 0 ─ 大きい 100 |
| フラストレーション | いら立ち、不安、落ち着かなさ | 小さい 0 ─ 大きい 100 |

尺度名と端点の方向は原著表1（p.73）で確認した。この短い説明は本研究向けの説明案である。検証済み日本語版の文言と同一には扱わない。予備実験前に教員と説明の適切性を確認し、参加者向け用紙の文言を固定する。意味を変えた場合は変更内容を報告し、日本語版の妥当性をそのまま主張しない。

### 追加の質問

以下は独自項目として扱う。N群にも装着不快と疲労を尋ねる。提示の意味と使いにくさは、受けた提示について回答してもらい、N群に受けていない動作FBの有用性を尋ねない。

| 質問 | 回答 |
|---|---|
| 装着機器や提示に、どの程度の不快感がありましたか | 0–10 |
| どの程度の疲労を感じましたか | 0–10 |
| 音や表示の意味は分かりましたか | 理解についての回答 |
| 使いにくかった点があれば教えてください | 自由記述 |

A・V群の「役立った」という回答は主観評価として報告し、それだけで客観的な学習効果を結論にしない。
