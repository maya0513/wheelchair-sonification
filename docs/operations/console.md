# 実験中のPC操作

[導入・装着・接続](setup.md)を終えた実施者向けの操作手順。課題の順序と時間の判断は[実験手順](../experiment-protocol.md)に沿って行う。

## 四つの画面

| 画面 | 操作 |
|---|---|
| 準備・チェック | HMDと同じ案内・割当候補・結果を確認。詳細欄で入力・音量・校正・表示位置・眼球校正確認を調整 |
| 実験 | 参加者・群・時点・課題・反復を登録し、記録と正式計時を操作 |
| 回答 | 音・表示の見本、口頭回答、理解確認・質問紙を保存 |
| 記録 | 保存先・コピー結果を確認し、再回収・USB用書出しを操作 |

準備の状態と判定はHMDが管理し、PCは反映された状態を表示する。送信中・反映済み・失敗を確認し、理由付きで拒否された操作を繰り返し押さない。古い画面・同時操作・記録中の設定変更は拒否する。

## 記録と計時

1. 参加者IDと群を登録する。時点・課題・反復を選び「課題を登録」を押す。
2. 「記録開始」を押す。HMDの応答後、評価では「3秒準備 → 開始合図」を押す。
3. ゴールを見て「計時終了」またはSpaceを押す。入力欄・選択欄の編集中はSpaceを使わない。
4. 訓練では目安2分で「訓練終了・FB停止」を押す。安全に止まるまで元データを残す。
5. 安全停止後に「記録終了」を押し、PCへのコピー・照合を確認する。

評価は1本、訓練は2分のブロックごとに記録する。主ボタンは現在の状態に合わせて表示する。参加者・群・課題を変更したら登録し直す。正式な開始・終了・時計の定義は[計測仕様](../specifications/measurement.md#正式な走行時間)を参照する。

## 休憩と中断

2分・20分タイマーは通知だけで、自動終了・移行・操作制限はしない。休憩に入るときは時点を「休憩」にして「課題を登録」し、視線取得を止める。HMDを外してもPC時計は動く。

通常終了と「中止・未完了」を使い分ける。アプリの中止は車いすを制動しないため、身体の安全停止は実施者が行う。通信断、HMD中断、保存失敗では提示・試行を未完了停止し、復帰だけでは再開しない。

計時中にブラウザーを再読込した場合、動いていた時計を復元したように扱わず、中止して新しい記録でやり直す。終了済みの同じ試行を再計時せず、技術的再試行は別の試行IDにする。[中止・再試行の規則](../experiment-protocol.md#中止再試行)

視線の状態は機器欄、欠測理由・取得率は詳細欄に表示する。視線欠測だけで記録開始を禁止しない。車輪・車体の欠測時と視線欠測時の違いは[FB仕様](../specifications/feedback.md)・[記録形式](../specifications/recording.md)を参照する。

## 回答と記録の確認

[共通教示・理解確認・質問紙](participant-materials.md)に沿って回答を入力する。アプリは理解確認の自動合否や進行の禁止を設けない。

各試行の終了後に[回収結果](records.md)を確認する。未完了と未回収は別の状態として扱い、本計測開始の可否は[実施運営](study-operations.md#本計測開始条件)で判断する。

機器なしで配置や表示を確認する場合は[画像プレビュー](../development/xr-preview.md)を使う。実測の接続不良時に自動で模擬入力へ切り替えることはない。
