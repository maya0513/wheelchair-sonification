# 実施記録の様式

実施時に残す項目を、用紙や電子表へ転記するための一覧。参加者の記録は[データ管理方針](study-operations.md#データ管理)に従って保管する。計時・エラーの定義は[計測仕様](../specifications/measurement.md)、集約と欠測の扱いは[分析計画](../analysis-plan.md)に従う。

## セッション表

参加者ごとに1つの研究用IDを付け、次の項目を残す。

| 区分 | 記録項目 |
|---|---|
| 識別・同意 | 研究用ID、実施日、使用した同意書、同意・撤回の状態、実験者、安全補助者 |
| 参加特性 | 年齢、利き手、車いす接触経験、運動習慣、矯正視聴覚、当日の痛み・体調、必要最小限の体格 |
| 設定 | 椅子、クッション、フットサポート、空気圧、会場・床面、機器型番・ID、装着側、校正、ソフトウェアのバージョン、Gitコミット、使用設定の控え |
| 割付 | 登録順、ブロック番号、群、開示時刻。未開示の全順序は別管理 |
| 個人目標 | 基準角θ0、目標θ*、要求増分Δ、基準の反復別本数と成立、基準時点の目標範囲内／外 |
| 説明・提示設定 | 音量設定、模擬提示の初回・再確認の正答数、所要時間、再説明の有無 |
| 時間 | 訓練終了、直後評価の開始・終了、休憩の開始・終了、保持評価の開始・終了、取り外し完了 |
| 逸脱と体調 | 停止、校正やり直し、再試行、省略、仕様変更、中止、有害事象、その時刻と理由 |

## 評価試行表

元の試行と再試行にそれぞれ識別子を付ける。置き換えた試行も消さず、置換対象と理由を対応付ける。

| 区分 | 記録項目 |
|---|---|
| 試行の識別 | 研究用ID、試行ID、時点（pre／post／retention）、課題（F8／straight）、予定反復（1／2）、元試行／再試行、置換対象 |
| 計時 | 開始・終了の動画フレームと時刻、完了の有無、完了時間[s] |
| 正確さ | 接触回数または不明、経路誤りの有無と内容、補助介入、未完了・中止の理由 |
| 全10 mの直進 | 時間[s]、主要側のプッシュ回数、速度[m/s]、1プッシュ当たり距離[m/push] |
| 中央区間の推進 | 有効角数n、有効開始間隔数m、有効率、角度・周期の元データと集約値 |
| データの成立 | 正常計測での少数・0本、追跡や動画等の技術欠損、判定不能の区別と理由 |
| 採点 | 各担当者の初期値、不一致、合議結果、参照した元映像 |

未完了の経過時間と、正しく完了した時間を区別する。直進の全10 m指標と中央区間の指標は別の項目へ記録する。オンラインで提示した値と、事後再解析の値も分ける。

## 訓練・FB表

参加者・訓練セットごとの記録と、個々のプッシュ・提示の記録を対応付ける。

| 区分 | 記録項目 |
|---|---|
| セット | 研究用ID、セット番号、直進／8の字、開始・終了、実動・切替・休憩時間、はみ出し時間、完了本数 |
| プッシュ | イベントID、側、開始・離手・次接触の時刻、角度、3状態、有効／無効、欠測理由 |
| 提示 | 対象イベント、判定・提示依頼・開始・終了の時刻、候補・実提示・取消・打切り、実提示長、理由、使用した画面・音の設定 |
| 提示時点の検証 | 回復期の開始、次プッシュへの継続、次接触後に新規開始した逸脱、判定不能 |
| 追加の声かけ | 指導者の文言と時刻 |

アプリで記録した時刻と、外部検証で測った実出力時刻を区別する。候補数、無効数、取消数、実提示数を別に集計できるようにする。大量のプッシュやログ行を参加者数に加えない。[時計と保存方法](../development/logging-and-timing.md)

## 条件確定の記録

本計測で使用する条件を固定したときに、日付、確認者、使用するGitコミットと次の資料を保存する。実際に用いた条件を追えるようにする。

| 区分 | 保存する内容 |
|---|---|
| 設営・装着 | コース写真と寸法、椅子・機器構成、固定・装着方法 |
| 提示・判定 | 表示、音、音量、目標算定、提示時間、検出処理と設定の控え |
| 検証 | 検証データの範囲、調整用と最終確認用の区別、失敗を含む結果、採点方法 |
| 割付・分析 | 乱数種、割付管理者、分析方針と解析用設定 |
| 運営 | 倫理確認、最終の同意用紙、教員確認、保管先と担当者 |

群ごとの提示方式を本計測中に変えない。変更が生じた場合は、Gitで条件の差を追えるようにし、適用した参加者・試行と理由を実施記録へ残す。
