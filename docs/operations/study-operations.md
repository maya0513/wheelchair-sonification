# 実施運営

当日の順序は[実験手順](../experiment-protocol.md)、測定性能は[検証計画](../specifications/validation.md)を正本とする。

## 募集・安全・データ管理

車いす未経験の成人学生等15名を募集し、参加・辞退の任意性を説明する。教員・研究責任者が倫理手続き、同意書、事故時の連絡先、健康上の参加条件を確認するまで募集・本計測を始めない。機器試験と参加者実験を区別する。

実施者1名を基本案とする。現地で、コース全体を見ながらPCへ即時アクセスし、危険時に介助できるかを確認する。成立しなければ配置・補助体制・会場を見直す。アプリ上の中止は車いすを制動しない。痛み、酔い、疲労、不安、前方視認の不足、転倒のおそれでは安全停止を優先する。本人の申告で理由を問わず中止できる。

平坦で滑らない床、5 mのコーン間隔と10 m直線、停止余裕・障害物・人の進入を確認する。屋外は直射日光・低照度を避け、メーカーの条件と全走路の追跡を確認する。実空間が十分見えなければ走行しない。

研究IDだけを機器・PCへ入力する。実名・連絡先・同意書・対応表は計測データと別管理し、公開リポジトリ・Releaseへ入れない。[保存形式](../development/research-records.md)のPCコピーは現地回収先であり、学内の正式保管先とは別。責任者がアクセス権、保存期間、バックアップ・撤回期限を決める。元データ削除は照合・バックアップと規則確認後に行う。

## 本計測開始条件

| 条件 | 担当・必要な証拠 | 現状 |
|---|---|---|
| G1 倫理・同意 | 教員・研究責任者：学内判断・最終書類・連絡先 | 未確認 |
| G2 会場・安全 | 学生研究者・責任者：単独見守り、PC操作、停止余裕、使用許可 | 現地確認待ち |
| G3 計測・提示 | 学生研究者：未使用記録による速度・追跡・出力・知覚の検証 | 実機未検証 |
| G4 手順・負担 | 学生研究者・予備参加者：2–3名の通し予備実験、時間・疲労・理解 | 未実施 |
| G5 データ保全 | 学生研究者・責任者：実機回収と復元、正式保管先・期間・権限 | 責任者・実機確認待ち |
| G6 条件固定 | 学生研究者・教員：手順・分析・設定・ソース、割付表の確定 | 予備実験後 |

数値・条件を変えたら、影響する確認を再実施する。条件確定記録にはG1–G6の証拠への参照、未解決事項、判断者を残す。実装済み・署名済み・公開済みを開始許可としない。
