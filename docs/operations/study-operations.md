# 実施運営

参加者の受け入れ、担当の割当、安全確認、データ管理、本計測を始める条件をまとめる。当日の走行手順は[実験手順](../experiment-protocol.md)、機器と手順の確認方法は[検証計画](../specifications/validation.md)を使う。

## 担当と確認待ち

| 役割 | 担当する作業 | 確認が必要なこと |
|---|---|---|
| 学生研究者 | 日程、同意説明、実施、記録、分析、計画変更の管理 | 実名を実施記録へ登録する |
| 担当教員・研究責任者 | 目的・対象・安全性、倫理手続き、保管規則の確認 | 原資料の指導教員は塗木淳夫。現在の責任者と手続き上の役割は確認待ち |
| 安全補助者 | 事前の安全練習、走行の監視、停止・介入 | 1名の確保、日程、訓練は確認待ち |
| 採点担当2名 | 群・時点を伏せた動画の計時とエラー確認 | 学生研究者と協力者を想定。割当は確認待ち |

## 対象と割付

本標本は車いす未経験の成人学生等15名とし、聴覚（A）・視覚（V）・追加FBなし（N）へ各5名を割り付ける。予備実験の2–3名は本標本と分ける。

対象は、18歳以上で日本語の教示と同意を理解でき、手動車いすを日常利用せず、正式な車いす技能訓練・車いすスポーツの経験がない人とする。一時的に座った経験だけでは除外せず、その内容を記録する。

現在の上肢・体幹の痛み、運動を妨げる状態、矯正しても走行路・表示を視認できない状態、3音を識別できない状態、椅子・装着機器が適合しない状態では参加を見合わせる。自己申告で確認し、適否が不明なら担当教員と相談する。研究者が診断することはしない。募集条件と中止基準は倫理手続きで確認後に使用する。

割付は、同意、適格性、共通習熟、事前評価、個人目標の基準量、模擬提示の理解を確認してから行う。基準量不足と理解確認の未達は、割付前のフローに理由を分けて残す。[基準量の条件](../specifications/feedback.md#個人目標と3状態)・[理解確認](participant-materials.md#説明と理解確認)

A・V・Nの6通りの順列から各ブロック1つを無作為に選び、3名ブロックを5つ用意する。初回募集前に乱数種、作成日、作成者、割付順を保存する。事前評価中の担当者には順序を開示せず、封筒または権限を分けた一覧から登録順に開示する。未開示の全順序は通常のセッション表と別に管理する。

欠測や成績を理由に割付を入れ替えない。固定ブロックでは次の割付を推測できる場合があるため、完全な盲検化とは扱わない。

## 募集・説明・同意

募集には学内手続きで許された方法を使う。研究者や教員との関係で断りにくくならないよう、成績・評価と参加は無関係で、不参加・撤回に不利益がないことを説明する。謝礼の有無、金額、支給条件は責任者と確認してから募集文へ記入する。

募集文では、成人の車いす未経験者を対象とすること、平地で直進と8の字を行うこと、装着機器と音・表示を使う場合があること、1回来訪90分以内であることを伝える。脳波測定は行わない。動画撮影、痛み・疲労・機器不快等による中止の自由、無作為割付により希望した条件に入るとは限らないことも説明する。

同意書を確定する前に、次の事項を確認する。

- 研究責任者と相談窓口の連絡先、倫理手続きの名称・番号・承認日、または学内の適用判断。
- 取得する属性、動作・動画・主観評価、研究目的、利用範囲、卒論・発表での扱い。
- 想定する負担、転倒・接触・疲労・装着不快への対応、中止できること。
- 撮影範囲と音声、顔の映り込み、画像の公開。顔が映る映像の発表利用は通常の計測同意と分けて確認する。
- 保存先、アクセスできる人、保管年限と削除方法、対応表の管理、撤回期限と削除できる範囲。
- 謝礼、事故時の学内対応と連絡、不参加による不利益がないこと。

実名の連絡先、年限、承認番号は確認した情報を記入する。必要事項が決まってから募集・本計測へ進み、説明の理解を確認して署名を得る。[参加者用資料](participant-materials.md)は説明と質問紙の準備用で、承認された同意書の代わりにはならない。

## 会場・機器・安全

会場はフットサルコート1面程度の広さとの申告がある。床材、屋内外、実寸、追跡可能範囲は未確認である。現地でコースと停止域を実測し、滑り、傾き、床の段差、配線、障害物、他者の出入りを点検する。

ゴーグルはユーザー確認によりVIVE Focus Vision。計測用トラッカーの型番・台数・接続先・性能は実物確認待ちで、標準コントローラーとは区別する。原発表の製品名から計測系の仕様を推測しない。椅子の車輪、空気圧、固定、ブレーキ、フットサポート、トラッカー固定具との干渉を点検する。柔らかいコーンを使い、停止に必要な余裕を確保する。

実空間が安全に見え、表示を見ても走行路を失わず、音が安全指示を妨げないことを確認する。Focus Visionのパススルー機能を使用する構成だが、実際の視認性と提示遅延は未検証である。視認性が成立しなければ実走行を始めない。

停止合図と安全補助者の位置は習熟中に練習する。痛みの発生・増悪、めまい、強い疲労、不安、機器不快、安全を保てない状況では中止する。無理な角度や速度の達成を求めない。中止理由と取得済みデータの使用意向を記録する。[試行中の中止と再試行](../experiment-protocol.md#試行成立と再試行の規則)

終了時に体調、痛み、違和感を確認し、問題があれば事前に決めた学内の対応へつなぐ。研究者による診断・治療は行わない。

## 本計測開始条件

| ID | 確認すること | 確認者・証拠 | 現在の状態 |
|---|---|---|---|
| G1 | 倫理手続き、募集、同意、撤回、保管規則が決まっている | 責任者、確認記録・承認情報・最終用紙 | 確認待ち |
| G2 | 会場、椅子、安全補助者、実空間の視認性が確保されている | 現地写真、寸法、点検票、補助者訓練 | 確認待ち |
| G3 | 接触角、3状態判定、追跡、回復期の提示開始、実出力が検証されている | 未使用記録での状態別件数・精度、誤差、有効率、提示記録 | 未実測 |
| G4 | 90分の通し手順で、課題理解、知覚、負担が確認されている | 2–3名の予備記録、逸脱と修正点 | 未実施 |
| G5 | 書類、設定、分析、割付の条件が固定されている | [条件確定の記録](record-forms.md#条件確定の記録)、使用するGitコミット、担当者 | 未実施 |
| G6 | 日程、保管先、バックアップ、当日の担当が確保されている | 日程表、アクセス確認、当日点検票 | 確認待ち |

G1–G6をすべて満たしてから本計測を始める。募集はG1で確認した範囲と確保できる日程に従う。予備実験も、必要な学内手続き、同意、安全確認を先に終える。機器の受入れ基準と通し予備実験の項目は[検証計画](../specifications/validation.md)を使う。

## データ管理

研究用IDと実名の対応表、同意書、参加者の映像・生ログは、学内で認められたアクセス制限のある保管場所へ保存する。公開リポジトリへは置かず、対応表を動作データから分ける。アクセス担当、保管期間、削除方法、バックアップ先、撤回受付期限を責任者と決め、同意書へ反映する。実際の保管先と年限は確認待ちである。

採点には、音声と不要な識別情報を外した動画の複製を使う。元データは保持する。匿名IDでも映像や体格から識別される可能性があるため、完全匿名とは断定しない。公開結果は集約表・図を基本とし、個人映像や生データの公開には別の同意と学内確認を得る。

使用した機器、校正、設定、ソフトウェア、Gitコミット、試行の中断や欠測理由は[記録様式](record-forms.md)に残す。ログの技術的な保存方法は[開発資料](../development/logging-and-timing.md)を参照する。

## データ収集終了までの工程

2026年12月20日頃までの収集終了を目標とし、機器不調等に備える予備日を残す。

| 時期（2026年） | 必要な成果 |
|---|---|
| 10月14日–25日 | 教員確認、倫理手続きの見通し、会場・機器・補助者確認、研究条件の整理 |
| 10月26日–11月8日 | 装置実装、角度、視認性、遅延、動画の検証 |
| 11月9日–15日 | 2–3名の通し予備実験、条件確定、G1–G6の確認 |
| 11月16日–12月13日 | 15名の本計測。1回来訪90分以内 |
| 12月14日–20日 | 機器不調等の予備日、収集終了、データ点検 |

倫理手続きや開始条件が間に合わない場合は、教員と範囲・日程を再検討する。追加募集は有意差や特定群の成績を見て決めない。変更が必要なら理由、適用時点、人数、割付計画を先に定める。脳波、独立した転移課題、複数変数のFBを加える場合は、[計画変更の手順](../decisions.md#計画を変更するとき)で扱う。
