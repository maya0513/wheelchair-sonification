# 実験当日の手順

実施者が、機器の準備から記録の回収までを当日の順序でたどるための入口です。各手順の詳しい操作は、それぞれの手順書にあります。当日の進行と課題の進め方は[実験手順](../2_experiment-protocol.md)が定め、ここでは手順書同士のつながりだけを示します。

## 当日の流れ

| 順序 | 手順書 | 終わるとどうなるか |
|---|---|---|
| 1. 準備 | [導入・装着・準備](1_setup.md) | アプリとPCを用意し、トラッカーの接続と固定、動作確認とフィードバック検査を終えた状態になる |
| 2. 説明 | [参加者への説明と質問項目](2_participant-materials.md) | 参加者が共通の教示を聞き、理解確認と質問紙への回答を終えた状態になる |
| 3. 実施 | [実験中のPC操作](3_console.md) | 課題と反復をPCで選び、記録と正式な計時を行った状態になる。進行の判断は[実験手順](../2_experiment-protocol.md)に従う |
| 4. 回収 | [保存先と記録の回収](4_records.md) | 各試行の保存、PCへのコピー、バックアップを確認した状態になる |

準備にはゴーグル単体の案内付きチェックも使えます。本実験中、参加者はメニューやコントローラーを操作しません。

## 当日以外の運営

募集と安全、データ管理、日程、本計測の開始条件G1–G6は[実施運営](study-operations.md)で扱います。当日に始めるかどうかは、実施運営の開始条件を確認してから判断します。

保存される内容の意味は、手順ではなく[記録形式](../specifications/recording.md)が定義します。回収の操作だけを行う場合は、このページの「4. 回収」から進みます。
