# 決定台帳：実装前に決めること

研究仕様 v1.1／2026-10-15。[資料入口](README.md)。研究の目的・条件と、まだ得られていない事実を混ぜないための台帳。コード・SDK・検出アルゴリズムの詳細は対象外だが、計測・提示が成立する条件は研究方法の一部として定義する。

## 状態の読み方

| 略号 | 状態 | 意味 |
|---|---|---|
| U | ユーザーと確定 | 会話または承認された計画で採用方針を決定。実機・倫理承認の完了を意味しない |
| D | 今回の設計案 | 詳細化のために設定した値・手順。本計測前の予備確認・凍結で採否を記録 |
| F | 実機・現地確認待ち | 型番、床面、性能等の事実がまだ分からない |
| E | 教員・倫理手続きの確認待ち | 学内規則や責任者の判断が必要 |

### v1.1の変更理由と適用

| 項目 | 変更前→変更後 | 理由・確認 |
|---|---|---|
| 必要本数・再試行 | 各反復3本未満で追加可→基準は2反復合計4本・各1本、評価は指標別集約、正常な少数では追加なし | 動作変化による欠測・追加練習を抑える。初期本数の安定性・成立率は予備で確認 |
| 3状態の検証 | 合算一致率のみ→状態別適合率・再現率・件数と境界帯を追加 | 特定状態の失敗が平均で隠れないようにする。調整用と最終確認用を分ける |
| 個人目標 | 95°直前で100°へ増大、95°から維持→95°へ連続的に増分を減らす | 高基準での維持方針を残し、閾値の跳びをなくす。増分・範囲内人数を群別に報告 |
| 提示 | 回復期の意味が曖昧→回復期に開始、次プッシュへの継続可、遅れた新規開始は取消 | 300 msと開始相を両立。領域外等では実行中も終了。実出力・取消・継続を検証 |
| 副次解析 | 演算順序・比較方針が未固定→式と3時点の探索的記述を固定 | 計算の選択で結論を変えない。主要2比較を維持 |
| 保持・出典 | 直後評価の影響・L17の版差が本文で不明瞭→詳細・発表版と文献ノートへ補足 | 同日内評価の範囲と数値の参照版を明示 |

計画としての改訂はユーザーの修正指示に基づき採用し、数値の初期設定はDとして予備確認に残す。全変更は本計測前に適用する。主アウトカム・3群・15名・来訪90分・再来訪なし・EEGなしを維持し、予定の本標本の参加負担を増やさない。予備検証の追加走行、同意書への反映、手続き上の再確認は責任者と確認し、G1–G6が揃ってから凍結する。
