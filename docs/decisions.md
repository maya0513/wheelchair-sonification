# 決定台帳：実装前に決めること

研究仕様 v1.0／2026-10-14。[資料入口](README.md)。研究の目的・条件と、まだ得られていない事実を混ぜないための台帳。コード・SDK・検出アルゴリズムの詳細は対象外だが、計測・提示が成立する条件は研究方法の一部として定義する。

## 状態の読み方

| 略号 | 状態 | 意味 |
|---|---|---|
| U | ユーザーと確定 | 会話または承認された計画で採用方針を決定。実機・倫理承認の完了を意味しない |
| D | 今回の設計案 | 詳細化のために設定した値・手順。本計測前の予備確認・凍結で採否を記録 |
| F | 実機・現地確認待ち | 型番、床面、性能等の事実がまだ分からない |
| E | 教員・倫理手続きの確認待ち | 学内規則や責任者の判断が必要 |

追加変更は、変更前後、理由、主アウトカム・群比較・参加負担への影響、決定者、適用時点、教員・倫理手続き上の再確認を記入する。本計測開始後の変更は逸脱として残し、変更前後を同じ条件として黙って統合しない。脳波・別FB方式・別コースの導入は新しい計画変更として扱う。
