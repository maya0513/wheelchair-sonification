# 設計上の判断

研究方法を選んだ理由と、代替案を採らなかった理由をまとめます。実施する条件の詳細は[実験手順](experiment-protocol.md)、[フィードバック仕様](specifications/feedback.md)、[分析計画](analysis-plan.md)で確認します。実機・現地・倫理手続きの確認状況は[実施運営](operations/study-operations.md#本計測開始条件)で管理します。

## 走行・旋回成績を主要評価にする

研究の関心は、漕ぎ方の再現だけでなく、車いすを操作する技能にあります。測定可能な範囲を平地での直進・旋回・加減速へ絞り、8の字の所要時間を主要評価とします。推進角は副次評価として併記し、漕ぎ方だけが変わった場合も操作成績だけが変わった場合も報告します。

時間は接触・経路誤り・未完了と合わせて読みます。エラーへ独自の秒数を加えると、速さと正確さのどちらが変わったか分かりにくくなるため、別の変数として残します。

## 並行3群で比較する

同じ人にすべての条件で学習してもらうと、先の練習を元へ戻せず、学習の持越しと提示方法の効果を分けにくくなります。そのため、聴覚・視覚・追加FBなしの並行群を使います。

15名は募集と実施の見通しから設定した規模です。十分な検出力を前提にせず、個人差と推定の幅を示します。共通教示だけでも動作が変わりうるため、N群にも同じ教示、目標、練習を与えます。[Lakens 2022](../research/papers/L48-lakens-2022.md)、[Rice 2013](../research/papers/L19-rice-2013.md)

## 直進と8の字を両方練習する

8の字は、左右旋回と加減速を短時間で評価でき、成人の両上肢駆動に近い先例があります。ただし、原著が検証したのは同じ走行を測る検者間の一致です。学習への反応性や再テスト信頼性は未検証のため、予備実験では今回の計時のばらつきと手順の成立性を確認します。[亀ヶ谷ら2021](../research/papers/L53-kamegaya-2021.md)

直進は推進動作を分けて測るために使います。評価では主要課題の8の字を先に行い、直進の追加練習が主要評価の直前に入ることを抑えます。どちらも訓練するので、再評価は独立した転移テストとは呼びません。

ボールを持つ課題は、注意の負荷に加えて手の使い方や推進方法も変えます。負荷を増やせば初心者の群差が明瞭になるとは限らず、今回は設けません。将来検討する場合は、副課題の正答や速度も測り、両課題の交換関係を評価します。[Salm 2025](../research/papers/L58-salm-2025.md)

## 推進角を走行中に伝える

進路からのずれを教える方法もありますが、本研究では推進動作への支援を扱います。接触角を計測・検証し、同じ情報を音と表示へ変換できるためです。操作成績への効果は間接的なので、角度だけの改善を走行技能の向上とは解釈しません。[FB内容の比較](../research/topics/feedback-design-alternatives.md)

接触角は離手まで確定しません。そこで、直前のプッシュへの情報を回復期に返します。開始済みの提示は次のプッシュへ続いてよいとし、遅れた情報を次の接触後に新しく出すことは避けます。300 msという提示長と開始時点をそれぞれ管理するための設計です。区間終了後の要約FBは条件を揃えやすい方法ですが、走行中の支援を調べる目的から採用しません。[Symonds 2016](../research/papers/L17-symonds-sensewheel-2016.md)、[Yan 2021](../research/papers/L14-yan-2021.md)

旋回には左右差が必要です。直進用の角度目標を旋回へ適用したり、左右対称性を旋回の成功指標にしたりしません。[Soltau 2015](../research/papers/L31-soltau-2015.md)

## 情報量と装着条件を揃える

3状態の音とマーカーは、比較する情報を揃え、実装と理解確認を進めやすくするために選びます。周波数や提示時間は本研究の設計値で、最適な処方として実証された値ではありません。視覚だけに数値や履歴を加えること、音楽・音量変化・定位を重ねることは、感覚以外の違いを増やすため避けます。

提示頻度の漸減や自己要求方式は、今回の人数で扱う比較要因に加えません。候補数と実提示数は分けて記録します。全員が割付前に両方の提示を動作なしで学び、条件別の追加練習や事後除外を作らないようにします。機器は全群で揃え、装着負担の差も抑えます。

## 個人目標と必要なデータ量を分ける

高い基準角では維持を求め、95°未満ではその値に近づくほど要求する増分を小さくします。これにより、境界で目標が跳ぶことを避けます。個人目標は臨床的最適値ではなく、増大・維持の別、要求増分、基準時点で既に許容範囲にある人数を報告します。[目標の算定](specifications/feedback.md#個人目標と3状態)

目標を決める基準角の必要量と、評価指標を計算するための必要量は目的が異なります。正常な計測でプッシュが少ない場合に追加走行させると、動作変化によって練習量が変わり、欠測にも偏りが生じます。本数だけを理由に再試行せず、基準量不足は割付前のフローへ、算出できない評価値は指標ごとの欠測へ記録します。必要量の安定性は予備実験で確認します。

## 同日内の評価に範囲を絞る

1回来訪90分以内で実施するため、主要評価は20分の休憩後に置きます。休憩前の直後評価も課題経験になるので、訓練だけによる保持は分離できません。全群の予定評価量を揃え、技術的な再試行の回数と遅延も記録します。翌日以降の保持と同等には扱いません。[運動学習の整理](../research/topics/motor-learning.md)

脳波計は未到着で、今回の装着・取得・同期・分析には組み込みません。認知負荷は主観評価を補助的に使います。将来検討する際の機器品質と解釈上の制約は、[簡易EEGの文献レビュー](../research/topics/eeg.md)にまとめています。

## 先行課題から取り入れる部分

| 要素 | 原著・先例 | 本研究で加える条件と注意点 |
|---|---|---|
| 8の字 | 5 m・1周、健常成人、2検者のストップウォッチ | 各時点2反復、動画計時、訓練への使用を加える |
| 姿勢・椅子 | 原著はAR-101等、背部を離さない指示 | 手元の椅子で設定を記録し、姿勢を揃える。無理な固定はしない |
| 時間上限 | L53に上限の記載なし。別のWC課題では60秒 [L57](../research/papers/L57-kilkens-2004.md) | 8の字1反復60秒を運用上の初期上限とする |
| 直進 | WPTは10 m、普段の方法・速度、複数の駆動法が対象 [L54](../research/papers/L54-askari-2013.md) | 前進・両手駆動、2反復、中央6 mの角度解析、動画を加える |
| m/push | WPTのm/cycleは推進距離の指標 | 代謝的・機械的効率とは解釈しない |

変更した条件に原著のICCをそのまま当てはめず、今回の測定で誤差と成立性を調べます。機器検証では全体平均だけで特定状態の失敗を隠さないよう、状態別の精度と境界付近を確認します。L17の結果にある受理稿と出版最終版の差は、[文献ノート](../research/papers/L17-symonds-sensewheel-2016.md#参照版と数値の差)で参照する位置を区別します。

## 計画を変更するとき

本計測前に、機器・現地・倫理手続きと予備実験の確認を終え、使用する条件を固定します。文書の変更理由、判断者、適用時点、主要評価・群比較・参加負担への影響はGitのコミットまたはPRで追えるようにします。必要な教員確認・倫理手続き上の再確認も行います。

本計測開始後の変更や手順からの逸脱は、適用した参加者・試行と理由を[実施記録](operations/record-forms.md)へ残します。変更前後を同じ条件として黙って統合しません。角度FBから頻度FBへの変更、別の提示方式、コース変更、脳波の追加は研究計画の変更として扱います。主要2比較以外の分析を結果を見て加えた場合は、事後探索と明記します。
