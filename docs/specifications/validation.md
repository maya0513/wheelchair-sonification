# 機器検証と通し予備実験

接触角とFBの技術性能を確かめた上で、参加者が当日の手順を安全に終えられるかを確認する。ここで示す数値は本研究の初期受入れ目標であり、達成済みの性能や、先行研究が保証した閾値ではない。本計測を始める最終判断には[開始条件G1–G6](../operations/study-operations.md#本計測開始条件)を使う。

## 検証の進め方

既知角度の模擬入力による処理確認、動画参照による検出・角度・状態の検証、参加者の提示理解、90分の通し実施を、それぞれ確認する。模擬入力で正しく動くことだけでは、実動作の計測精度は分からない。

閾値・校正・検出法を調整する記録と、最終確認に使う記録を走行単位で分ける。最終確認は設定を固定した後の未使用記録で行い、少なくとも2名の予備参加者を含める。直進の往復、加減速、姿勢差、再装着で確認する。

機器検証に追加走行が必要な場合は、90分の参加者手順へ黙って加えず、事前の同意と安全確認を満たす別の予備検証として実施する。調整後は失敗した確認結果も残し、別の未使用記録で最終確認する。同じ記録の再生は回帰確認として使う。

## 機器の受入れ基準

| 項目 | 初期の基準と記録 |
|---|---|
| 接触イベント | 動画参照と一致窓±50 msで1対1に対応付け、適合率・再現率・F1を記録する。F1≥.90、イベント時刻のMAE≤50 ms |
| 推定接触角 | 対応が成立した区間で、角度MAE≤3°、絶対平均偏り≤2°。未検出・誤検出を別に報告する |
| 3状態 | 全体正答率≥90%、各状態の適合率・再現率≥80%。検証量と境界付近の条件は次節に従う |
| 追跡 | 全方向・再装着後を含め、中央区間の有効率≥95%を目標とする |
| 提示 | 原則300 ms、判定確定から実提示開始まで200 ms以内を目標とする。実開始は離手後・次接触開始前であること |

MAEは誤差の絶対値の平均、偏りは符号付き誤差の平均を指す。適合率は出力したうち正しかった割合、再現率は参照イベントのうち正しく返せた割合、F1はその両方をまとめた値である。

動画は接触候補の参照であり、力が出た推進相の正解ではない。一致した区間の小さな平均誤差だけで性能を判断せず、検出できなかった区間、参照の遮蔽、判定不能の件数と理由も残す。人数、試行数、本数、角度範囲、誤差範囲を報告する。

## 3状態の技術検証

各人の固定目標と参照角度から、推定結果を見ずに参照状態を付ける。同じプッシュに多数の仮想目標を当てて本数を増やさない。参照側のSHORT・TARGET・LONGがそれぞれ30本以上あることを初期の必要量とする。

両境界（θ*−5°、θ*＋5°）の上下それぞれ2°以内を各5本以上含める。境界帯の件数、角度誤差、状態一致は別に示す。状態を作るために痛みのある動作や無理な可動域を求めない。安全に必要な範囲を検証できなければ、範囲、目標、許容幅の設計を見直す。

| 判定項目 | 定義と条件 |
|---|---|
| 全体正答率 | 正しく検出・分類できた参照プッシュ数／全参照プッシュ数≥90%。未検出・無効も分母に含める |
| 状態別再現率 | その参照状態を正しく返せた数／その参照状態の全件数≥80%。3状態すべてで満たす |
| 状態別適合率 | その状態を正しく返せた数／その状態として出力した全件数≥80%。余分な検出も分母に含め、出力0件は合格としない |
| 混同行列 | 参照3状態と「参照なし」、推定3状態と「未検出・無効」を区別し、誤分類・未検出・余分な検出を残す |
| 検証量・範囲 | 参照各状態30本以上、各境界の上下2°以内を各5本以上。人数、走行、側、方向、角度範囲、再装着を記録する |

全体平均だけで特定状態の失敗を隠さず、検出不成立や境界例を後から捨てない。1状態でも条件を満たさない場合や検証量が足りない場合は、受入れ条件を満たしたとは扱わない。検出法や許容幅を調整した場合は、未使用記録で再確認する。30本、80%、境界帯の幅と本数も、本研究の初期設計値である。

## 提示時点の確認

離手、判定、提示依頼、実提示の開始・終了、次接触開始を区別して測る。音と画面のそれぞれで、次を記録する。

- 回復期に実提示を開始できた割合。
- 開始済みの提示が次のプッシュへ継続した割合。
- 次接触後に新規開始した不適合。
- 領域離脱や遅延等による取消・打切りと、その理由。
- 候補数、実提示数、実提示率、実提示長。

200 ms以内でも回復期開始の条件を外れれば適切な提示として扱わない。時点を判定できない例を成功に数えず、実提示が得られない場合や時点の検証ができない場合はG3を完了としない。条件間で取消・打切りが偏るときは、同じ数のFBを与えられたとは報告しない。[実出力を測る方法](../development/logging-and-timing.md#音と表示の実出力を測る)

## 通し予備実験

本標本とは別の2–3名で、必要な同意と安全確認の下、90分の手順を通す。少人数の予備実験で検出力、臨床的妥当性、一般的安全性を保証することはできない。

| 確認する項目 | 記録と判断 | 成立しない場合 |
|---|---|---|
| 課題理解 | 1周の経路、終了線、停止を自力で理解できるか | 共通説明と図を見直し、再確認する |
| 床・設営 | 5 m・10 mの寸法、停止余裕、安全補助者の位置 | 会場を調整する。短縮する場合は研究条件の変更として扱う |
| 計時 | 2採点者が開始・最終通過を特定できるか。差が0.2秒を超える例はすべて再確認 | 撮影角度と定義を改善して再採点する |
| 基準量 | 事前2反復合計4本以上・各反復1本以上の成立率、角度分布、反復間差。正常な少数プッシュでは追加走行しない | 不足が頻発する、または基準が不安定なら、全員共通の区間・必要量を本計測前に再設計する |
| 機器性能 | 接触イベント、角度、3状態、追跡、提示が上記基準を満たすか | 検出、固定、参照法、追跡配置、提示系を見直し、再検証する |
| 知覚 | 座位の模擬理解に加え、走行中も3状態を区別でき、不快・危険な視線移動がないか | 表示位置、大きさ、提示時間等を条件間で揃えて再確認する |
| 負担 | 両課題と訓練19分を安全に実行できるか | 運動量と教示を見直す。差を作るために負荷を増やさない |
| 時間・記録 | 90分以内に終わり、20分休憩、必要な2反復、動画、状態、欠測理由が揃うか | 本計測前に手順を見直す |

成立した条件と失敗を含む確認結果を[条件確定の記録](../operations/record-forms.md#条件確定の記録)へ残す。角度が成立しない場合に頻度へ自動置換することはせず、[研究計画の変更](../decisions.md#計画を変更するとき)として判断する。
