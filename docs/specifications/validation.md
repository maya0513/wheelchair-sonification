# 検証計画

数値は本研究の初期受入れ目標であり、保証された機器性能ではない。[計測仕様](measurement.md)と[FB仕様](feedback.md)を対象とし、調整用と最終確認用の記録を分ける。ソフトウェアの合成入力試験は、実動作の精度検証を代替しない。

## PCで確認すること

| 対象 | 確認例 |
|---|---|
| 回転速度 | 左右既知速度、逆回転、359°→1°、傾斜軸、車体旋回・平行移動、同時刻・欠測・再接続 |
| 提示 | 同じ平滑値から音と棒を作る。上限は提示だけ。停止付近のヒステリシス、左右独立、欠測で両側停止、手首欠測だけでは停止しない |
| 計時 | 固定時計による3秒準備、開始音、手動停止、取消、二重操作、通信遅延との独立、入力中のSpace無効 |
| 保存 | 正常・中断、保存失敗、試行別転送、SHA-256照合、不一致・再回収、再起動。旧形式を拒否 |
| 再生 | 保存した位置姿勢・時刻・校正から、左右速度と提示値を同じ処理で再生成 |
| 画面・音 | 共通Unity UIのPNGと実ブラウザー画像を目視。共通音生成処理のWAVを分析し、試聴可能な一覧を残す |

20分を実際に待つ試験は行わず時計を進める。90分継続試験は任意実行とし、ビルド・公開の必須待機条件にはしない。

## 実機・現地の受入れ

| 項目 | 初期目標・残す情報 |
|---|---|
| 角変位 | 車輪の印と角度目盛で既知角を左右・前後・再装着後に確認。MAE≤3°、絶対平均偏り≤2°を目標。接触角の検証ではない |
| 回転速度 | 安全な固定状態で一定時間の回転数を別の時計と数える。複数速度・左右・逆回転で平均速度誤差≤5%または0.03回転/秒の大きい方。参照誤差も記録し、瞬時速度の精度とは分ける |
| 追跡 | 全走路・旋回を含め、左右車輪と車体の同時有効率≥95%。手首有効率を別集計 |
| 出力遅延 | 入力からAPI要求、音・画面の実出力を区別。実測可能な収録機器を借りられる場合、同一時間軸で測る。入力変化から出力変化まで200 ms以内を初期目標。機器がなければ未検証とし、API時刻で代用しない |
| 音・視認 | 左右を聞き分け、停止・速度差を理解できる。走行中も前方確認・停止指示を妨げず、連続2分で不快・疲労を確認。正弦波だから快適とはみなさない |
| 計時 | 実際のPCスピーカーの合図が走路全体で聞こえる。手動停止の操作位置と反応誤差を反復確認。Web Audioの予定時刻を実音時刻とみなさない |
| 運用 | 5台・通信・電池・容量、HMD着脱、再接続、両側回収、停止・中断。単独で見守りとPC操作を両立できるか |

既知角の確認は固定具と車輪が安全に支持される場合だけ行う。無理な持ち上げや走行中の手作業はしない。速度の基準値に、同じトラッカーから作った値を使わない。

## 通し予備実験

必要な手続きの後、本標本外の2–3名で[90分の手順](../experiment-protocol.md)を通す。時間、負担、理解、単独見守り、20分休憩と再装着、全反復の保存を記録する。調整後は未使用記録で再確認する。90分以内に成立しない場合、休憩や評価をその場で削らず計画を見直す。

確認記録には日時、担当、機器・設定・ソース識別、参照方法、人数・本数・範囲、成功と失敗、未確認項目を残す。[G1–G6](../operations/study-operations.md#本計測開始条件)の判断は責任者と行う。
