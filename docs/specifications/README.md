# 仕様と定義

この研究で使う定義と数値の正本は、このフォルダの4件です。解説や手順書には必要な要約を置きますが、定義や設定を変えるときは、必ずこの4件から更新します。

## 4件のつながり

車輪の回転は、まず[計測仕様](measurement.md)で回転速度として求め、正式な走行時間もここで定めます。次に[FB仕様](feedback.md)が、その速度を音と縦バーへ変える方法と、提示する場面を定めます。実施した内容は[記録形式](recording.md)が定める形式で保存します。[検証計画](validation.md)は、この3件が実機と現地で満たすべき確認方法と受入れ目標を定めます。

| 正本 | 定めること | 定めないこと |
|---|---|---|
| [FB仕様](feedback.md) | 返す情報、速度の処理、音、縦バー、提示条件 | 計時と採点、記録の列 |
| [計測仕様](measurement.md) | 正式な走行時間、回転速度の記録、機器の識別と校正 | 提示値の計算、統計の集約 |
| [記録形式](recording.md) | 保存するファイル、列の意味、座標系、時計、有効性 | 保存先へのコピーと回収の操作 |
| [検証計画](validation.md) | PCで確認すること、実機と現地の受入れ目標、通し予備実験 | 機器性能の保証。数値は本研究の受入れ目標であり、保証された性能ではない |
