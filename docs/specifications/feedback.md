# 車輪速度フィードバックの仕様

本研究で返す情報・音・表示の正本。課題と進行は[実験手順](../experiment-protocol.md)、時計と採点は[計測仕様](measurement.md)、記録列は[保存形式](../development/research-records.md)を参照する。

## 返す情報

左右車輪の、車体に対する符号付き回転速度を独立に求める。単位は回転/秒（rps）。元の符号付き速度を保存し、提示には平滑化した速度の絶対値を使う。前進と後退が同じ速さなら、同じ表示・音になる。接触角、推進力、肩の負担を測る方式ではない。

同じ処理結果をV群の左右2本の棒、A群の左右2つの音に使う。平均・左右差・目標との差へ置き換えない。N群には動作情報を追加しない。

## 初期設定

以下は本研究の工学上の設定値。先行研究が保証した最適値・達成済み性能ではない。本計測前に予備確認し、全参加者へ共通の設定を固定する。

| 項目 | 設定 |
|---|---|
| 提示範囲 | 0–1.5 rps。範囲を超えた値は表示・音だけ上限へ収め、元の値は保存 |
| 平滑化 | 符号付き速度へ一次低域フィルタ。時定数50 ms、係数 `1-exp(-dt/0.05)` |
| 停止付近 | 各輪で0.05 rps以上なら提示開始、0.03 rps未満なら停止。中間は前の提示状態を維持 |
| 共通提示値 | 動作中は `u=clamp(abs(filtered_speed)/1.5,0,1)`、停止中は0 |
| 音高 | 動作中 `f=220*3^u` Hz。左右とも220–660 Hz |
| 音色・音量 | 正弦波、速度で音量を変えない。快適な音量を実施者が設定・記録 |
| 音の接続 | 位相を連続させ、開始・終了は20 msでフェード。周波数変更も20 msで滑らかにつなぐ |
| 音の左右 | 左輪を左チャンネル、右輪を右チャンネル。3D距離減衰・Doppler・残響なし |
| 有効な入力 | 左車輪・右車輪・車体。手首の欠測はFBを止める条件にしない |
| 入力欠測 | 100 msを超える欠測や無効姿勢では両方を無提示。再取得後の最初のサンプルは速度を作らず、次の新しいサンプルを待つ |

同じ入力時刻の姿勢を何度も差分計算しない。欠測を速度ゼロや最後の正常値で補わない。車体の動きを相対姿勢で除き、校正した車軸まわりの回転変化を連続角として扱う。359°→1°は+2°の変化として扱う。

## 提示する場面

| 場面 | A：聴覚 | V：視覚 | N：追加FBなし |
|---|---|---|---|
| 訓練の直進・8の字 | 左右の連続音 | 左右2本のゲージ | 提示なし |
| 事前・直後・保持評価 | 提示なし | 提示なし | 提示なし |
| 訓練終了操作後、記録終了まで | 提示なし | 提示なし | 提示なし |
| 停止・無効入力・中断 | 消音 | 動作情報を消去 | 提示なし |

折返しや旋回を、接触角案の理由で除外しない。訓練中の回転をそのまま返す。高い音や長い棒を正解・成功とは説明しない。

## ゴーグルの見せ方

Unity公式XR Interaction Toolkit 3.4.1のWorld Space UIを手本に、編集可能なPrefabを使う。TextMeshProの日本語SDF、白系背景、黒文字、灰色と青のアクセントで構成する。文字は36以上、自動縮小なし。

訓練中のV群は視野下部の1枚に、同じ寸法・色の左右2本の棒と「左」「右」だけを示す。初期視角24°×8°、中心は視線より下10°。数字・目標・履歴・設定・追従する上部バーを加えない。A・N群と全評価ではゲージを消す。通常起動ではHMD内に操作メニューを出さない。

大きさ・見切れはUnity画像で、レンズ越しの可読性・床面の見え方は実機で確認する。[プレビュー](../development/xr-preview.md)

## 根拠と限界

[Gref 2016、Table 1](../../research/papers/L13-gref-2016.md)には、左右車輪回転速度の和から音高への対応がある。[Dyer 2017](../../research/papers/L64-dyer-2017.md)は両手の動作音を左右チャンネルへ分けた。今回の「左右車輪速度を独立した連続音へ」は両者を参考にした設計で、完全な追試ではない。

連続音は音割れがなくても不快になりうる。[Dubus・Bresin 2010](../../research/papers/L66-dubus-bresin-2010.md)の議論を踏まえ、実装から出した音見本を試聴し、実機で左右の識別・疲労・周囲の指示の聞き取りを確認する。左右が分からない場合に平均FBへ自動変更せず、本計測前に設計を再検討する。
