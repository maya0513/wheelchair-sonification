# 走行中フィードバックの画面・音仕様

個人目標、3状態判定、画面・音の内容と提示の規則を定義する。提示機器とSDKの選定、接触検出の実装方法は[開発ガイド](../development/guide.md)、計測値の意味は[計測・採点の定義](measurement.md)を参照する。

## 提示するものと学習目標

**主要側（利き手側）の直前に完了したプッシュの推定ハンドリム接触角**を返す。接触開始から終了までの車輪の回転量を位置姿勢と接触候補から推定する値であり、力閾値で定めた推進相や推進力を直接計測した値ではない。

走行は止めず、当該プッシュの離手後・次の接触開始前の回復期に**実提示を開始**する。開始済みの提示は次プッシュへまたがってよく、次接触だけを理由には打ち切らない。分類上は「走行中の、ストローク終了後に開始する離散的KP」であり、提示全体を回復期へ限定する方式ではない。動作中の角度を連続音へ変える方式、区間終了後の要約FB、メトロノーム、言語指導とは区別する。[L17](../../research/papers/L17-symonds-sensewheel-2016.md) [L05](../../research/papers/L05-fujii-2016.md) [情報FBレビュー](../../research/topics/information-feedback.md)

FBは10 m直進の中央2–8 mの範囲で、開始・終了ともその範囲にある有効なプッシュに対してのみ提供する。方向転換、停止・制動、範囲外、8の字課題では提供しない。左右対称性や旋回の角度を目標にしない。

## 個人目標と3状態

事前の直進2反復について、中央区間の主要側有効プッシュ角を合わせた中央値を `θ0` とする。基準算定には**2反復合計4本以上、かつ各反復1本以上**を必要とする。片方の反復だけで目標を決めないための本研究の初期設定で、推定の安定性は予備実験で確認する。追跡等の技術的不成立だけを[規定の再試行](../experiment-protocol.md#試行成立と再試行の規則)の対象にする。正常計測で本数が少ない場合は追加走行せず、基準量不足として割付へ進めずに記録する。本数を増やすために短くこぐ・速度を変える教示をしない。予備段階で不足が頻発する場合は、全員共通の基準量・区間の設計を本計測前に改訂する。

```text
要求増分Δ = min(10°, max(0°, 95° − θ0))
θ* = θ0 + Δ

θ0 < 95°  : θ* = min(θ0 + 10°, 95°)
θ0 ≥ 95°  : θ* = θ0
目標範囲  : [θ* − 5°, θ* + 5°]（両端を含む）
```

| 判定 | 条件 | 共通の意味 | 聴覚 | 視覚 |
|---|---|---|---|---|
| SHORT | θ < θ* − 5° | 次は少し長めにこぐ | 440 Hz | 左領域にマーカー |
| TARGET | θ* − 5° ≤ θ ≤ θ* + 5° | 今くらいの長さを保つ | 660 Hz | 中央領域にマーカー |
| LONG | θ > θ* + 5° | 次は少し短めにこぐ | 880 Hz | 右領域にマーカー |

1回の有効プッシュをそのまま分類し、数ストローク平均・区間中央値は使わない。基準算定だけに中央値を使う。目標は3群とも同じ算定規則で説明し、来訪中に更新しない。高い基準値を理由に事後除外しない。

**最大＋10°、95°、±5°は本研究の設計値**。高い基準角では維持を求める方針を保ち、95°で目標が急に下がらないよう、95°未満の増大先も95°で頭打ちにする。最適な推進角、臨床的な改善量、傷害予防の閾値が実証された値ではない。[L15](../../research/papers/L15-richter-2011.md) [L17](../../research/papers/L17-symonds-sensewheel-2016.md)

| θ0 | θ* | 要求増分Δ | 目標範囲 |
|---:|---:|---:|---|
| 60° | 70° | 10° | 65–75° |
| 90° | 95° | 5° | 90–100° |
| 94.9° | 95° | 0.1° | 90–100° |
| 95° | 95° | 0° | 90–100° |
| 97° | 97° | 0° | 92–102° |

Δが5°以下なら基準値自体が既に許容範囲に入る。目標達成の余地は全員同じではないため、θ0・θ*・Δと、増大／維持・基準時点で範囲内の人数を群別に報告する。高基準値の参加者を事後除外せず、天井効果を解釈へ残す。

## 視覚画面

実空間を見ながら読める表示を必須とする。HMDを使う場合は安全な実空間視認を先に確認する。周囲を隠す不透明なVR画面だけで実走行を行わない。画面の機器依存の解像度は未確定であり、以下は見せる情報の仕様。

```text
┌────────── 実空間の視界（走行路・コーン・周囲）──────────┐
│                                                        │
│                                                        │
│          ┌─────────┬─────────┬─────────┐              │
│          │  短い   │ 目標範囲 │  長い   │              │
│          │    ●    │         │         │ ← SHORT例    │
│          └─────────┴─────────┴─────────┘              │
└────────────────────────────────────────────────────────┘
             下部中央の小さな固定ウィジェット
```

- 3領域を等幅とし、文字・枠・マーカーの色や形を領域間で統一する。動的情報は**マーカーの位置だけ**。左右は角度の大小であり、旋回方向ではない。
- 角度数値、頻度、速度、得点、履歴、矢印による進路誘導、達成音との併用を追加しない。
- 枠と3ラベルはV群の訓練直進中に表示し、マーカーを300 ms表示後に消す。次の提示まで前回マーカーを残さない。
- 仮の配置は視野下部中央、画面幅約25%・高さ約10%。絶対ピクセルは実機に合わせるが、読めるサイズと視界の遮蔽を予備実験で確認して全員に固定する。
- A・N群と全群の無FB評価ではゲージも消す。全群共通の安全・計測状態の表示以外は出さない。共通状態表示を出す場合は同じ位置・文言とする。

## 聴覚の音

| 項目 | 仕様 |
|---|---|
| 波形 | 単一正弦波の純音。音楽、声、ノイズを混ぜない |
| 周波数 | SHORT 440 Hz／TARGET 660 Hz／LONG 880 Hz |
| 長さ | 300 ms（立ち上がり・終わり各10 msのフェードを含む） |
| 音量 | 3音で同じ出力設定。最初に聞き取れる快適な音量へ調整し、設定を記録・固定 |
| 左右 | 同じ音を左右へ出す。定位・左右差の情報を与えない |
| 空間効果 | 距離減衰・Doppler・残響による情報変化を使わない |
| 出力 | 有線を優先。周囲の声と安全指示を聞けることを確認 |

音高は角度の大小を表し、音量・長さは成績で変えない。高い音が「よい」という意味ではない。音の間隔は参加者のプッシュに依存し、外部の一定テンポへ合わせる指示はしない。音間隔が周期の手掛かりにもなる点は解釈上の限界として記載する。

440／660／880 Hzと300 msは、最適と実証された処方ではなく、状態を識別しやすく条件を比較しやすい初期設定。[マッピングの根拠と限界](../../research/topics/feedback-design-alternatives.md)を参照。デジタル音量設定を校正なしに音圧dBと呼ばない。3音で主観的な大きさが著しく異なる場合は本計測前に提示系を再評価し、設定変更を条件確定の記録へ残す。

## 提示の時間・頻度・競合

```text
有効な接触開始 ─── プッシュ ─── 離手 → 判定 → [音／マーカー 原則300 ms] → 消去
                                         ↑ 次接触開始より前に実提示を開始
                                           開始済みの提示は次プッシュへ継続可
```

- 訓練直進中の有効プッシュごとに提示候補を作り、以下の成立条件を満たす場合に提示する。漸減・閾値外のみ・自己要求方式を今回の要因に追加しない。候補数・実提示数・取消数を分ける。
- 角度確定の後、実際の提示開始まで200 ms以内を初期の運用目標とする。判定確定からの遅延と、動画の離手からの遅延を分けて実測する。保証済みの値ではない。
- 有効な最新イベントが先行提示と重なる場合は先行提示を打ち切り、最新状態を300 ms提示する。両条件で同じ規則を使い、打切り回数・実提示長を記録する。キューを貯めて遅れた成績を再生しない。
- 提示開始前に次の接触が始まった場合、または回復期・追跡状態を確認できない場合は、その前プッシュの提示を取り消す。遅れた状態を次プッシュ中に新規開始しない。実出力の遅れでこの条件を外れた例は提示逸脱として記録する。
- 直進の有効領域外、停止・制動・旋回、追跡不良、安全停止、課題切替では、待機中の提示を取り消し、実行中の提示も終了する。次接触開始だけでは実行中の提示を終了しない。
- 無効プッシュ・追跡欠損は「SHORT」や「TARGET」に分類せず無提示とする。最後の正常値で埋めない。
- 連続した追跡不良などで安全・成立性が失われた場合は、実施者が全群共通の停止指示を出す。成績の助言はしない。[中止規則](../experiment-protocol.md#試行成立と再試行の規則)

離手、判定、提示依頼、実提示開始終了、次接触開始を区別して検証する。回復期に開始できた割合、次プッシュへ継続した割合、次接触後に開始した逸脱、取消・打切り理由と実提示長を残す。200 ms以内でも回復期開始の条件を外れれば適切な提示とは扱わない。条件間で取消や打切りが偏る場合は、同じ有効プッシュ数を提示できたと報告しない。[受入れ条件](validation.md#検証の進め方)

## 3群の統制

| 項目 | A：聴覚 | V：視覚 | N：追加FBなし |
|---|---|---|---|
| 基本教示・個人目標 | 同一 | 同一 | 同一 |
| 訓練直進 | 純音のみ | マーカーのみ | 動作情報なし |
| 訓練8の字 | 追加FBなし | 追加FBなし | 追加FBなし |
| 事前・直後・休憩後評価 | 追加FBなし | 追加FBなし | 追加FBなし |
| 装着機器・負担 | 同一構成 | 同一構成 | 同一構成 |
| 速度教示 | 快適な一定のペース | 同左 | 同左 |

A・N群もV群と同じ機器を装着し、表示オフによる機器変更を行わない。機器を揃えられない構成は本計測の開始条件を満たさない。無FB群の「自己感覚」には通常の視覚・聴覚・体性感覚が含まれる。

## 本計測前の確認

基準量、角度と状態の精度、追跡、提示時点、走行中の知覚と不快感は[検証計画](validation.md)で確認する。読み取り・聞き取りが成立しない場合は、両条件の情報と時間の対応を保って設定を見直す。使用した設定と確認結果は[条件確定の記録](../operations/record-forms.md#条件確定の記録)へ残す。
