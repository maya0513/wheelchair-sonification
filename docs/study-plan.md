# 研究計画

**左右車輪速度の聴覚・視覚フィードバックが、車いす初心者の練習直後の平地操作成績に及ぼす影響**

自然な推進・旋回に伴う車輪の動きを、そのまま音または表示へ変換して返す。正解の角度や理想速度へ誘導する課題ではない。支援を外した後の成績を比較し、その場の支援と練習後の変化を区別する。[運動学習の整理](../research/topics/motor-learning.md)

## 背景と目的

車いすのソニフィケーションには速度・旋回等を返した先例があるが、効果は課題によって異なり、定量的な保持の根拠は限られる。[Gref 2016](../research/papers/L13-gref-2016.md)。直接的な動作音化には学習上の利点を示す別課題の研究もある一方、常に有効とはいえない。[Effenberg 2016](../research/papers/L10-effenberg-2016.md)、[Nikmaram 2019](../research/papers/L49-nikmaram-2019.md)

本研究は手元のVR機器で取得できる左右車輪速度を使い、同じ2変数を聴覚・視覚で返す場合と追加FBなしの場合を比較する。接触区間の推定に依存せず、装置の成立性を確認しながら小規模な探索研究を行う。[候補比較と選択理由](../research/topics/feedback-design-alternatives.md)

## デザイン

| 項目 | 計画 |
|---|---|
| 対象 | 車いす未経験の成人学生等15名。予備参加者2–3名は別 |
| 割付 | 聴覚A・視覚V・追加FBなしN、各5名。3名ブロックを5つ使う無作為割付 |
| 課題 | コーン間5 mの8の字1周、10 m直進 |
| 来訪 | 1回・合計30分。共通の機器準備・校正は実施者が来訪前に済ませる |
| 訓練 | 直進1分＋8の字1分を2セット。実動4分、切替・休憩を含め7分 |
| FB | 訓練の両課題で左右別々の回転速度を返す。評価時は全群無FB |
| 評価 | 事前・直後の2時点。各課題2反復。休憩後の保持評価は設けない |
| 主要評価 | 開始合図からゴールまでの8の字時間の2反復平均 |
| 追加記録 | 全群で左右の視線・頭部姿勢を探索用に保存。主要分析には加えない |
| 副次・補助 | 快適速度での直進時間、左右回転速度の記述、主観負荷・不快・疲労、欠測・介入逸脱 |

開始合図をPCから出し、実施者が目視で計時を終了する。原著の動き出し基準からの変更で、反応時間と手動操作の誤差を含む。[計測定義](specifications/measurement.md)

## 問いと分析

主要な問いは、練習直後・無FBの8の字成績がA対V、A対Nで異なるか。聴覚の優越を前提とせず、両側の比較を行う。参加者ごとの事前成績で調整した群間差と95%区間を中心に示す。2つの探索的検定はHolm法で調整する。[分析計画](analysis-plan.md)

直進は快適速度であるため、時間短縮を成功と決めない。車輪速度が増えたこと、左右差が減ったこと、主観的に役立ったことだけで技能向上を結論にしない。

## 結論の範囲

各群約5名の探索研究で、十分な検出力は保証しない。反復・ログ行を参加者数に加えず、非有意を同等性と呼ばない。短い訓練後の無FB成績を調べる計画であり、持続的な学習や保持は検証しない。直後の変化には課題への慣れや疲労も含まれる。訓練の実動4分で群差が生じることは保証されず、予備実験で成立性を確認する。記憶固定化の機序、生活上の自立、上肢負担や傷害予防も結論にしない。

全群で同じ装着・教示・練習量を使う。参加者・実施者は提示条件に気づくため盲検ではない。単独実施とスポーツ用車体での成立性、実機性能、倫理手続きは[実施運営](operations/study-operations.md)で確認する。
