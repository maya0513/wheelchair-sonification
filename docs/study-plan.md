# 研究計画

**走行中の推進動作フィードバックが車いす初心者の平地操作技能の獲得と同日内保持に及ぼす影響：聴覚・視覚・追加フィードバックなしの小規模3群比較**

車いすをこぐ動作について同じ情報を音または表示で伝えたとき、支援を外した後の走行・旋回成績にどのような違いが生じるかを調べます。漕ぎ方の変化と、操作の速さ・正確さを合わせて評価します。

以下では、追加のフィードバックを「FB」、ハンドリムに手を接触させてこぐ1回の動作を「プッシュ」と呼びます。「同日内保持」は、訓練当日の休憩後に、FBなしで測る成績を指します。

## 背景と研究の位置づけ

手動車いすの移動には、推進動作に加えて旋回や加減速が必要です。接触角やプッシュ頻度は漕ぎ方を表す指標ですが、角度を大きくすることや回数を減らすことが、そのまま上肢負担の低減を意味するわけではありません。角度の増大に力や速度の増加を伴った報告もあります。[Richter 2011](../research/papers/L15-richter-2011.md)、[Symonds 2016](../research/papers/L17-symonds-sensewheel-2016.md)

FBは練習中の動作を支えます。ただし、支援を受けている間の成績には、その場の助けも含まれます。学習を考えるには、支援を外した後にも変化が残るかを確認する必要があります。[Kantak 2012](../research/papers/L03-kantak-2012.md)、[Fujii 2016](../research/papers/L05-fujii-2016.md)

| 近い先行研究 | 分かったこと | 本研究で確かめる点 |
|---|---|---|
| [Gref 2016](../research/papers/L13-gref-2016.md) | 車いすの速度・旋回・傾きを音に変換し、質的に評価した | 推進角を伝える音と表示を、学習と無FB評価で比較する |
| [Symonds 2016](../research/papers/L17-symonds-sensewheel-2016.md) | 走行中の回復期に、直前のプッシュへ言語FBを与えた | 自動的な提示を使い、対照群と休憩後の評価を設ける |
| [Yan 2021](../research/papers/L14-yan-2021.md) | 区間終了後の視覚要約FBで、保持と実走行への転移を報告した | 走行中の音と表示を比較する。評価は1回来訪の範囲で行う |
| [亀ヶ谷ら2021](../research/papers/L53-kamegaya-2021.md) | 健常成人の5 m・1周8の字で、検者間の計時一致を検証した | この課題を訓練と評価に使い、今回の測定誤差と成立性を確認する |

本研究の貢献は、推進動作の計測を検証した上で、同じ情報を伝える音と表示を比較し、漕ぎ方と平地操作成績を併せて示すことにあります。先行研究だけでは、今回の課題と提示方法で聴覚が優れるかは分かっていません。

## 研究の問い

| 問い | 位置づけ | 評価する内容 |
|---|---|---|
| Q1：聴覚FBで訓練した群の休憩後の8の字時間は、追加FBなし群・視覚群と異なるか | 主要 | 事前時間で調整した2つの群間差 |
| Q2：直進中の接触角は目標へ近づき、FB除去後にも変化が残るか | 副次 | 接触角、プッシュごとの目標絶対誤差、頻度、速度の3時点の推移 |
| Q3：時間短縮に、接触・経路誤り・未完了の増加が伴うか | 副次 | 試行ごとのエラー、完了率、中止理由 |
| Q4：提示は理解しやすく、負担なく使えるか | 補助 | 理解確認、主観的負荷、快適性、疲労、データ有効率 |

聴覚の有用性を期待しつつ、主要比較は両側で行います。認知負荷は補助的な主観評価として扱います。接触角と所要時間が同じ方向へ変化することを前提にせず、両者に関連があっても、それだけで因果機序が分かったとは解釈しません。

## 対象と比較方法

車いす未経験の成人学生等15名を、聴覚（A）、視覚（V）、追加FBなし（N）の並行3群へ、各5名ずつ無作為に割り付けます。予備実験の2–3名は本標本に含めません。15名は実施可能性から設定した人数で、十分な検出力を保証するものではありません。[標本数の考え方](../research/papers/L48-lakens-2022.md)

全群で、基本教示、個人目標、課題、練習時間、休憩、装着機器を揃えます。N群にも通常の環境情報や体性感覚、共通教示はあります。割付は事前評価と理解確認の後に開示します。参加者と実施者には提示の違いが分かるため、動画の計時・採点で可能な範囲の盲検化を行います。[参加条件と割付](operations/study-operations.md#対象と割付)

## 課題とフィードバック

8の字1周で、直進・左右旋回・加減速を組み合わせた平地操作を評価します。コーン間は5 mです。10 m直進では漕ぎ方を評価し、中央2–8 mのプッシュを解析します。両課題を訓練し、各評価では8の字、直進の順に2反復ずつ行います。[コースと実施方法](experiment-protocol.md)

FBは訓練中の直進に限って与えます。主要側の直前のプッシュの推定接触角を、個人目標に対して「短い／目標範囲／長い」の3状態に分け、音またはマーカーで伝えます。提示は離手後の回復期に始めます。8の字や評価中には追加FBを与えません。個人目標と提示の詳細は[フィードバック仕様](specifications/feedback.md)にまとめています。

## 1回来訪での評価

来訪は90分以内とし、習熟と事前評価の後に、直進と8の字を3セット練習します。訓練は実動12分、切替と休憩を含めて19分です。その後、無FBで直後評価を行い、20分の座位休憩を挟んで再評価します。[当日の進行](experiment-protocol.md#90分の進行)

主要な評価時点は休憩後です。予定上、訓練終了から再評価の開始までは約25分あり、実際の時刻も記録します。休憩後の成績には、直後評価で経験した8の字と直進の影響も含まれます。この設計で測るのは、これらの経験を経た後の同日内成績です。翌日以降の保持や、訓練だけによる記憶固定化を分離して測ることはできません。

## 分析と結論の範囲

主要アウトカムは、休憩後の8の字2反復の平均時間です。事前の平均時間で調整したANCOVAを用い、聴覚と追加FBなし、聴覚と視覚の差と95%区間を示します。分析単位は参加者とし、プッシュや反復を人数に加えません。副次・補助評価では個人の推移と群別の記述値を示します。[集約・比較・欠測の扱い](analysis-plan.md)

接触や経路誤り、未完了も時間とともに報告し、速さと正確さの関係を確認します。事前角度から個人目標を作るため、目標誤差の群内の減少だけをFBの効果とは解釈せず、N群の変化も比較します。少人数での区間の広さや欠測による偏りを踏まえ、非有意を同等性の証明として扱いません。

評価対象は、初心者の平地操作と同日内の変化です。坂・段差・移乗・後輪バランス・スポーツ技能や生活上の自立度は扱いません。力・トルク・代謝・傷害を測らないため、負担軽減や傷害予防への効果も結論にはできません。ボール課題、独立した転移テスト、再来訪、脳波測定は設けません。設計を選んだ理由は[設計上の判断](decisions.md)、実施前の確認事項は[開始条件](operations/study-operations.md#本計測開始条件)を参照してください。
