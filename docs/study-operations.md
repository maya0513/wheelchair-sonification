## 募集・説明・同意

募集は学内手続きで許された方法を使う。研究者や教員との関係で断りにくくならないよう、成績・評価と参加は無関係で、不参加・撤回に不利益がないことを説明する。謝礼の有無・金額・支給条件は未確認で、教員確認後に募集文へ記入する。今回、他者への連絡は行わない。

募集文に含める確定内容：車いす未経験の成人、平地での直進と8の字、装着機器、音または表示を使う場合があること、1回来訪90分以内、脳波なし、動画撮影、痛み・疲労・機器不快等による中止自由。無作為割付で希望する条件に入るとは限らないことも説明する。

同意書を確定するための必須事項：

- 研究責任者・相談窓口の連絡先、倫理手続きの名称・番号・承認日または学内の適用判断。
- 取得する属性、動作・動画・主観評価、研究目的、利用範囲、卒論・発表での扱い。
- 想定負担、転倒・接触・疲労・装着不快への対応、参加を中止できること。
- 撮影範囲と音声、顔の映り込み、公開する画像の有無。顔が映る映像の発表利用は通常の計測同意と分けて確認する。
- 保存先、アクセスできる人、保管年限・削除、対応表の管理、撤回の受付期限と実際に削除できる範囲。
- 謝礼、事故時の学内対応・連絡、参加しなくても不利益がないこと。

実名の連絡先・年限・番号を推測で埋めない。決まるまで募集・本計測へ進まない。説明の理解を確認してから署名を得る。

## 安全と負担

会場と各コースを実測し、滑り、傾き、床の段差、配線、障害物、他者の出入りを確認する。椅子の車輪・空気圧・固定・ブレーキ・フットサポート、トラッカー固定具の干渉を点検する。コーンは柔らかい物を使い、停止の余裕を確保する。

実空間が安全に見え、表示を見ても走行路を失わず、音が安全指示を妨げないことを確認する。HMDがこれを満たさなければ実走行は開始しない。型番不明のためパススルー機能があると仮定しない。

停止の合図と安全補助者の位置を習熟中に練習する。痛みの発生・増悪、めまい、強い疲労、不安、機器不快、研究者が安全を保てない状況で中止する。痛みを我慢した目標角度・速度の達成を求めない。中止は成績不良と同一にせず、理由を記録する。

終了時には体調、痛み、違和感を確認し、問題があれば学内の事前に決めた対応へつなぐ。研究者による診断・治療は行わない。

## 主観評価用紙

補助評価は、最後の訓練セットを含む**訓練3セット全体**を対象に1回行う。直後課題を終えた後、52–57分の枠内で記入する。枠内に収まらなければ質問紙を欠測とし、20分休憩や主要評価を削らない。実施の有無・時点と省略理由を記録する。予備実験で1分程度に収まる用紙と説明を確認する。

NASA-TLXは[公式資料D08](../research/papers/D08-nasa-tlx.md)と[日本語版原著L60](../research/papers/L60-haga-1996.md)を参照する。今回は**6下位尺度を個別に記述**し、一対比較の重み付けを行わず、WWLや独自の総合得点を作らない。身体的負荷を認知負荷と混同しない。

| 下位尺度 | この研究での短い説明 | 回答（0–100、5点刻み） |
|---|---|---|
| 知的・知覚的要求 | 考える、見分ける、注意する負担 | 小さい 0 ─ 大きい 100 |
| 身体的要求 | 体を動かす負担 | 小さい 0 ─ 大きい 100 |
| タイムプレッシャー（時間的要求） | 急かされる感じ、時間の圧迫 | 弱い 0 ─ 強い 100 |
| 作業成績 | 自分で感じる課題の達成度 | よくできた 0 ─ できなかった 100 |
| 努力 | うまく行うために必要だった努力 | 小さい 0 ─ 大きい 100 |
| フラストレーション | いら立ち、不安、落ち着かなさ | 小さい 0 ─ 大きい 100 |

尺度名と端点の方向は原著表1（p.73）を画像でも照合した。この短い説明は研究用の説明案で、検証済み日本語版を完全に再現したという意味ではない。予備実験前に教員と説明の適切性を確認し、参加者向け用紙の文言を凍結する。意味を変えた場合は変更版であることを報告し、日本語版の妥当性をそのまま主張しない。

追加する短い項目（独自項目として報告）：装着・提示の不快感0–10、疲労0–10、提示の意味が分かったか、使いにくかった点の自由記述。N群にも装着不快・疲労を尋ね、受けていない動作FBの有用性を答えさせない。A・V群の「役立った」という回答だけで客観的学習効果を結論にしない。

## 予備実験と凍結

2–3名を対象に、同意・安全確認の下で全90分を通す。予備データは本標本から分ける。少人数の予備実験で検出力・臨床的妥当性・一般的安全性を保証したとは書かない。

| 項目 | 初期の確認基準・記録 | 失敗時 |
|---|---|---|
| 課題理解 | 1周の経路・終了線・停止を自力で理解 | 共通説明・図を改訂し再確認 |
| 床・設営 | 5 m・10 m、停止余裕、安全補助者の位置 | 会場調整。短縮するなら別条件として全資料を改訂 |
| 計時 | 開始・最終通過を2採点者が動画で一致して特定。差が0.2秒超の例を全て再確認 | 撮影角度・定義を改善し再採点 |
| 基準量・少数プッシュ | 事前2反復合計4本以上・各反復1本以上の成立率、角度分布・反復間差を記録。正常な少数プッシュでは追加走行しない | 不足が頻発・基準が不安定なら、全員共通の区間・基準量を本計測前に再設計 |
| 推定接触角 | 動画の接触候補を参照にイベントF1≥.90、時刻MAE≤50 ms、角度MAE≤3°・絶対平均偏り≤2°を初期目標 | 検出・固定・参照法を検証。無検証のFBで開始しない |
| 3状態の一致 | 参照状態ごと30本以上で、全体正答率90%以上、各状態の適合率・再現率80%以上を初期基準。両境界付近も下記の条件で含める | 1状態でも条件未達・検証不足なら不合格。検出・許容幅等を再検討し、新しい未使用記録で確認 |
| 追跡 | 全方向・再装着後、中央区間の有効率95%以上を初期目標 | 追跡・コース配置を再確認 |
| 提示 | 原則300 ms、判定後200 ms以内、実提示開始は離手後・次接触開始前。開始済み提示の次プッシュへの継続、取消・打切り・実提示率を記録 | 次接触後の新規開始は不適合。遅延・取消で有効な提示が成立しなければ設定・提示系を修正 |
| 知覚 | 座位の模擬理解確認に加え、走行中も3状態を区別でき、不快・危険な視線移動がない | 表示位置・大きさ・提示時間等を条件間で揃えて再確認 |
| 負担 | 両課題と訓練19分を安全に実行できる | 運動量・教示を再検討。負荷を増やして差を作る方向へ変更しない |
| 時間・記録 | 90分以内、休憩20分を確保、必要な2反復・動画・状態・欠測理由が揃う | 本計測前に手順を改訂 |

数値は**本研究の初期受入れ目標**で、先行研究が保証した閾値ではない。イベント精度は一致窓±50 msで1対1に対応付けた適合率・再現率・F1も残す。角度は一致した区間だけの誤差と、全区間の検出不成立を別々に示す。動画は接触候補の参照であって、力が出た推進相の正解ではない。

### 3状態の技術検証

閾値・校正・検出法の調整用と、最終確認用の記録を走行単位で分ける。最終確認は設定を固定した後の未使用記録で行う。少なくとも2名の予備参加者、直進の往復、加減速、姿勢差、再装着を含め、参照側でSHORT／TARGET／LONGが各30本以上あることを初期の必要量とする。機器検証の追加走行が必要な場合は、通し90分の参加者手順へ黙って足さず、事前の同意・安全確認を満たす別の予備検証として実施する。

目標は各人の固定値を使い、同じプッシュへ多数の仮想目標を当てて検証本数を増やさない。参照角度と目標から、推定結果を見ずに状態を付ける。両境界（θ*−5°、θ*＋5°）の上下それぞれ2°以内を各5本以上含め、境界帯の件数・誤差・状態一致を別に示す。状態を作るために痛みのある動作や無理な可動域を求めない。安全に必要な範囲を検証できなければ、範囲・目標・許容幅の設計を見直す。

| 判定項目 | 定義・初期条件 |
|---|---|
| 全体正答率 | 正しく検出・分類できた参照プッシュ数／全参照プッシュ数≥90%。未検出・無効も分母へ含める |
| 状態別再現率 | その参照状態を正しく返せた数／その参照状態の全件数≥80%。3状態すべてで満たす |
| 状態別適合率 | その状態を正しく返せた数／その状態として出力した全件数≥80%。余分な検出による出力も分母へ含める。出力0件は合格にしない |
| 混同行列 | 参照3状態に加えて「参照なし」、推定3状態に加えて「未検出・無効」を区別し、誤分類・未検出・余分な検出を残す |
| 検証量・範囲 | 参照各状態30本以上、各境界の上下2°以内を各5本以上。人数・走行・側・方向・角度範囲・再装着を記録 |

30本・80%・境界帯の幅と本数も**本研究の初期設計値**であり、一般的な性能保証や推奨基準ではない。全体平均だけで1状態の失敗を隠さず、検出不成立や境界例を後から捨てない。調整をやり直した場合は、失敗した確認結果も残し、さらに別の未使用記録で最終確認する。同じ記録の再生は回帰確認に使い、独立した性能確認と呼ばない。

既知角度の模擬入力による分類処理の確認、動画参照による検出・角度・状態の確認、参加者の模擬提示による理解確認を別々に行う。動画は接触候補の参照で、力に基づく正解ではない。参照の遮蔽や角度判定が不明な例は件数と理由を残す。人数・試行数・本数・誤差範囲を報告し、小さい平均誤差だけで範囲外の性能を保証しない。

### 提示時点と凍結記録

離手・判定・提示依頼・実提示開始終了・次接触開始の時間関係を確認する。実提示が回復期に開始した割合、次プッシュへ継続した割合、次接触後に新規開始した不適合、領域離脱等の取消、遅延による取消、実提示長を音・画面別に残す。実提示が得られない状態や、時点を判定できない状態でG3を完了扱いにしない。

凍結記録には、日付、文書版、コース写真・寸法、椅子・機器構成、表示・音・目標・300 ms、検出／設定版、検証データの範囲、採点方法、乱数種・割付管理者、倫理確認、分析方針、教員確認を残す。本計測で群ごとの提示方式を変えない。角度が成立しない場合の頻度への自動置換は現行仕様に含めず、研究計画の改訂として扱う。

## データ管理

研究用IDと実名の対応表、同意書、参加者の映像・生ログは公開リポジトリへ置かず、学内で認められたアクセス制限のある保管場所へ保存する。実名対応表を動作データから分ける。アクセス担当、保管期間、削除方法、バックアップ先、撤回受付期限を責任者と決め、同意書へ反映する。現在これらの実際の保管先・年限は未確認。

分析用動画は音声と不要な識別情報を外した複製を使い、元データを保持する。匿名IDでも映像や体格から識別されうるため、完全匿名と断定しない。公開可能な結果は集約表・図を基本とし、個人映像や生データの公開は別の同意と学内確認を要する。
