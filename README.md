# wheelchair-sonification

車いす初心者の技能練習を、左右車輪の回転速度を返す音・ゲージで支援する卒業研究。聴覚・視覚・追加FBなしの3群で、FBを外した後の8の字時間を比較する。被験者のアプリ操作はなく、実施者がPCで手動選択・計時する。
